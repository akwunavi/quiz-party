# Bulldog №4 — 10 параллельных сценариев

Один диагностический экран и одна детерминированная модель движения (`model.mjs`) для десяти наборов событий. Production Race Scenario V2 и игровые компоненты не используются и не изменены. В прототипе нет косточки и нет отдельной программной бабочки; BUTTERFLY показывает только очищенную alpha-анимацию собаки.

## Просмотр

`DOG4_PARALLEL_10_SCENARIOS.mp4` открывается обычным видеоплеером, без сервера. Это полная запись 45,00 с в игровом времени, 2560×1440, 24 кадра/с, H.264 yuv420p, без аудио.

Для интерактивной версии распакуйте ZIP и в папке с `index.html` выполните:

```bash
python -m http.server 8795
```

Откройте `http://127.0.0.1:8795/` в Chrome. Доступны Play, пауза, сброс, выбор скорости и перемотка. Таблица диагностики раскрывается под экраном. Зависимостей от репозитория, React или сборки нет; нужен только локальный HTTP-сервер для загрузки модулей и атласов.

## Файлы

- `model.mjs` — единственная модель позиции и состояний всех десяти собак.
- `app.mjs`, `index.html` — интерактивная визуализация.
- `layout.json`, `manifest.json`, `assets/` — диагностическая раскладка, утверждённый фон Visual Pass 3 и уменьшенные атласы утверждённых alpha-кадров.
- `validate.mjs` — проверки всех сценариев в Node.
- `record.mjs` — запись того же Canvas в MP4 через Chromium и ffmpeg. Для повторной записи нужны `playwright-core`, Chromium и ffmpeg; просмотр готового MP4 этого не требует.
- `REPORT.md` — результаты и известные ограничения.

Исходные PNG/WebM и файлы репозитория не перезаписаны.
