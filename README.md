# Bulldog #4 — технический аудит переходов

Это отдельный диагностический набор. Исходные RUN и SNIFF_PEE, утверждённые WebM и production не изменялись. Начните с [REPORT.md](REPORT.md).

## Видео для просмотра в обычном проигрывателе

- [01_start_from_existing_run.mp4](01_start_from_existing_run.mp4) — исходная стойка и начало бега → утверждённый RUN.
- [02_run_loop_test.mp4](02_run_loop_test.mp4) — утверждённый RUN три раза; исходный шов виден.
- [03_stop_feasibility.mp4](03_stop_feasibility.mp4) — freeze и резкий переход намеренно показывают отсутствие STOP.
- [04_sniff_action_variants.mp4](04_sniff_action_variants.mp4) — полный SNIFF и два диагностических сокращения.
- [05_return_feasibility.mp4](05_return_feasibility.mp4) — конец SNIFF и несовместимый переход к стойке.
- [02b_internal_loop_candidate.mp4](02b_internal_loop_candidate.mp4) — эксперимент с коротким циклом, не утверждённый RUN.
- [03b_reverse_stop_diagnostic.mp4](03b_reverse_stop_diagnostic.mp4) — обратное воспроизведение раннего разгона, не утверждённый STOP.
- [04b_sniff_neutral_candidate.mp4](04b_sniff_neutral_candidate.mp4) — дополнительный срез SNIFF #12–216 с почти нейтральным началом; конец остаётся в боковом ракурсе.

Все MP4: H.264, yuv420p, 1276×720, 24 FPS, faststart, без аудио. Диагностические надписи указывают исходные кадры. Монтажные скачки в 03 и 05 специально оставлены видимыми.

## Кадры

Папка [reference-frames](reference-frames/) содержит исходные PNG в полном разрешении: рекомендуемые пары и три альтернативные пары для START, STOP и RETURN, а также контактные листы. Файлы `*_uniform_*.png` — отдельные производные копии на ровном бежевом фоне для будущих опытов; исходные PNG сохранены без изменений. Успешная генерация в Kling по этим кадрам не проверялась.

`dog4-start-alpha.webm` — производный прозрачный START из исходного RUN #0–39. Он не заменяет утверждённый RUN.

## Границы проверки

Метаданные и полное декодирование файлов проверены локально. Покадровые кадры и количественная геометрия изучены. Просмотр непрерывного движения при 1× на большом проекторе этим аудитом не подтверждён; диагностики предназначены для такой оценки пользователем.
