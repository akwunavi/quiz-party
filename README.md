# Bulldog Racing — isolated visual prototype

Visual Pass 3 environment with five supplied RUN videos. Preview-only publication authorized by the user.

Open index.html through a static HTML host. The self-contained alternative is Bulldog-Racing-Real-Dogs.html. Controls: 1–5 states, Space Play, H hide UI, C calibration.

This publication branch contains only prototype artifacts. No production app, CI workflows, application state, scoring or winner logic. Do not merge into main.

See Real-Dogs-Report.md for known background, loop and performance limitations.
