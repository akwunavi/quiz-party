Старт: коммит `61ae98d`, решение архитектора «P3 принимаем, `lead = 3`, `f35 → RUN #88`». V3 (`dog4-v3-lab`), production, Dog4, исходные ассеты не менялись; новых изображений, AI-видео и alpha нет; merge/deploy нет. Единственная правка вне лаборатории — уточнение `docs/bulldog-race/ANIMATION_CONTRACT.md` (клипы вписываются в окна сценария), утверждённое в задании.

## 1. Что реализовано

* **Визуальный слой** `visualAt(contract, segments, t)` (`src/visual.mjs`): чистая функция, читает физические сегменты V3, ничего не пишет; `lead`, `tail`, `pad`, ограниченный `retime` (в том числе `tailRateByNext` для тестового варианта), `shift`; усечение и отсутствующие ассеты возвращаются явно (`overflow`, `MISSING_ASSET`), не подменяются. 0,35 мкс на вызов, 17 мкс на построение временной шкалы собаки (замер на 200 гонках).
* **Bulldog №4 как эталон** (`characters/dog4.contract.json`): тождественные метаданные; 4 571 761 точка сравнения со старым `stateAt`/`frameFor` — **0 расхождений** (пресеты A/B/C, 300 случайных гонок, границы сегментов ±5·10⁻¹⁰…2·10⁻⁹).
* **Френк** (`characters/frenk.contract.json`): только то, что существует; статусы в контракте:

| клип | статус в контракте |
|---|---|
| RACE_STAND (стойка, BASE) | утверждена |
| START (RACE_START gen3 + стык f35→RUN #88, `lead 3`) | рабочий; **визуальная приёмка не пройдена** |
| RUN (цикл #87–98) | утверждён (внутри таблицы START, `spillFromStart`) |
| STOP (73 кадра: 37 в окне + хвост 36) | утверждён |
| BUTTERFLY (игровая обрезка f1–f93) | принят как рабочий; **retime ×1,093 не утверждён** |
| SNIFF_PEE (EVENT V3.2, 200 кадров) | **сырой, без alpha** |
| ROLL | **отсутствует** (`MISSING_ASSET`) |
| RETURN | вшит в EVENT SNIFF_PEE |
| FINISH_DECELERATE | **временно** = STOP, не утверждено (`PROVISIONAL`) |

* **Валидатор** (`src/validator.mjs`): Dog4 проходит; Френк как есть даёт ровно одну ошибку (BUTTERFLY после STOP, −11 кадров) и список неполных ассетов; вариант ×1,0932 проходит; из 14 внесённых искусственных дефектов обнаружены 14.
* **Смешанная гонка** (`tests/mixed_race.mjs`): Френк в полосе 1 + четыре Bulldog №4, реальная физика V3; три демонстрационные гонки (текст + диаграмма) в `results/`.

## 3. Переход STOP Френка в неподвижное окно (движение и контакт лап)

Метод (`analysis/stop_contacts.py`): alpha STOP (73 кадра) декодируется, опорные кадры = нижняя точка силуэта у земли; контакты — кластеры маски в нижней полосе, ведущий кластер прослеживается по кадрам эпизода; мировое смещение лапы = ход якоря физического STOP (по кривой V3, 5 категорий) + смещение лапы в координатах спрайта. Данные и диаграмма: `results/stop_contact_analysis.json`, `STOP_CONTACT_CHART.png`.

**Что видно:**
1. Клип — **прыжковый галоп с фазами полёта**, а не «шаги». Контактов 5 эпизодов по 2–3 кадра (кадры 1–2, 10–12, 20–21, 29–31 — в физическом окне; 39–40 и оседание 48–58 — в неподвижном хвосте), между ними лапы в воздухе до ~10 px.
2. **В каждом контакте лапа уходит назад в координатах спрайта на 9–21 px (до 14 px/кадр)**: клип снят с камерой, следящей за собакой. Ход якоря V3 в окне ≤ 1,16 px/кадр, поэтому скольжение определяется клипом, а не категорией скорости (разница между категориями < 0,6 px).
3. **Окно (кадры 1–37):** скольжение за эпизод −9,1 / −19,4 / −12,0 / −21,2 px. Для сравнения у утверждённого RUN Френка (кадры #87–98, разбор вне репозитория) лапа в контакте уходит назад со средней скоростью **13,0 px/кадр** (макс. 13,5) при скорости якоря 1,16 px/кадр. То есть окно STOP — **на уровне RUN**, который уже принят. Dog4 не измерялся: ассетов нет.
4. **Неподвижный хвост (кадры 38–73) — новое по сравнению с RUN:** после остановки якоря ещё два эпизода: кадры 39–40 (−12,6 px, 12,6 px/кадр) и оседание 48–58 (−16,4 px, скорость затухает 4 → 0 px/кадр); корпус неподвижен с кадра 63. Итого ≈ **29 px скольжения лап при остановленной физике**, плюс запечённое смещение корпуса 10,6 px вперёд.
5. Стык окно→хвост (кадры 37→38): кадры идут 1:1 без retime, скачка фазы нет (кадр 37 — полёт, 38 — касание, смещение корпуса cx 1,5 px). Но контакт 39–40 — приземление с ходом лапы назад 12,6 px/кадр **при нулевой скорости якоря**.
6. **Foot-lock невозможен в рамках поводка:** чтобы все опорные лапы стояли в мире, нужен накопленный сдвиг 61,7 px к кадру 37 и 90,7 px к кадру 73 (NORMAL); корпус прошёл бы 129 px против 38,5 px без сдвига. Бюджет поводка 39 px. Клип изображает бег со скоростью примерно в 6 раз больше скорости STOP в V3 (так же RUN примерно в 11 раз) — это свойство клипа и скорости трассы, не ошибка контракта.

**Вывод:** по строгому критерию «нет скольжения лап относительно трассы» STOP Френка **не проходит**: в окне скольжение на уровне RUN, в хвосте добавляется 29 px при остановленной физике. Контракт P3 этого не лечит и не должен имитировать. Решение за архитектором: (a) принять как уровень RUN (собака «ещё докатывается», читается как торможение); (b) требовать STOP с опорой лап (новый ассет, отдельное разрешение); (c) вводить тихий shift-закон хвоста (не построен, потолок 39 px).

* Только тело ×1,134 выходит за границу 1,12; пропуск в «тихих» кадрах (альтернатива, не реализована) даёт p95 0,224 — как оригинал. Решение о retime не принималось.

## 5. Фактические ограничения прототипа

1. Лаборатория работает с **метками кадров**, не с пикселями: рендер Френка в смешанной гонке не строился; Dog4 не рендерился (ассетов нет в checkout).
2. T1/T8 структурные: модель V3 не менялась, поэтому «не повлияло» доказывает отсутствие связи (граф импортов, замороженные данные), а не сопротивление изменениям.
3. T3 не включает настоящий цикл рендера.
4. Shift-массивы есть только для START; для STOP/хвоста сдвиг **не определён** (`UNDEFINED_NOT_BUILT`). Стыки STOP→действие и действие→START не измерены.
5. Контакт лап измерен для STOP Френка; для RUN Френка — по кадрам из рабочей папки (вне ветки); RUN и STOP **Dog4** не измерялись.
6. Нет клипов: ROLL (отсутствует), alpha SNIFF_PEE; FINISH_DECELERATE временно STOP; START не принят визуально.
7. EVENT SNIFF_PEE принят как цельное тело 200 кадров; запас окна 0,55 кадра зависит от того, нет ли внутри него собственных пауз.
8. Retime BUTTERFLY — расчёт и превью, глазная проверка не проводилась (T11).
9. Все метрики плавности — силуэт/центр масс, не восприятие.

## 6. Рекомендация

* **Архитектура P3 готова к следующему шагу — проектированию интеграции** (визуальный слой как отдельный модуль рядом с физикой, контракт и валидатор в приёмке ассетов): детерминизм, независимость от физики, золотой тест Dog4 (4,57 млн точек) и фазовая сетка STOP подтверждены на реальной физике V3.
* **Френк к интеграции в игру не готов.** Блокеры: нет ROLL; нет alpha SNIFF_PEE; BUTTERFLY после STOP не помещается (нужно решение по retime); FINISH не утверждён; START без визуальной приёмки; контакт лап STOP не проходит строгий критерий (нужно решение a/b/c из раздела 3); T11 не проведён.
* Перед интеграцией: (1) повторить T2 на реальном рендерере с пикселями Dog4; (2) глазная проверка стыка START→RUN и retime BUTTERFLY; (3) решение по STOP; (4) по желанию — сравнить RUN/STOP Dog4 по тому же методу контактов, чтобы знать, какой уровень скольжения «утверждён» на самом деле.
