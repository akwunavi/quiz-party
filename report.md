# Bulldog №4 — тест прозрачности RUN

Отдельный тест удаления фона. Визуальный прототип гонки, остальные собаки и production-код не менялись. Видео **не зациклено**.

## Материал и обработка

- Исходник: `bulldog_4_run.mp4`, H.264, 1276 × 720, 24 fps, 121 кадр (5,041667 с).
- После просмотра всего клипа оставлены исходные кадры **40–120 включительно**. Начало полезного устойчивого бега — 1,666667 с; диапазон по времени **[1,666667; 5,041667) с**. На отметке около 1,2 с собака ещё переходит к бегу.
- Модель сегментации: локальная BiRefNet-general-lite через ONNX/rembg, вход модели 1024 × 1024. Маски уточнены между соседними кадрами оптическим потоком с проверкой согласованности и окклюзий. Для мягкой границы применён closed-form alpha matting (PyMatting) и очистка цвета на полупрозрачных краях. Внутренние непрозрачные пиксели собаки взяты непосредственно из исходника; исходные пол и контактная тень удалены.

## Результат

- `dog4-run-alpha.webm`: VP9 с alpha, **1276 × 720, 24 fps, 81 кадр, 3,375 с**.
- `dog4-four-backgrounds.mp4`: короткий сравнительный ролик с одной и той же собакой на белом, чёрном, ярко-зелёном и тёплом песочно-зелёном фоне.
- `review-grid.jpg` и `frame-XX-*.png`: контрольные кадры в шести фазах движения на всех четырёх фонах.

На проверенных кадрах уши и кончики ушей, лапы, морда, контур корпуса и просветы между ногами сохраняются. Крупных остатков исходного пола, серого прямоугольника или заметного ореола на четырёх фонах не видно. Маски между соседними кадрами согласовывались по движению; на просмотренных фазах явного скачка контура нет. Быстрые лапы местами остаются чуть мягче корпуса — результат следует оценить в движении до обработки остальных собак.

В локальном Chrome готовый WebM декодирован в шести точках ролика: alpha вне собаки равен 0, внутри корпуса — 255. Все четыре переключателя фона проверены. Это подтверждает работу alpha в Chrome для подготовленного файла; отдельную опубликованную страницу следует открыть по тестовой ссылке для визуальной приёмки.
