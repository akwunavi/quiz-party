## Рокки — фаза RUN перед STOP (исправлено)

* Причина: принятый `phase.mjs` отказывался работать на RUN короче 155 кадров (в коде: «six advances need separate review»), а в случайных гонках V3 такие отрезки составляют 16% остановок (длины 23…143 кадра; все длины V3 = 23 + 12·m). Там перед STOP оставался #62 вместо #68: шов RUN→STOP IoU 0,58 (против 0,84), лапы на 5 px ниже.
* Исправление: `runtime/phase_v2.mjs`. От 155 кадров вызывает принятый `phase.mjs` без изменений (побайтно совпадает на всех длинах 155…2003, тест). Короче — схема пропусков по лестнице: T1 (107–143) — те же параметры принятого алгоритма, раньше эти длины просто не рассматривались; T2 (83, 95) — тот же #64→#66 с укороченным беспропускным хвостом; T3 (23–71) — пропуски на любом кадре цикла по цене шва, равномерно, не чаще чем через 2 кадра.
* Результат: на 28725 остановках из 2500 гонок × 5 дорожек — **#68 в 28725 из 28725**; повторов кадров нет, каждый шаг +1 кадр цикла или пропуск +2, ячейки START→RUN (0–10) не тронуты. Таблица по длинам: `ROCKY_PHASE_EVAL.md`.
* Ограничение, которое остаётся (физика цикла, не ошибка кода): нужно 6 пропусков в любом отрезке, поэтому у самых коротких пробегов темп шага выше: ×1,5 на 23 кадрах (≈1 с, 80 из 4659 коротких остановок), ×1,25 на 35, ×1,17 на 47, ≤×1,125 с 59 кадров. Худший шаг при этом IoU 0,69 (обычный шаг ≥0,757) — всё равно заметно мягче единственного шва 0,58. Альтернативы (вход в #67/#69, не исправлять, удлинять цикл) хуже или равны — разбор в `ROCKY_PHASE_EVAL.md`/KNOWN_ISSUES. Выключатель: `CONFIG.minCorrectedCells` в `phase_v2.mjs`.
* Статус: короткая схема (n < 155) технически проверена, **глазной приёмки не было** — см. `ROCKY_PHASE_BEFORE_AFTER.mp4`. Длинные пробеги — принятое поведение без изменений.

## Существующие тесты Race V3/P3 (повторный прогон)

Тесты `race-v3-p3-lab/tests` жёстко привязаны к контракту Фрэнка и эталону Пупса — на остальных собак их не распространить без переписывания, поэтому для Зефира, Рокки и Луны вместо них работает общий валидатор выше.

* T1 **PASS** — physics independent of characters / metadata
* T2 **PASS** — Bulldog 4 golden: P3 identity metadata == legacy frameFor/stateAt
* T3 **PASS** — independence from FPS / evaluation order
* T4 **PASS** — phase: RUN frame before STOP == STOP entry, on every real STOP and FINISH
* T5 **FAIL** — no truncation: every clip fits its window
* T6 **PARTIAL** — no sliding while the sprite stands (pre push-off) / paw contact
* T7 **PARTIAL** — phase jumps at joins (START -> RUN #88)
* T8 **PASS** — no advantage from clip length (mixed lane assignment)
* T9 **PASS** — leash and finish: visual offset bounded, zero at crossing
* T10 **PASS** — contract validator
* T11 **NOT_RUN** — eye acceptance (retimed BUTTERFLY, joins at game scale, STOP tail)
* T12 **PARTIAL** — local mixed race: Frenk + 4 x Bulldog 4 on real V3 physics

T5 FAIL (Фрэнк как есть: BUTTERFLY после STOP не влезает на 11 кадров) относится к старому контракту; контракт Фрэнка из пакета интеграции (`integration_v1`) проходит валидатор без ошибок. T11 требует человека.

## Зефир: сверка с его принятой лабораторией

Контракт + адаптер сравнены с `runtime/dog2stop.mjs` (его принятая лаборатория STOP) в окнах BASE/START/RUN/STOP/FINISH на 100 гонках: сопоставлено 581 496 кадров; расхождений по кадру **0**  по сдвигу спрайта **0** (макс. разница 0 px).
Действия (BUTTERFLY/ROLL/SNIFF_PEE) проверены только валидатором P3 и наличием кадров: их порядок взят из атласов и `rhythm_variants.json[selected]`.

## Швы состояний (попиксельно, с учётом сдвигов спрайта)

Эталон — IoU соседних кадров цикла RUN у той же собаки (мин.). Шов помечен, если IoU < 0,75 или лапы сдвинулись > 3 px или центр > 8 px.

| Рокки №3 | 0.76 | нет |
| Пупс №4 | 0.778 | нет |
| Луна №5 | 0.745 | нет |

Фрэнк RUN→STOP (0,73) чуть ниже эталона цикла (0,758). Пакет Фрэнка принят пользователем, но глазной проверки именно этого шва в отчёте P3 нет (T11 «NOT_RUN») — оставляю как наблюдение, не как ошибку.

Пояснение к T4: у Фрэнка, Зефира и Луны в контракте объявлен кадр RUN перед STOP (`run.stopEntry`), проверяется он. У Пупса и Рокки такого поля нет (стиль dog4): проверяется только первый кадр STOP, а фаза RUN у Пупса задана самой арифметикой V3 (эталон), у Рокки — проверяется отдельно (раздел выше).
