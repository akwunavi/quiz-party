# Единые правила отображения (display contract)

Описывает, как ставить спрайт любой из пяти собак в Race V3. Числа — из `assets/dogs/*/display.json` и замеров `reports/sizes.json`; ничего не менялось в утверждённых пропорциях.

## 1. Геометрия сцены (общая, `dog4-v3-lab/layout.json`)
* Логический кадр 1920×1080. Дорожки: `laneY = 260 + 159·i`, i = 0..4 (шаг 159 px). Старт `x = 406`, финиш `x = 1484` (+92 px контрольный вынос).
* Спрайт всегда рисуется **207×116** в точке `(x − 148 + сдвиг, laneY − 110)`. Якорь спрайта = (148, 110): строка 110 ячейки лежит на линии дорожки (линия лап), столбец 148 — на мировой координате собаки.
* Между дорожками свободно 159 − (110 + 6) = **43 px**: спрайт не заходит на соседнюю дорожку (верх ячейки на 110 px выше линии, низ на 6 px ниже). Проверено в лаборатории: наложений дорожек нет.

## 2. Размеры ячеек атласа
| собака | ячейка | как попадает в 207×116 |
|---|---|---|
| Фрэнк, Зефир, Луна | 207×116 | 1:1 |
| Рокки, Пупс | 178×100 | растяжение ×1.163 по x и ×1.16 по y (как рисует игра; решение по Пупсу сохранено, Рокки сделан так же) |

Унифицировать ячейки механически не требуется и не делалось: игра рисует любую ячейку в 207×116. Допустимые размеры ячейки — любые с тем же соотношением ≈1.78 (207:116) при 24 колонках; `atlas.json` хранит `cellWidth/cellHeight/columns` каждой собаки.

## 3. Линия лап и сдвиги
* Линия лап = строка 110. Нижний ряд силуэта у стоек: Фрэнк 109, Зефир 109, Рокки 108, Пупс 110, Луна 110 (разброс ±2 px). В беге лапы опускаются до 110 (Фрэнк, Зефир, Луна), у Пупса до 113 и у Рокки до 115 (растяжение ячейки 100→116): до 5 px ниже линии дорожки в отдельных кадрах галопа. Это замеры, не правка.
* Сдвиг спрайта по x (px спрайта, + вправо) — по правилам каждой собаки, их исполняет `runtime/dog_visual.mjs` (`shiftPx`):
  * **Фрэнк**: массивы START по категории скорости, массивы STOP по категории, стационарный сдвиг от последнего STOP.
  * **Зефир**: сдвиг стойки для стойки и всех действий; START гасит качание корпуса (`−(cx − cxRun)·(1 − smoothstep(k/42))`); STOP — сдвиги монтажа с плавным выходом на сдвиг стойки.
  * **Луна**: `contract/stop_shift.json` — сдвиг на каждый кадр STOP (37 + хвост 22); вход 0, выход ≈ −1 px.
  * **Рокки, Пупс**: сдвигов нет (у Рокки сдвиг входа STOP запечён в атлас); у Рокки есть поправка КАДРА RUN (`runtime/phase.mjs`).
* Тень в лаборатории — общий нейтральный эллипс; у Фрэнка и Зефира в их runtime есть свои правила тени (в адаптер не переносились: это арена, не библиотека).

## 4. Масштаб
* Все пять — `scale = 1.0`. Луна остаётся 1.0 (RUN на 21% длиннее среднего остальных и на 17% — по прежней оценке). Возможное ×0.93 включается галочкой в лаборатории (рисует спрайт с якорем (148,110)) и **не применено** — решать в общей гонке.
* Размеры в игровых пикселях (RUN, среднее по циклу): см. `reports/SIZE_COMPARISON.md`. Разброс по длине: Пупс ×0.73 … Луна ×1.21 от среднего остальных. Утверждённые пропорции автоматически не менялись.

## 5. Другое разрешение проектора
* Спрайты рисуются на логическом кадре 1920×1080 и масштабируются вместе с ним. Атлас 207×116 при 3840×2160 растягивается ×2 (нужна ячейка 414×232 для 1:1); для 2560×1440 — 276×155.
* Исходные alpha — 1276×720 с собакой ≈ 660 px: ячейку можно пересобрать до **1276×720 (×6.16 от 207)** без апскейла. Для крупного плана/4K пересобирать из alpha каталога `alpha/` рецептом собаки (`tools/`; у Фрэнка и Луны воспроизводимость подтверждена попиксельно, у остальных — не запускалась).
* Правило пересборки: `ширина ячейки = 207 · (ширина экрана / 1920)`, высота = ширина·116/207; якорь и строка лап масштабируются тем же коэффициентом; для Пупса и Рокки пересборка из alpha убирает потерю чёткости от растяжения ×1.163.

## 6. Что нельзя
Менять физику Race V3, окна клипов, лидирование/таил собаки или якорь по-собачьи. Любое такое изменение — отдельное решение с проверкой `tools/validate_library.mjs`.
