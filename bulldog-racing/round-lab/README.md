# Лаборатория раунда «Скачки бульдогов» (выбор → пьедестал)

Нейтральная браузерная лаборатория: полный сценарий на настоящей модели Race V3 и библиотеке пяти собак. Не арена, не production, приложение Quiz Party не затронуто.

**Запуск** (из корня репозитория): `python3 -m http.server 8000`, затем открыть `http://localhost:8000/bulldog-racing/round-lab/` в Chrome/Chromium (видео не нужны, только PNG-атласы; первая загрузка ≈ 120 МБ).

Панель справа: число команд (1–24), раскладка («случайно / поровну / все на №3 / перекос / никто»), кнопки 1–5 за каждую команду (менять можно до старта), seed (пусто = случайный в момент старта), D (длительность, с), скорость ×1…×8 (только ускоряет показ), «Завершить выбор → К старту», «Пропустить паузу», «Перезапуск».

Сценарий: выбор (IDLE → SELECTED → RETURN по правилам каждой собаки) → завершение выбора (ставки заблокированы) → сценический переход → отсчёт (собаки в RACE_STAND на линии) → гонка Race V3 с действиями и бабочкой → финиш с местами → пьедестал (очки команд = 5 − место выбранной собаки).

Файлы: `src/raceV3.mjs` (Race V3 с параметром длительности), `src/rules.mjs` (ставки/очки), `src/selection.mjs` (правила IDLE), `src/butterfly.mjs` (объект-бабочка), `src/game.mjs` (контроллер сценария), `src/main.mjs` (отрисовка и панель), `tests/round.test.mjs` (13 тестов: `node --test bulldog-racing/round-lab/tests/round.test.mjs`), `reports/` (видео и отчёт).
