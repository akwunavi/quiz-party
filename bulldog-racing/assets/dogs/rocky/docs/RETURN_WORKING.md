# Рокки — RETURN_TO_IDLE D принят как рабочий вариант

**Решение пользователя:** вариант D из коммита `95f3f2c` принят для дальнейшей сборки и финальной визуальной проверки полной цепочки выбора. **Это не окончательная production-приёмка.** Варианты A/B/C/E/F отклонены; повторно их не предлагать без принципиального устранения дефектов.

- Карта RETURN D неизменна: утверждённый SELECTED source **#120→24**, обратный порядок, каждый кадр один раз, **97 кадров / 4,041667 с при 24 FPS**.
- Исходные SELECTED #0–120, IDLE B (240 кадров) и FRONT_STAND не изменялись.
- [Прозрачный WebM D](assets/DOG3_RETURN_D_ALPHA_97.webm) собран из **уже утверждённой alpha SELECTED** перестановкой кадров; повторная сегментация и генерация не применялись.
- [Проверка WebM на четырёх фонах](DOG3_RETURN_D_ALPHA_FOUR_BACKGROUNDS.png), [проверка alpha всех 97 кадров](return_d_alpha_check.json), [проверка Chromium](return_d_browser_check.json).
- [Изолированная лаборатория выбора](index.html) и [карта сценариев](SELECTION_LAB_MAP.json) показывают IDLE B → SELECTED → RETURN D → IDLE B при подтверждении выбора в шести разных фазах.

При переходе к IDLE B последний кадр RETURN — SELECTED #24, первый кадр IDLE B — source IDLE #0. Верх силуэта отличается на 3 px исходного кадра, линия опоры совпадает; этот стык пользователь признал подходящим в D. Обратная мимика и переступание передней лапы требуют финальной оценки в полной цепочке.

Первоначальная лаборатория ожидала завершения всего IDLE B и давала до **239 кадров / 9,958 с** на фазе #1. Пользователь отклонил **эту политику ожидания**, сохранив D рабочим RETURN. Новая [лаборатория выхода через совместимые стойки](../idle-exit-lab/REPORT.md) подготовлена отдельно для визуальной приёмки. Production-политика ещё не утверждена.
