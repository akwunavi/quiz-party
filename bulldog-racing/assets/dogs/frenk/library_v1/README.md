# Библиотека анимаций Фрэнка (Bulldog №1) — `frenk-library-1.1.0` (23.10.2026; первая версия 1.0.0 — 15.10.2026)

**Библиотека завершена (23.10.2026).** В 1.1.0 добавлен утверждённый выбор в любой момент IDLE — вход A, `../selection_anytime_v1/APPROVED.md`. Клипы не менялись.

Один воспроизводимый набор всех утверждённых анимаций Фрэнка. Индекс со всеми файлами и SHA-256 — `LIBRARY.json`, проверка — `python3 library_v1/verify_library.py`. Генераций Kling в этой работе не было. Утверждённые движения, гоночный пакет, Bulldog №4, физика V3 и production не менялись. Merge и deploy не выполнялись.

| Экран выбора: выбор в любой момент | после выбора IDLE своими кадрами идёт до стойки f12 (0–106 кадров, максимум 4,42 с), затем SELECTED f20 → RETURN → IDLE с f9; утверждено 23.10, вход A | `../selection_anytime_v1/` (`selection.mjs`, лаборатория, `APPROVED.md`) |

Все три клипа экрана выбора: 1276×720, 24 к/с, VP9 с alpha (`alpha_mode=1`; декодировать через libvpx-vp9, в Chromium работает штатно). Камера и плита у них общие, поэтому собаку между клипами не нужно ни сдвигать, ни масштабировать.

**Последовательность экрана выбора:**
`IDLE (цикл, сколько угодно раз) → выбор в любой момент → IDLE до f12 → SELECTED → RETURN_TO_IDLE → IDLE с индекса 1 (исходник f9), бесконечно`.
Последний кадр RETURN (r121) занимает место индекса 0 цикла (f8), поэтому после него — индекс 1. Пример плеера — `../selection_alpha_v1/player/` (каждый новый клип рисуется сразу с нужного кадра, без удержания и без пропуска первого кадра).

Не входят ни в одну последовательность (существуют, не менялись): FRONT_STAND (still с alpha), FIRST_START (alpha). Переход от выбора к гонке не проектировался.

## Как пересобрать
```

selection_alpha_v1/build_idle_loop.sh            # цикл IDLE 220 кадров из alpha f8–f118
python3 library_v1/make_library.py               # LIBRARY.json (хэши)
python3 library_v1/verify_library.py             # все проверки
node selection_alpha_v1/tools/browser_check.mjs OUT && python3 selection_alpha_v1/tools/analyse_frames.py OUT && python3 selection_alpha_v1/tools/analyse_realtime.py OUT
```
Сама нейросетевая alpha заново не пересчитывалась (1,5 ч). Воспроизводятся её входы (исходники, кадры, поправка тона) и все производные файлы.

## Ограничения
1. **SELECTED f91–f93 (0,08 с):** в смазе лап при прыжке есть сероватый полупрозрачный шлейф — цвет пола, смешанный со смазом в исходнике. Автоматическая чистка срезала бы лапы, поэтому не применялась.
2. Принятые ранее дефекты движения остаются как были:
   * SELECTED f97–f99 — смаз и «плавание» морды;
   * RETURN — два подмигивания подряд и смаз лапы r68–r72;
   * RETURN чуть мягче исходников (−4 % резкости на стыке).
3. В конце SELECTED уши в 10–20 px от верхнего края кадра 1276×720: при раскладке экрана выбора нужен запас сверху.
4. Масштаб экрана выбора (анфас, крупно) не связан с масштабом гоночных спрайтов 207×116. Переход выбора к гонке не проектировался.
5. Файл цикла IDLE при повторной сборке совпадает по кадрам, но не побайтно (особенность кодировщика VP9). Хэш в `LIBRARY.json` — у закоммиченного файла.
