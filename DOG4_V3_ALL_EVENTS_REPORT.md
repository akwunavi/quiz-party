# Bulldog №4 — V3 с BUTTERFLY, SNIFF_PEE и ROLL

Три диагностических пресета работают на пяти копиях одной собаки. Арена Visual Pass 3 и одобренные анимации сохранены. ROLL подключён как `RUN → STOP → ROLL → START → RUN`; отдельного RETURN и статичной паузы нет. Остальные пути: `RUN → STOP → BUTTERFLY → START → RUN` и `RUN → STOP → SNIFF_PEE → RETURN → START → RUN`.

## Длительности и задержки

| Событие | STOP | Действие | RETURN | START | Сумма клипов | Фактическая потеря относительно чистого бега |
|---|---:|---:|---:|---:|---:|---:|
| BUTTERFLY | 1,542 с | 5,042 с | — | 1,000 с | 7,583 с | 6,310–6,313 с |
| ROLL | 1,542 с | 6,042 с | — | 1,000 с | 8,583 с | 7,307–7,317 с |
| SNIFF_PEE | 1,542 с | 7,260 с | 2,721 с | 1,000 с | 12,523 с | 11,252–11,258 с |

Потеря рассчитана сравнением `crossing` у той же собаки с тем же профилем скорости при одном событии и при чистом беге. STOP и START продолжают продвижение с плавным торможением и разгоном; координата неподвижна только во время действия и RETURN. Дополнительных штрафов нет. Диапазон возникает из-за привязки STOP к безопасной фазе RUN (цикл 11–22) и сегментных вариаций скорости. По времени потери ROLL находится между BUTTERFLY и SNIFF_PEE.

Время от старта сценария. Последний кадр записи включает стойку всех пяти собак. Визуальная линия и контрольная точка согласованы: при `progress=1` задний контур корпуса доходит до линии, STOP заканчивается за ней. Место фиксируется в момент пересечения и после торможения не пересчитывается.

## Проверка и ограничения

- `node validate.mjs`: 15 финишей, непрерывность временных интервалов и прогресса, ровно один START после каждого события, полная длительность ROLL 145/24 с и кадр #144 перед START, отсутствие сдвига координаты во время ROLL.
- Chromium: все три пресета проиграны до конца, сброс очищает состояние, повторный запуск даёт те же времена; критических ошибок страницы нет.
- В игровом масштабе ROLL находится в своей дорожке. Общая геометрия кадра постоянна, выравнивания по нижнему пикселю каждого кадра нет. Стойка после ROLL совпадает с согласованной точкой входа START. Стыки STOP/ROLL/START сохраняют небольшие исходные различия освещения, наиболее заметные крупным планом.
- Бабочка как отдельный игровой объект в лаборатории не добавлена. Это пять одинаковых визуальных копий №4 и диагностические наборы событий; сценарии не предназначены для автоматического переноса в production.
