## Схема перехода

`RUN loop #22 → STOP #0–36 → BASE_STAND / ROLL_START → [ROLL: завалиться, коротко поваляться, подняться] → ROLL_END / BASE_STAND → START #0–39 → RUN prelude #0–10 → loop #11–22`

Индивидуальные PNG `DOG4_RUN_LOOP_22_REFERENCE.png`, `DOG4_STOP_00_REFERENCE.png`, `DOG4_STOP_36_REFERENCE.png`, `DOG4_START_00_REFERENCE.png` — контрольные кадры, **не** Start/End Frame для ROLL. Контактный лист `DOG4_ROLL_TRANSITION_SHEET.png` показывает их в последовательности и специально уменьшен для обзора; в Kling загружать два полноразмерных `DOG4_ROLL_START/END.png`.

## Совместимость и риски

STOP как вход пригоден на текущем масштабе гонки: он действительно тормозит после RUN #22, заканчивается устойчивой стойкой. По прошлой проверке RUN #22→STOP #0 имеет IoU силуэтов около 0,856 и небольшую смену фазы лап/головы, более заметную крупно. В новом пороговом сравнении STOP #36→BASE_STAND IoU около **0,981**, линия опоры отличается примерно на 1 px; средняя разница RGB внутри пересечения плотных областей около **7,6/255**. Поза близка, но светотень и детали морды могут мигнуть на крупном плане. START #0 относительно BASE_STAND имеет IoU около **0,982** при том же пороге и совпадает по цвету гораздо точнее (около 0,06/255). Разница IoU здесь зависит от порога alpha; измерения не доказывают бесшовность будущего ROLL.

Отдельный RETURN **не нужен по проекту клипа**, если ROLL сам поднимает собаку и действительно заканчивается в точном `DOG4_ROLL_END.png` с четырьмя опорами и неподвижным корпусом. Если результат Kling заканчивается лежащей/полувставшей собакой, с другой позой головы, ракурсом или заметно иным размером, простой cut к START не годится. Тогда сначала запросить исправленный ROLL или отдельный физически осмысленный RETURN, а не скрывать скачок crossfade.

Главные риски Kling: лишние/исчезающие лапы при повороте и подъёме; вращение всего тела вокруг вертикальной оси как на платформе вместо переката с переносом веса; разворот камеры или смена ракурса; дрейф масштаба и положения на холсте; изменение окраса, морды и ушей; финиш, лишь приблизительно похожий на BASE_STAND. Учитывая видимую ¾ стойку, дальняя задняя лапа частично закрыта корпусом; проверять четыре опоры по движению, не по одному итоговому силуэту. Проверять исходный фон и тень перед удалением фона; они не должны стать частью alpha-собаки.

## Длительность

**Минимум 4,5 с** (108 кадров при 24 fps). Ниже этого трудно сохранить перенос веса, читаемое короткое валяние, подъём и спокойную финальную стойку без ускоренной пластики.

**Рекомендация 5,5 с** (132 кадра при 24 fps); 5–6 с допустимы, если генератор ограничивает длину. Внутри 5,5 с: 0,0–0,5 с перенос веса; 0,5–1,5 с аккуратное опускание на бок; 1,5–3,1 с короткое валяние без полного оборота; 3,1–4,8 с подъём; 4,8–5,5 с точная финальная стойка. Не делать длинную неподвижную задержку. С существующими STOP 1,542 с и START 1,000 с вся цепочка займёт примерно **8,042 с** при ROLL 5,5 с. Это оценка для будущего сценария, не изменение Race Scenario V2/V3. Если нужно уложиться в 5-секундный полный эпизод V2, текущие клипы не помещаются.

## Готовое техническое задание для Kling

Использовать `DOG4_ROLL_START.png` как Start Frame и `DOG4_ROLL_END.png` как End Frame; обе картинки одинаковые, полноразмерные 1276×720. Целевая длина 5,5 с, частота 24 fps, если настройки Kling позволяют. Предлагаемый prompt:

> The same blue-gray French bulldog, same facial features, ears, coat, body proportions and three-quarter view facing screen right. Locked camera, fixed framing and scale, full dog visible throughout, same neutral beige background and even lighting. Starting from the supplied standing pose, the dog shifts weight naturally, gently lowers onto its near side, makes one short playful wriggle while lying down, then plants its paws, rises naturally and returns to the exact supplied standing pose on all four paws. End with a brief stable stand. Natural limb contact and weight transfer. No camera movement, zoom, platform spin, full-body 360-degree rotation, extra limbs, props, butterflies, floor markings, changing coat or changing character.

Сгенерированное видео **нельзя считать готовым ассетом** по двум одинаковым крайним PNG. На следующем этапе отдельно проверить непрерывное движение, суставы и опоры, совпадение последнего кадра с BASE_STAND, а затем удалить фон проверенным pipeline и проверить реальные стыки STOP→ROLL и ROLL→START. Текущий пакет только готовит исходные точки для такой генерации.
