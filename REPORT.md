## Стыки и композиция

- **SNIFF_PEE #228 → RETURN #12:** близкие стойки, пересечение силуэтов IoU 0,936; в крупном плане есть лёгкая смена взгляда и положения корпуса. Цифра не заменяет визуальную оценку.
- **Внутри RETURN:** фрагмент непрерывен. Примерно в #40–#76 передняя лапа долго остаётся поднятой и повторяет жест, иногда собака выглядит слегка зависшей. Это есть в исходном Kling MP4 и не вызвано удалением фона. На игровом масштабе дефект меньше, но не исчезает полностью.
- **RETURN #120 → START #0:** IoU 0,959; низ лап около y=692 против y=689, положение и размер близки. В крупном плане видна небольшая смена выражения глаз/морды.
- **START → RUN 11–22:** после START #39 использованы RUN alpha #0–#10 как исходный непрерывный переход (это следующие кадры того же RUN источника), затем повторены кадры #11–#22 рабочего loop. START, RUN и STOP не менялись.
- Геометрических поправок и кроссфейдов нет. Игровой preview использует фон утверждённого Visual Pass 3, прежний масштаб 0,23 и отдельную контактную тень в композиции; настройки игры не изменялись.

## Прозрачность и проверка

Фон удалён существующим локальным pipeline: BiRefNet General Lite ONNX, оптическое распространение масок, временное согласование и alpha matting. Результат — VP9 WebM с `alpha_mode=1`, 1276 × 720, 24 fps. Кадры #12, #32, #56, #72, #96, #120 просмотрены на белом, чёрном, зелёном и бежевом фоне: части собаки сохранены, исходный чёрный фон и водяной знак отсутствуют. На чёрном фоне крупно местами заметна мягкая кромка. Все итоговые MP4 — H.264 / yuv420p / 24 fps; полный ffmpeg decode прошёл без ошибок. В Chrome подтверждена реальная прозрачность WebM через canvas. Игровой MP4 проигран целиком в Chrome: `ended=true`, `currentTime=17,208 с`, 399 представленных браузером видеокадров. Это техническая проверка воспроизведения, не визуальное утверждение естественности движения.
