# Bulldog #4: кадры для RETURN

**Выбор:** `DOG4_RETURN_START.png` — настоящий прозрачный кадр SNIFF_PEE **#228** (9,500 с от начала); `DOG4_RETURN_END.png` — декодированный **первый кадр существующего `dog4-start-alpha.webm`**. Оба PNG: 1276 × 720, RGBA, в исходных координатах. Файлы `_NEUTRAL.png` — те же кадры поверх одинакового сплошного бежевого фона для подачи в Kling, если требуется непрозрачное изображение. Собака не масштабировалась и не перемещалась.

## Почему #228

- #208: голова и корпус ещё опущены после действия, стойка не завершена.
- #216: все лапы опущены, но подъём головы только что закончился.
- #224: устойчивая стойка, возможная точка.
- **#228:** более поздний устойчивый кадр; лапы стоят, линия опоры не меняется, короткая спокойная пауза после #224 уже видна. На соседних #225–#228 силуэт меняется мало (IoU каждого с предшествующим кадром ≥ 0,995).
- #230: начинается новый наклон головы и перенос веса (IoU с #229 падает до 0,973). #234 уже внутри этого движения; #240 — шаг, передняя лапа не стоит устойчиво. Обрезать на них означало бы оборвать движение.

Остаются исходные кадры SNIFF_PEE **#0–#228 включительно: 229/241 кадров, 9,542 с из 10,042 с**. Уходят #229–#240, последние 0,500 с: начало нового наклона корпуса и шага. Нюханье, поднятие и опускание лапы, движения языка сохранены.

## Геометрия и стыки

Первая граница точная: RETURN начинается копией SNIFF_PEE #228. Непосредственно перед ней собака стабилизируется, а не делает незаконченный шаг. Вторая граница точная по кадру: RETURN должен закончиться копией декодированного START #0. Его силуэт совпадает с SNIFF_PEE #0 с IoU **0,9977**; это та же практически общая стойка, но End Frame взят непосредственно из START WebM.

Между кадрами RETURN требуется настоящее движение: конец SNIFF имеет боковой ракурс, START — фронтальный три четверти. Силуэтные рамки соответственно **594 × 632** и **496 × 665 px**; центры силуэта (629, 404) и (636, 377), низ лап y=683 и y=689. IoU начальной и конечной поз всего **0,569** — простая склейка или поворот плоской картинки не подойдут. Нужны перенос веса, один или несколько небольших переступов лап, затем плавный поворот корпуса и головы к камере и фиксация всех четырёх лап на исходной линии земли. Ориентир длительности настоящего RETURN: **1,2–2,0 с**, исходя из объёма поворота и переступа, без подгонки под Race Scenario V2.

## Риски и требования к будущему видео

Основной риск — изменение морды/окраса, скольжение лап и скачок кажущегося размера при развороте. Камера, холст 1276 × 720 и линия земли должны оставаться неподвижными; не менять телосложение, сине-серый окрас, уши, глаза и пропорции. Финал должен прийти **точно** в выданный End Frame и спокойно удержать его перед START. Эти кадры являются заданием для будущего RETURN, а не проверкой ещё не существующего видео. Никакая генерация, монтаж RETURN, изменение START или игровой логики здесь не выполнялись.
