Крайние кадры SNIFF_PEE, RETURN и START не изменены. Стыки со STOP и RUN используют те же пары кадров, что и согласованный монтаж. Ускорение начальной стойки START 3× заметно лишь по микродвижениям головы при крупном просмотре; в игровом масштабе статичная задержка сокращена. В RETURN видимый ритм переступания несколько быстрее предыдущего Moderate, но каждая фаза веса и постановки лап сохранена. В SNIFF_PEE действие остаётся комедийно читаемым; язык и повторный подъём лапы сохранены.

### Проверка

- Два H.264 MP4 в yuv420p, faststart, без аудио: 1276×720 (крупно) и 1920×1080 (игровой масштаб Visual Pass 3). Оба полностью воспроизведены Chromium до события `ended` в 14,981 с.
- Три производных VP9 WebM 1276×720 имеют `alpha_mode=1`; Chromium декодирует SNIFF_PEE поверх ярко-зелёного фона с прозрачной областью за собакой. Исходные RGBA кадры используются без изменения маттинга и внешности.
- Время воспроизведения переменное (VFR): базовые кадры исходника 24 кадра/с, отдельные спокойные фазы идут быстрее. Потерь исходных кадров и промежуточной интерполяции нет.
- Масштаб, положение, линия земли и фон совпадают с предыдущими игровыми предпросмотрами. Активные стыки не изменились. Полностью бесшовной физической непрерывности между независимо созданными Kling-роликами это не доказывает; прежние мелкие различия поз и ракурса на границах остаются.

### Race Scenario V2: только анализ

Код сейчас использует событие SNIFF_PEE **5 с** (0,5 с DECELERATE, 0,3 с STOP, 3,6 с ACT, 0,6 с ACCELERATE), а `RaceRound` по умолчанию получает `raceSec=18`; `buildRaceV2` допускает максимум 60. Оптимизированное событие длится **12,523 с**: непосредственно SNIFF_PEE 7,260 с, согласованный STOP 1,542 с, RETURN 2,721 с и START 1,000 с. Текущий сценарий не может отобразить все эти клипы в 5-секундном событии без рассинхрона.

Время без продвижения не обязательно 12,523 с: при движении во время торможения и разгона потери времени составили бы приблизительно 7,260 + 2,721 + 1,542/2 + 1,000/2 = **11,252 с** на эпизод, или **22,504 с** при двух эпизодах. Это иллюстрация при условии симметричного профиля торможения/разгона, не действующий расчёт победителя.

Для будущего согласования разумно рассматривать базовую продолжительность порядка **75–90 с**, а верхнюю длительность показа с двумя длинными событиями — ориентировочно **100–120 с**. Это потребует отдельного решения об увеличении предела `raceSec`, сетке событий и лимите эпизодов. Две такие остановки дадут серьёзный спортивный штраф; без изменения генератора и пересчёта финиша нельзя гарантировать ни честный баланс, ни отсутствие заранее предрешённого проигрыша. Возможные варианты: не больше одного длинного SNIFF_PEE на собаку, более короткие DISTRACTED, ограничение суммы потерянного времени и/или удлинение базового забега. При будущей интеграции позиция должна вычисляться по фазам DECELERATE / STOP / ACT+RETURN / ACCELERATE, с нулевой скоростью при неподвижных фазах, без привязки расчёта победителя к видеочасам.

Production и Race Scenario V2 не изменены. Требуется визуальная оценка пользователя перед дальнейшим использованием.
