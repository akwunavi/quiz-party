# Bulldog #4 STOP — монтажный результат

## Решение

Из нового Kling MP4 собран STOP длиной **1,542 с** (37 кадров, 24 fps). Вход из RUN и выход в SNIFF_PEE сделаны прямой сменой кадров. На масштабе гонки (0,23 от исходного видео) движение выглядит пригодным для просмотра и оценки. Крупный план показывает небольшой скачок положения лап/головы на входе и мягкую кромку альфа-маски; считать склейку окончательно утверждённой без просмотра пользователем нельзя.

## Монтаж

- Исходник: `kling_20261012_VIDEO_A_single_c_5047_0.mp4`, 1276 × 720, 24 fps, 73 кадра, 3,042 с. SHA-256: `7de366cda9ca0990893fe5020fcb6b534be6f490c38c2b3d5b24148198cd5938`.
- Кадры источника имеют нумерацию с нуля. В финале взяты **#23–#54 подряд** (0,958–2,250 с по времени начала кадров), затем **#56, #58, #60, #62, #64** (до 2,667 с по времени начала последнего кадра). Точное соответствие дано в `final-frame-map.txt`.
- Первые 23 кадра удалены как лишний бег, кадры #65–#72 удалены как длинная неподвижная стойка. Лишь почти неподвижный конец #54–#64 ускорен примерно вдвое выбором каждого второго реального кадра. Ни масштаб, ни положение, ни форма тела не изменялись; интерполяции и кроссфейда нет.
- Вход: конец RUN #22 → STOP #23. Выход: STOP #64 → SNIFF_PEE #0. На сегментационных силуэтах IoU соответственно 0,852 и 0,990; эти числа помогают выбирать точки, но сами по себе не гарантируют визуально безупречный переход.
- Для сравнения проверены более короткий STOP #23–#54 и более поздний вход #27. Поздний вход даёт худшее совпадение с RUN; короткий вариант хуже совпадает с началом SNIFF_PEE из-за поворота головы.

## Альфа и проверка

Применён существующий локальный BiRefNet General Lite ONNX pipeline, оптическое распространение масок между опорными кадрами, временное согласование и маттинг краёв. Исходный пол и тень не перенесены. В `dog4_stop_alpha.webm` — VP9 с `alpha_mode=1`, 1276 × 720, 24 fps; Chrome декодировал видео и при выборке через canvas показал прозрачные, мягкие и непрозрачные пиксели. Все итоговые MP4 — H.264 / yuv420p / 24 fps и полностью декодированы ffmpeg без ошибок. Игровой preview использует фон утверждённого Visual Pass 3 и масштаб собаки 0,23; это композиционная проверка, не изменение игры.

## Оставшиеся вопросы

- На входе при крупном просмотре есть заметное изменение фазы лап и небольшое перемещение головы; на масштабе гонки оно менее заметно. В исходной тормозящей части нет явных двойных лап или крупного расплавления корпуса. На чёрном фоне в крупном плане местами видна мягкая светлая кромка.
- Действие STOP длится 1,542 с, а предусмотренные сейчас DECELERATE + STOP в Race Scenario V2 — около 0,8 с. Включить весь клип в это окно без изменения расписания нельзя. Для интеграции потребуется отдельное решение о времени переходов. Race Scenario V2 здесь не изменялся.
- Проверено техническое декодирование и ход времени в Chrome, а также просмотр ключевых кадров и масштаба гонки. Непрерывная художественная оценка должна быть подтверждена пользователем по приложенным видео. Это **кандидат на использование**, не утверждение production-интеграции.
