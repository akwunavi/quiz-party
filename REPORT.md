# Bulldog №4 — FINISH test без Kling

12 октября 2026. Использованы существующие материалы из подготовки `aa92582d57a55b428faf2210076ed1acc4e5584b`, согласованный STOP и ранее обработанные RGBA кадры. Исходные видео/PNG не перезаписывались.

## Монтаж

Экспорт: 24 FPS, H.264/yuv420p, faststart. Оба MP4 содержат 247 кадров / 10,292 с. Крупный план 1276×720, игровой масштаб 1920×1080.

| BASE_STAND до старта | #0–11 | точный исходный RUN #0 | 0,000–0,500 с | 0,500 с |
| START | #12–30 | согласованный монтаж alpha #21–39 | 0,500–1,292 с | 0,792 с |

| FINISH_STAND | #199–246 | `DOG4_BASE_STAND.png`, исходный RUN #0 | 8,292–10,292 с | 2,000 с |

В игровом предпросмотре собака действительно перемещается при анимированном RUN. Простой светлый вертикальный оверлей финиша нанесён поверх копии неизменённого фона Visual Pass 3. Центр силуэта пересекает x=1120 примерно на кадре #157 (6,542 с), за 0,208 с до первого кадра STOP. При торможении есть небольшой инерционный сдвиг позиции; логика игры не использовалась и не менялась. В крупном плане персонаж остаётся на месте, чтобы было удобно оценить работу лап и оба стыка.

## Качество стыков

**RUN alpha #22 → STOP #0 (6,750 с).** Это та же пара, которая ранее использовалась для события SNIFF_PEE. Силуэты перекрываются с IoU 0,856, масштаб и направление корпуса близки. STOP показывает приземление, снижение корпуса и тормозящие шаги; собака не продолжает бег после остановки. В крупном плане в один кадр меняется фаза передних и задних лап и слегка голова: центроид передних лап уходит примерно на (+8,9,+2,4) px, тогда как естественный соседний кадр RUN #22→#23 даёт примерно (−10,6,−12,6) px. Это небольшой монтажный стык, заметнее в крупном плане; в игровом масштабе резкой телепортации или смены размера не обнаружено. Стык не скрывался смешиванием кадров.

**STOP #36 (Kling #64) → BASE_STAND RUN #0 (8,292 с).** Маска последнего STOP и маска исходной стойки RUN #0 имеют IoU около 0,986. Центры четырёх областей опоры лап расходятся менее чем на 1 px, центр головы — примерно на 1–2 px; линия земли одна. Поза и ракурс соответствуют. При крупном просмотре возможна слабая смена светотени шерсти, деталей морды/глаз и контуров пальцев, потому что кадры происходят из двух Kling-роликов; средняя разница RGB в области собаки около 3,5 уровня из 255. В игровом масштабе скачок практически неразличим. Финальные 48 исходных кадров композиции используют ровно одну неизменную позу BASE_STAND, без START, движения лап или дрожания геометрии. Мелкие различия декодированных пикселей H.264 ниже 0,2/255 в среднем и относятся к компрессии.

## Решение

**STOP можно переиспользовать как FINISH_DECELERATE в текущем игровом визуальном масштабе**, после него напрямую показывать точную базовую стойку RUN #0. Отдельная FINISH-анимация на данном этапе не требуется для игрового предпросмотра. Ограничение остаётся на крупном плане: короткий скачок фазы лап на RUN→STOP и лёгкая смена освещения на STOP→BASE. Если эти стыки окажутся заметны и неприемлемы при пользовательском просмотре, понадобится отдельный FINISH, который начнётся в фазе RUN #62 и закончится точным RUN #0, с промежуточными тормозящими шагами и согласованным освещением; нынешние исходники тогда не заменять монтажными маскировками.

Оба MP4 проверены через ffprobe и воспроизведены в Chromium до `ended`. Ни RUN, ни STOP, SNIFF_PEE, RETURN, START, arena, Race Scenario V2, production или другие собаки не менялись. Merge/deploy не выполнялись.
