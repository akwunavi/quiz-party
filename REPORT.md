# Dog #4 — аудит цикла RUN

**Решение:** пригодного для безусловного утверждения цикла не найдено. Для дальнейшей визуальной проверки оставлены два диагностических кандидата со статусом **CONDITIONAL**: alpha #3–13 (предпочтительный по локальному шву) и #11–22 (альтернативный шаг). Ни один из них не проверен субъективным воспроизведением при 1× на проекторе; считать их принятыми нельзя.

## Краткая записка для решения

- Если нужен следующий тест, сравнивать только утверждённый RUN и два коротких варианта #3–13 и #11–22. Это диагностические повторы, а не готовое утверждение нового цикла.
- Если нужен гарантированно естественный беговой цикл на 15–30 секунд, текущих кадров недостаточно для такого вывода. Провести просмотр чистых видео при 1× и оценить, приемлемо ли частое повторение одинакового жеста.
- Не использовать как финальные циклы alpha #3–25 или #34–58. Первый кажется визуально правдоподобным в contact sheet, но меняет горизонтальное направление на стыке; второй имеет заметно худшее совпадение позы и шага.

## Следующие шаги и ограничения

1. Просмотреть чистые A и B при реальной скорости 1×, желательно 20–30 секунд; оценить контакт лап, ритм и повторяемость выразительных жестов. Эта проекторная проверка не выполнялась.
2. Использовать A только как предпочтительный локальный seam, B — как альтернативу. До приёмки оставить оба со статусом CONDITIONAL.
3. Если ни один короткий повтор не выглядит естественно при 1×, запросить недостающий RUN-материал вместо объявления победителя по метрикам.

Для такой генерации минимально требуется **новый RUN с несколькими полными шагами**, в котором сохраняются масштаб, ракурс ¾ вправо, линия земли и фаза тех же лап на начале и конце. Исходные source #43 и #53 — наиболее близкая локальная пара для reference Start/End Frames; source #51/#62 — альтернатива. Начальная и конечная позы должны совпасть не только по силуэту: движение корпуса и каждой видимой лапы должно продолжаться в прежнем направлении на соседних кадрах. Короткий «мостик» только между нынешними концами не устранит частый механический повтор 11–12 кадров.

Техническая проверка файла и измерение похожести кадров не равны художественной приёмке. Production и утверждённый RUN не менялись; генерация нового видео и деплой не выполнялись.
