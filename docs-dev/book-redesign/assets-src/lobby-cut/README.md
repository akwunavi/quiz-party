# Вырезанные ассеты лобби и таймера (13.11.2026)
Нарезано из листа, присланного ведущим (1400×850, RGB, фон ровный серый). Альфа восстановлена по фону: для house, lantern, snow_hill, fence, timer_face — заливкой от краёв; timer_ring — по расстоянию от цвета фона; smoke — мягкое облако (прозрачность строится по плотности, исходного альфа-канала у дыма нет, форма приблизительная).
Файлы: house, smoke, lantern, snow_hill, fence, timer_face (плашка таймера без цифр, с колокольчиком и бантом), timer_ring (золотое кольцо).
Ограничение: разрешение мало (house 325×212, lantern 115×363, timer_face 315×330) — на 1920×1080 и тем более 3840 будет мягко; для финала нужны исходники крупнее.
