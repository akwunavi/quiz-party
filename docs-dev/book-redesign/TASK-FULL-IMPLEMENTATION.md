# ТЗ: полноценное внедрение утверждённого дизайна темы «Книга» (13.11.2026)

Ветка: `claude/ny-book-redesign-20261112`. Старт работ — через 3 часа после получения (по просьбе ведущего).

## Решение
Концепция утверждена целиком: раздел «Актуальная версия» + бывший «На согласовании» просмотра https://claude.ai/artifact/M7CjLLptYX5oKopK86cAAW. «Архив / Отклонено» не использовать. Новых прототипов/концептов не делать — переносить в реальные компоненты. Гонки бульдогов уже задеплоены отдельно, не трогать. Приоритет: последние текстовые решения (единая свиток-модалка, уменьшенная; перелистывание А; без текста и плиток на сгибе в правилах и «Скрэмбле»).

## Подготовка
Проверить ветку и актуальный main (после релиза гонок, 7141ecf — прод 10.64); матрица «утверждённый экран → компонент → изменения»; общие компоненты; зависимости темы от общих компонентов. Затем сразу реализация, без отдельного согласования, если нет блокирующего противоречия (тогда — один конкретный вопрос). Посторонние изменения не переносить.

## Объём (25 экранов/состояний)
Лобби (с командами/без), подключение и QR, рандомайзер, заставки раундов, правила, вопросы без/с 1/2 (с вариантами)/3–4 картинками, «Отвечайте», раскрытие ответа, показ ответов команд, кроссворд, сопоставление, порядок, блиц, «120 секунд», «Скрэмбл», «3 попытки», «Угадай мелодию», «Своя игра», промежуточные результаты, перерывы/переходы, финал, все модалки и доп. состояния. Новых игровых этапов не придумывать.

## Book Core
Бордовая кожаная обложка, пергамент, центральный сгиб, золото, гирлянды, ели и венки, тёплый свет, согласованная типографика, общие отступы/безопасные зоны. Книга целиком на экране, в т.ч. 1899×905, без обрезки обложки; стол без пустых полос; одна адаптивная система, не отдельные реализации под разрешения.

## Ассеты
Использовать переданные (assets-src/hires и др.): домик, дым, фонарь, холм, забор, кольцо таймера (диска под цифры НЕТ — цифры динамические), декоративные книги, свиток, team-card, ели/венки/гирлянды, основной ассет книги. Не генерировать, не подменять, прозрачность и пропорции сохранять. Нет файла — назвать точное имя.

## Лобби/рандомайзер
Крупный Quiz Party, QR, домик с дымом, холм/фонари/забор, ели, гирлянды, команды справа, снег. 0/4/8/16/24 команд; без команд — без пустых карточек. Рандомайзер затемняет весь фон включая QR, по центру.

## Карточки команд
`team-card.webp`, растяжение без деформации краёв, имя — HTML-текст; цветной шарик там, где нужен цвет команды; статусы правильности; старые плитки не возвращать.

## Текст и изображения
Единая подгонка; длинные вопросы читаемы, без обрезки и без нечитаемого кегля; учёт отступов и сгиба. Текст обычного вопроса может пересекать сгиб; правила, плитки и игровые элементы — нет. 1–4 картинки с учётом ориентации/пропорций/объёма текста; без огромных подложек, мелких картинок, пересечений с таймером.

## Правила / Скрэмбл
Правила: название слева, правила справа; кроссворд: сетка слева, название+правила справа; ничего не пересекает сгиб; длинный текст — перестроить страницу. Скрэмбл: плитки и ячейки целиком слева, ответы команд справа, ничего на сгибе, крупные плитки, сохранить карточки/таймер/плашку; 6/8/16 команд.

## Мелодия / Своя игра
Утверждённые книги и плитки; сыгранные приглушены, без «Отыграно»; без отдельного этапа приёма ответов в мелодии; ОДИН компонент свиток-модалки на все модальные состояния обеих механик (ставки, выбор команды если есть, задание, трек, ответ, прочее), чуть меньше прежнего; без старой модалки и винила; ёлки не перекрывают книгу/управление.

## Таймер
Единый новый (кольцо + динамические цифры/прогресс по реальному состоянию); проверить: обычный вопрос, «Отвечайте», блиц, «120 секунд», Скрэмбл, музыкальные. Старую жёлтую розетку не возвращать.

## Прочее
«Отвечайте»: overflow=1 на 1280×720 — причина, не маскировка. Ответ: вопрос, правильный ответ, картинка, пояснение, ответы команд, статусы; 3 с автораскрытие и ручное сохранить; логику правильности не менять. Блиц, «120 секунд», «3 попытки» (буквенные ячейки), кроссворд/сопоставление/порядок — перенос оформления без упрощения механик. Финал: медали, появление от последнего к первому, затем полная таблица, при малом числе строки расширяются, 16 читаемо; расчёт и сортировку не менять.

## Перелистывание
Вариант А на реальных компонентах: при смене страницы, не на тиках таймера/ответов; без пустых кадров/вспышек/дублей; не блокирует ведущего; быстрые переходы; reduced-motion. Раскрытие ответа — отдельное событие. Снег, гирлянды, свиток сохранить.

## Адаптивность
1920×1080, 1899×905, 1366×768, 1280×720; графика ещё 2560×1440. Не решать уменьшением всего интерфейса; общие ограничения и безопасные зоны.

## Логика (не менять)
Показ всех вопросов перед ответами, управление с телефона, таймеры, автораскрытие 3 с + ручное, ставки/треки, баллы, порядок раундов. Кнопки управления на проектор не возвращать.

## Порядок
Аудит → матрица → Book Core → лобби и общие → вопросы/ответы/правила → спецмеханики → модалки → перелистывание и анимации → адаптивность → регрессия → сверка с макетами.

## Приёмка (что предоставить)
Единый просмотр на реальных компонентах; матрица «макет → экран»; сравнительные кадры; видео перелистывания А, раскрытия ответа, финала; адаптивность на всех разрешениях; tsc/eslint/vitest/build; список файлов; оставшиеся отклонения. Отдельно: проверено лично / автоматически / не проверено.

## Границы
Не трогать бульдогов, другие темы, редактор компоновки (не подключать к админке); не менять дизайн и логику; не генерировать ассеты; НЕ merge, НЕ deploy, НЕ повышать версию. Деплой «Книги» не разрешён.
