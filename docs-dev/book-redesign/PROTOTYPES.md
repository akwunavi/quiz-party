## 2. Технические решения

1. **Две сцены (PLAN §1.1, вариант A).** Стол — `Stage fit="cover"` (на весь экран). Книга, декор, снег и fx-слой — новый режим
   `Stage fit="contain"`: масштаб = `min(w/1920, h/1080)` = `--u` вёрстки, книга всегда целиком. Сдвиг contain-сцены в CSS —
   `--bk-ox/--bk-oy`; **все** отступы игровой вёрстки «Книги» = сдвиг + N·`--u` (иначе на 1899×905 вёрстка уезжала бы с разворота
   на 145 px). Лаборатория рисует прежний `BookWorld` (не тронут).
2. **Книга — CSS без растров:** бордовый кожаный переплёт (SVG-шум, тиснёная строчка), золотые уголки, срез стопки страниц (видимая
   толщина), пергамент с пятнами и затемнением к сгибу, центральный сгиб (тень + блик), закладка, свет лампы. Цвета — токены `--bk-*`.
3. **Декор — временные растры** (ели ×4 разной высоты, гирлянда с бантом, ветки-уголки, веточки) из присланных листов. Смонтированы
   всегда, плотность — `data-decor` (лобби — максимум, вопросы/ожидание/разбор — минимум) → только `opacity`, без перемонтажа (F13).
   Плоские флажки, плоские ели, домик и сугробы в бою больше не рисуются (остались только в лаборатории).
4. **Лампочки** — DOM-узлы по `lamps` из `MANIFEST.json` (автопоиск ярких тёплых пятен), мерцание CSS (`mix-blend-mode: screen`).
5. **Рецепты — списками селекторов** (`bk-card`, `bk-photo`, `bk-stamp`), без копирования больших блоков по механикам. Старые `--nb-*` — алиасы.
6. **Шрифты.** `--bk-serif` (PT Serif) — вопрос, повтор, ответ, буквы вариантов, имена команд, число таймера; `--bk-display`
   (Cormorant Garamond 700) — только заголовки. Замер: `.q-text` и `.q-recall` — PT Serif 700 normal (было 700 / **400 italic**), совпадение
   по всем снимкам (`fontMatch`). Ruslan Display остался в заголовке окна трека и в «Своей игре» (не переделывались).
7. **Рамка фото по форме картинки:** ячейка прозрачна, рамка — на `<img>`; прозрачные PNG — `data-alpha` (8×8 canvas после `onLoad`).
8. **Раскрытие A/B/C без новых состояний:** A = `show_answers && !reveal` — тот же `QuestionScreen` + штамп; B — анимация только на живой
   смене `reveal`; C — карточка ответа, картинка ответа отдельным элементом, картинки вопроса — компактная галерея (только `ny_book`).
9. **Мелодия:** книжка-подложка на каждую тему (число тем/треков из данных; проверено 3×4 и 4×6, длинное название на табличке),
   объёмные плитки, сыгранная — «перевёрнута»; пластинка вращается только по событиям `SharedPlayback` (`playing` → да; `pause/waiting/ended`/отписка → нет).
   Замер на `14-melody-snippet`: реальный mp3 получил `playing`, `.bk-vinyl.is-spin` = true на всех вьюпортах.
10. **Финал:** заголовок «Глава последняя. / Наши победители»; в шапке `Р1…Р8` + название раунда; медали `FinMedal` (и `AwardMedal` для `ny_book`);
    ничья — общее место и одинаковая медаль (`rankTeams` не менялся).

## 3. Сравнение с макетами — «совпало / отличается и почему»

### 3.1 Лобби (`mock-lobby.webp`; `01-lobby-*`)
- **Совпало:** бордовый переплёт с золотыми уголками; разворот со сгибом; лента «QUIZ PARTY» с хвостами; хвойная гирлянда с бантом и
  лампочками; QR на наклонной пергаментной карточке слева (код прямой); ели у краёв разной высоты; снег и огоньки.
- **Отличается:** нет домика с дымом, холма, забора и фонаря — в присланных листах их нет, новых генераций не делали (вместо них
  ветки-уголки и вторая малая ель); правая страница в макете пустая — у нас там команды (решение ведущего); лента заголовка плоская
  (в макете — объёмная свёрнутая с золотым кантом) — ассета ленты нет.
- **Раскладка:** 0 — «Ждём первую команду» + подсказка (без пустых слотов); 1–4 карточки; 5–8 список; 9–16 две колонки; 17–24 три;
  больше — три колонки по 8 и «+N ещё» (только если не помещается). Номер у каждой команды. Бумага: QR нет, слева крупное приглашение.

### 3.2 Правила, кроссворд (`02-rules`, `03-crossword-intro`)
- **Совпало:** номер раунда закладкой, название крупно (display), правила на пергаментных карточках с золотой кромкой.
- **Отличается:** длинное название больше не режется; сетка кроссворда прежняя (клетки перекрашены под бумагу); бейдж «РАУНД» над номером
  частично перекрыт — см. §6.

### 3.3 Вопрос (`04`–`08g`)
- **Совпало:** текст на пергаменте; картинки «фото на странице» с ровными полями по форме картинки; 4 картинки 2×2; буквы вариантов —
  красные кружки книжным шрифтом; декор в игре — только веточки в нижних углах вне безопасной области.
- **Отличается:** вопрос с одной картинкой — сплит «лист в линейку + фото» (прежняя раскладка, перекрашена); у одиночной картинки в сплите
  `data-alpha` нет (там голый `<img>`, не `FitImg`).

### 3.4 Ожидание ответов (`09-answer-time`, `09p`)
- **Совпало:** розетка-таймер, чипы команд с полосой цвета. **Отличается:** «ОТВЕЧАЙТЕ!» — display-шрифтом без неоновой рамки; отдельного
  макета «часы + счётчик» нет.

### 3.5 Раскрытие (`10-recall-A`, `11-*`, `12-*`)
- **Совпало (с ТЗ):** A идентичен вопросу; карточка ответа с золотой кромкой; колонка ответов команд вмещает 8 (имя мелко, ответ крупно;
  10+ — плотный режим); пояснение 400 знаков целиком; картинка ответа — отдельным элементом, картинки вопроса — компактной галереей.
- **Отличается:** анимацию раскрытия на снимке не видно (только на живой смене, снимок — конечный кадр); картинка ответа в `12-*` мелковата
  (получает остаток высоты карточки при длинном вопросе и пояснении) — §6.

### 3.6 Мелодия (`13-*`, `14-melody-snippet`)
- **Совпало (с ТЗ):** книжки-категории по числу тем, объёмные номерные плитки, существующие состояния. **Отличается:** окно трека —
  прежняя модалка-вкладыш с проигрывателем сверху; заголовок окна — прежний Ruslan.

### 3.7 Итоги (`mock-final-standings.webp`; `15-*`, `16-award-1`)
- **Совпало:** «ИТОГИ ИГРЫ» со звёздочками, крупный тёмно-синий заголовок, ели и гирлянда с бантом, медали у мест, 1-е место на бордовой
  плашке, итог в золотом кольце (V1). **Отличается:** заголовок «Глава последняя. Наши победители» (решение ведущего); есть бронза; в шапке —
  названия раундов; дробные через точку (`42.5`, как в коде); нет нижней ветки с шишкой и фонарей (ассетов нет).

### 3.8 Три варианта финала (`?bkfin=1|2|3`, сцены `15-finale-{8,16}[-v2|-v3]`)
- **V1 «Плашка»** (по умолчанию): лист в двойной золотой рамке, 1-е место — бордовая плашка, итог в золотом кольце.
- **V2 «Венок»**: заголовок в хвойных полувенках, строки — отдельные карточки без общей рамки, 1-е место — золотая карточка со свечением.
- **V3 «Грамота»**: бордово-золотая рамка-грамота, разлинованные строки «книги учёта», 1-е место — красное имя и двойная золотая черта.

## 6. Расхождения и предложения

1. Нет домика/дыма/холма/забора/фонаря/нижней ветки с шишкой и объёмной ленты — нужны исходники (листы их не содержат).
2. Картинка ответа в `12-revealed-answer-media` мелкая: блок ответа делит высоту между повтором вопроса, картинкой и пояснением 400 знаков.
   Предложение: при `media.answer` ставить картинку и пояснение в две колонки внутри карточки (этап 4, Б4).
3. Бейдж «РАУНД» над номером на `02-rules` перекрыт гирляндой по верху (0.3 высоты надписи) — сдвинуть бейдж или поднять гирлянду на этом экране.
4. Заголовок окна трека мелодии и «Своя игра» — ещё в Ruslan (в баре читаются «Л→Λ»): перевести на `--bk-display`/`--bk-serif` (Б5/Б8).
5. Ели `tree-2`/`tree-4` вырезаны из заходящих друг на друга крон по близости — у `tree-4` слева срезан кусок лапы; для финала нужен лист без перекрытия.
6. Лампочки найдены автоматически: часть — блики на шишках; в финальных ассетах разметить вручную.
7. 17+ команд: цвета команд повторяются (24-цветная палитра) — номер на карточке различает.
8. Выбрать один вариант финала (V1/V2/V3), убрать флаг `?bkfin`.
