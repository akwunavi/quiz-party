# Макеты «Книги» 28.11.2026: промежуточные результаты, финал, «вспоминаем игру»

Только макеты (игровой код не менялся). Холст 1920×1080, статичные HTML+CSS на настоящих ассетах `public/ny-book/*` и шрифтах темы. Подложка — снимок настоящего пустого разворота (`assets/bg-*.jpg`, снят `tools/capture-bg.cjs` на стенде).

Кадры — `results/*.jpg`, исходники — `*.html` (генерирует `tools/build-mockups.cjs`, общий стиль `mock.css`). Пересборка: `node tools/build-mockups.cjs && NODE_PATH=/opt/node22/lib/node_modules PLAYWRIGHT_BROWSERS_PATH=/opt/pw-browsers node tools/shoot.cjs <каталог PNG>`; замеры — `measure.json`.

Выходы за безопасную область: только строки-подписи (рамка строки на 3–5 px выше 134, сам глиф ниже) и закладка «7» (по замыслу выходит из верхнего обреза страницы). Заход на сгиб (930…990) — только у намеренно центральных «героев» (заголовки, победитель, свиток-слайд); в таблице А сгиб свободен.
