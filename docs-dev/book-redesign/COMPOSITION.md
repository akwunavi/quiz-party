# Книга: единая композиция (ТЗ «единая композиция», шаг 2)

Статус: НА СОГЛАСОВАНИИ. Игровая логика не тронута.

## Сцена
Единица `--u = min(w/1920, h/1080)`, `Stage fit="contain"`. Все размеры — `calc(N * var(--u))`.

## Зоны (в единицах сцены 1920×1080)
| зона | границы | кто занимает |
|---|---|---|
| рабочая область | x 250–1670, y 208–(1080−SAFE.b) | весь контент экранов |
| верхняя полоса | y 56–208 | метка раунда слева, таймер справа (слот 150×150, x 1520–1670), заголовок |
| слот таймера | 150×150, `TIMER_D`, `TOP_Y=56` | только BookTimer |
| декор-зоны | x<250 и x>1670, низ | ёлки (`dense`), гирлянда сверху, дом/забор (лобби) |

Константы живут в `src/ny/book/adaptive/safeArea.ts` (`TOP_BAND=208`, `TIMER_D=150`, `TOP_Y=56`); тест `bookAdaptive` стережёт, что слот таймера не пересекает рабочую область.

## Плотность декора (`bookDecor(phase)`)
- лобби — редкий (пейзаж слоями: холм, дом, дым, фонарь, забор);
- вопрос, показ ответов, ответ, итоги — плотный (две ёлки);
- остальное — средний.

## Общие компоненты
`BookTeamCard` (карточка команды, `team-card.webp`, шарик цвета команды), `BookTimer`, `BookNote`, `BookMelodyCovers` (обложки: мелодия и «Своя игра»), свиток-модалка (`bk-unroll`, `scroll.webp`), сетка 4+4 для «120 секунд».

## Правила
1. Ни один элемент не выходит из рабочей области и не заходит в слот таймера.
2. Текст вписывается `useFitText` (только уменьшение); `!important` на font-size запрещён.
3. Цвета — через переменные темы; ассеты низкого разрешения не растягиваем (дом, фонарь, циферблат — нужны исходники крупнее).
4. `prefers-reduced-motion`: анимации (снег, свиток) отключаются селекторами не слабее базовых.
