## 3. «Угадай мелодию» строго по коду (`lib/melody.ts`, `MelodyRound.tsx`)
Доска: `idle` (3–4 темы × треки, использованные `played`) → рулетка `spinning` (подсветка прыгает) / ручной выбор → модалка (`mel-modal`) поверх доски:
1. `listen` — «СЛУШАЕМ 1 СЕКУНДУ…» (таймера в модалке нет — убран осознанно);
2. `bidding` — «ЗА СКОЛЬКО СЕКУНД УГАДАЕТЕ?», команды ставят секунды 2–10 (подсказка 2–5 → 2 балла, 6–10 → 1 балл), список ставок;
3. `bids` — ставки собраны, очередь команд, у первой метка «ИГРАЕТ»;
4. `snippet` — играет отрывок на выигравшую ставку (пассивный экран, подсвечена играющая команда);
5. `answering` — отвечает первая команда (`turn 0`); дедлайн-счётчик `mel-count` есть в этой стадии (поле `deadline`), поле ответа/неверный;
6. `passed` — ход второй команде, трек слушает целиком, 0.5 балла;
7. `reveal` — ответ и кто забрал баллы / «никто не угадал» (`wonTeam` пусто); 8. `done` — назад к доске.
Выдуманных экранов («Принимаем ответы» и пр.) и старого общего таймера нет и не будет добавлено. В «Книге» уже есть прототип `Vinyl` (пластинка крутится по `usePlaybackActive`).
