## 3. Что можно использовать повторно
* **Если пользователь выберет пятнистую чёрно-белую Луну (вариант A):** стойку анфас из RUN vs2 #8–#12 — как основу FRONT_STAND (через правку картинки, чтобы получить чистую студию без водяного знака) и бег vs2 #41–120 + alpha v2 — как **кандидат** RUN. Цикл RUN в нём ещё не найден, фон меняется посреди клипа, есть зелёный рефлекс — пригодность решится проверкой цикла и рядом с другими собаками. Экономия — одна генерация RUN.
* **Если выбран другой окрас:** старые клипы не годятся (другая собака). Используются только как образец пропорций и стиля.
* Методы, инструменты и лаборатории других собак (конвейер alpha, поправка тона, `selection.mjs`, контракт V3, проверка пакета Пупса) — повторно, без изменений.

## 4. Обязательные требования (из контрактов и опыта)
* **Ракурс.** Экран выбора — анфас, лицом к зрителю, взгляд в камеру, вся собака в кадре с запасом над ушами (на прыжке SELECTED — тоже). Гонка — строгий профиль вправо, камера на уровне корпуса, как у №1–№4.
* **Размер и якорь.** Полный кадр 1276×720. Гонка: в стойке лапы на строке ≈ 684 px (95 % высоты), высота собаки и центр по X — как у Пупса / Фрэнка в RACE_STAND (сверяется рядом в одной лаборатории до приёмки). Экран выбора: высота собаки и линия лап — как у G0 Пупса (лапы ≈ 684 px). Все клипы одного экрана — одним масштабом, без поклипового сдвига.
* **Первый / последний кадр.** Каждый клип начинается и кончается своей стойкой (FRONT_STAND или RACE_STAND), кроме RUN (цикл) и START / STOP (стойка ↔ бег). Генерация — Kling first + tail по утверждённой картинке стойки.
* **Длительности.** START ≤ 1,0 с; STOP ≤ 37 кадров; BUTTERFLY ≤ 121; ROLL ≤ 145; SNIFF_PEE ≤ 7,26 с, RETURN ≤ 2,72 с (или SNIFF_PEE + RETURN одним клипом ≤ 9,98 с, как у Фрэнка); RUN — цикл 12 кадров = 0,5 с.
* **Alpha.** VP9 `alpha_mode=1`, тот же конвейер, проверка на 4 фонах и крупно. Студия однотонная серая (не зелёная, не белая): белой шерсти нужен контраст, зелёный даёт рефлекс.
* **Бабочка.** В игровом alpha-клипе бабочки нет. Реакция Луны — взгляд и движение головы / лап за невидимой целью; если Kling нарисует бабочку, она вырезается маской (как у Пупса).
* **Стыки.** Без кроссфейдов. Стойка ↔ клип — сдвиг центра ≤ 1 px, линия лап ±1 px в полном кадре.
