# Луна (№5) — план производства (02.11.2026)
Каждый шаг с Kling — **только по отдельному слову пользователя**, по одной попытке; следующий шаг — после приёмки предыдущего. Цены — по журналам Пупса, Фрэнка и Зефира (Kling v3.0, 720p, без звука: 5 с видео ≈ 30 кредитов, 10 с ≈ 60; правка картинки ≈ 20) и могут измениться. Повторы оценены по истории: SELECTED у Пупса — 4 попытки, ROLL у Зефира — 3, STOP у Зефира и Фрэнка — 2–4.

Для всех клипов одинаково:
* **кадр:** 1276×720, 24 к/с, однотонная серая студия, мягкая тень, камера неподвижна, вся собака в кадре с запасом над ушами;
* **first / tail:** утверждённая картинка стойки (G0 или RACE_STAND), чтобы клип начинался и кончался ею;
* **alpha:** общий конвейер (`bulldog1-frenk/alpha_pipeline`, BiRefNet-lite + matting) → VP9 `alpha_mode=1`; поправка тона по статичному фону к картинке стойки; проверка на белом / чёрном / зелёном / бежевом и крупно (уши, морда, язык, лапы, просветы между лапами, белая шерсть у пятен);
* **стык:** без кроссфейда; стойка ↔ клип — центр ≤ 1 px, лапы ±1 px; пиксельная разница на стыке ниже 90-го процентиля обычного шага;
* **промпт:** только то, что должно быть, без перечня «нельзя»; движения — как у принятых собак (один подскок обеими передними лапами, а не прыжки с лап на лапы).

| шаг | что | вход | Kling | контрольная точка |
|---|---|---|---|---|
| **0** | выбор внешности | эскизы `stage1/sketches/` | 0 (или 1–3 концепта ≈ 20–60 по желанию) | пользователь выбирает окрас и черты |
| **1** | **FRONT_STAND G0** — картинка анфас | старый кадр #9 или эскиз выбранного окраса | 1 картинка ≈ 20 (+20 на повтор) | пропорции бульдога, окрас, глаза в камеру, уши с запасом, лапы на одной линии ≈ 684 px; ряд рядом с №1–№4 — «другая собака, тот же мир» |
| **2** | **RACE_STAND** — картинка в профиль вправо | G0 (личность) + камера и масштаб стоек №1–№4 (только как ориентир кадра, без переноса позы) | 1 картинка ≈ 20 (+20) | строгий профиль, рост и линия лап как у Пупса и Фрэнка в спрайте 207×116; пятна совпадают с G0 по смыслу. **После шагов 1–2 внешность заморожена** |
| **3** | **IDLE** | first = tail = G0 | 1 видео 10 с ≈ 60 | живое ожидание без прыжков и разворотов, несколько возвратов в стойку (ворота); alpha, тон, карта задержек выхода (цель ≤ ≈ 3,6 с, как у Пупса) |
| **4** | **SELECTED** | first = tail = G0 | 1 видео 5 с ≈ 30; ожидаемо 1–3 попытки (30–90) | радость на морде + один подскок обеими передними лапами; кончается в G0 → RETURN_TO_IDLE не нужен. Если не кончается — **4b** RETURN_TO_IDLE, 1 видео ≈ 30 |
| **4c** | лаборатория экрана выбора | IDLE, SELECTED | 0 | цепочка IDLE → ворота → SELECTED → IDLE f1, 3 цикла, ≥ 8 моментов выбора, 4 фона, карточка обрезает по верху (как у Пупса) |
| **5** | **RUN** | вариант A: проверить старый vs2 #41–120 + alpha v2; иначе first = RACE_STAND, бег вправо на месте, камера ведёт | 0 при A и удачной проверке, иначе 1 видео ≈ 30 | найти цикл 12 кадров (0,5 с) без скачка; 10 повторов в масштабе игры рядом с Пупсом; рост и высота как у соседей |
| **6** | **START** | first = RACE_STAND, tail = кадр цикла RUN | 1 видео ≈ 30 | игровой отрезок ≤ 1,0 с; конец входит в цикл RUN без скачка |
| **7** | **STOP** (= FINISH) | first = кадр RUN перед STOP, tail = RACE_STAND | 1 видео ≈ 30 (ожидаемо до 2 попыток) | игровой отрезок ≤ 37 кадров; фаза входа = кадр RUN перед STOP (тест T4); лапы не «едут» после остановки |
| **7c** | лаборатория бега | BASE, START, RUN, STOP | 0 | BASE → START → RUN → STOP → BASE во всех 5 скоростных категориях V3, рядом с Пупсом |
| **8** | **SNIFF_PEE + RETURN** | first = tail = RACE_STAND | 1 видео 10 с ≈ 60 (или 2 × 5 с) | нюхает → метит → возвращается в стойку; вместе ≤ 9,98 с, разметка окон SNIFF_PEE 7,26 + RETURN 2,72; задняя лапа естественно |
| **9** | **ROLL** | first = tail = RACE_STAND | 1 видео ≈ 30 (ожидаемо до 2) | валяется на спине и встаёт; ≤ 145 кадров + добивка стойкой; голова всё время в кадре (у Зефира v1 «без головы») |
| **10** | **BUTTERFLY** | first = tail = RACE_STAND | 1 видео ≈ 30 | **реакция**: смотрит вверх, следит, тянется / клацает; ≤ 121 кадр + добивка; если Kling нарисует бабочку — вырезать маской, в игровом клипе её нет |
| **10c** | лаборатории действий | 8–10 | 0 | каждое действие в V3 после STOP и «в начале трассы», 5 категорий; затем все события рядом с №1, №2, №4 |
| **11** | **интеграционный пакет** | всё принятое | 0 | атлас 207×116, контракт V3 `dog5`, `MANIFEST.json`, модуль выбора, проверки P3 (T1–T4, T8–T10 PASS), как у Пупса |
