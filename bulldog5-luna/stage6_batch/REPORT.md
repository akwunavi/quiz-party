## 2. Генерации и кредиты

## 3. START из RUN G1 (без Kling) — `start/`, `contract/`
* В клипе RUN подряд: стойка #0–#21, подсед #22–#27, толчок #28–#30, галоп, цикл #60–#71.
* **Решение — механизм Фрэнка (`lead` + `spillFromStart`)**: START-таблица = #18…#59 один к одному, затем цикл; первые 7 кадров (#18–#24, почти неподвижная стойка и начало подседа) показываются **до** физического старта, толчок #28 — уже после него (`releaseIdx 10` ≥ lead 7). Ни одна фаза не выброшена, ничего не ускорено.
* Проверено **неизменённым** валидатором P3 и прогоном 2000 гонок V3 (`contract/check_contract_result.json`): `derivedLead = 7`, перед **каждой** из 23 012 остановок и финишей стоит RUN #71, STOP начинается своим первым кадром; START всегда начинается с #18 за 7 кадров до старта.
* Отвергнутые варианты (`start/DOG5_START_from_RUN_G1_SA_vs_SB_x1realtime.mp4`): S-A — уложить #18–#48 в 24 такта: подсед сжат втрое, рывок 12,5 при галопе ≈ 9; S-B — сдвинуть цикл на #52–#63: START 1:1, но не совместим с уже сгенерированным STOP (вход #72 продолжает цикл #60–#71).
* Цена lead: последние 7 кадров окна каждого действия заняты START, поэтому тело действия ≤ окно − 7 (− хвост STOP).

## 4. STOP и фазы с RUN — `stop_check.json`, `stop_shift.json`
* Вход: Race V3 показывает перед STOP последний кадр цикла (#71) — это проверено прогоном; первый кадр STOP-генерации — #72 исходника RUN (на входе разница 0,54). Стык RUN #71 → STOP f0 = 8,68 — ровно как обычный шаг #71 → #72 (8,59).
* Kling тормозит медленно: галоп до ≈ #34, стойка к #64–#68. Окно движущейся части — ровно 37 кадров. **Вырезан один целый повторяющийся шаг #8–#17** (шаг галопа здесь 10 кадров): шов #7 → #18 = 7,6 при обычном шаге 12,9. Движение: #0–#7 + #18–#46 = 37; хвост #47–#68 = 22 кадра — Луна дотормаживает и встаёт уже в окне стойки/действия (как хвост STOP у Фрэнка). Конец хвоста → RACE_STAND: 0,68; масштаб и лапы в конце совпадают с RACE_STAND (центр 648,5 / 648,2, лапы 685, рост 664).
* **Сдвиг корпуса**: камера Kling держала Луну неидеально — корпус уезжает вперёд до 110 px кадра и возвращается на стойке. В V3 это читалось бы как рывок вперёд и откат назад на месте (≈ 16 px игры). Посчитан **shift-массив** (как у STOP V4 Фрэнка): на входе 0 (стык с бегом не трогается), к хвосту — полная стабилизация; применён в диагностической цепочке. В общей сборке его нужно передать движку как часть контракта.
* Ограничение действий после STOP (с lead 7 и хвостом 22): BUTTERFLY ≤ 92, ROLL ≤ 116, SNIFF_PEE + RETURN ≤ 210 кадров. Все текущие отрезки входят (валидатор P3: ok).
