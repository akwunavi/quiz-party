# Луна — бесплатная проверка RETURN_TO_IDLE (08.11.2026)
**Итог: естественный возврат из конца SELECTED в FRONT_STAND из имеющихся кадров собрать нельзя.** Нужна одна генерация — ТЗ в `RETURN_TO_IDLE_KLING_TZ.md` (не запускалась).

Лист с кадрами — `RETURN_free_check_sheet.png`, замеры — `return_free_check.json` (средняя разница кадров 319×180, 0–255; обычный шаг между соседними кадрами: медиана 0,88, 90-й процентиль 4,19).

## Конечная поза SELECTED
s97–s120 — собака стоит, широко улыбается с зубами, голова чуть опущена и подана вперёд. От FRONT_STAND отличается на 9,9.

## Что пробовал
| подход | что получается | вывод |
|---|---|---|
| прямой переход в IDLE | ближайший кадр IDLE — f58 (8,7, прищур с поднятой лапой) | скачок вдвое больше заметного шага — нет |
| частичный обратный монтаж SELECTED (как RETURN D у Рокки) | на конец похожи только s85–s89 (3,8–4,6) — это приземление после подскока. Дальше назад — сам подскок задом наперёд (s80 → s69: собака «взлетает» с лапами вперёд и садится назад), присед s68–s57, потом закрытие улыбки s30 → s21 и встряхивание головы s19 → s13 | **неестественно**: обратный прыжок читается сразу, это не «успокоилась», а перемотка. У Рокки возврат шёл через спокойные кадры; у Луны между улыбкой-концом и стойкой спокойного участка нет |
| спокойная улыбка SELECTED s32–s56 как мост | ближайший кадр IDLE к ней — f31 (5,4), к концу SELECTED она тоже не близка | скачок — нет |
| укоротить SELECTED до s56 (без подскока) | теряется главное — подскок | не годится |
| кроссфейд | запрещён правилами — маскирует плохой стык | не рассматривал |

## Почему у Рокки получилось, а у Луны нет
У Рокки финальная поза SELECTED была близка к кадрам спокойной части, и обратный ход шёл через движения, которые читаются в обе стороны. У Луны путь от широкой улыбки к стойке внутри исходников проходит только через подскок и приседание — их обратный ход заметен.
