# Луна (Bulldog №5)
Технический id — `dog5`, имя — «Луна». Самостоятельный персонаж, не связан с Пупсом (№4, `dog4`). Цель — полная библиотека анимаций, совместимая с Race V3 и экраном выбора, по образцу принятых пакетов №1–№4.

* `STATUS.md` — где мы сейчас.
* `DECISIONS.md` — решения пользователя.
* `stage1/AUDIT.md` — аудит материалов №5 и уроки четырёх собак.
* `stage1/APPEARANCE_OPTIONS.md` + `stage1/sketches/` — варианты внешности (эскизы окраса) на согласование.
* `stage1/LIBRARY_PLAN.md` — перечень состояний.
* `stage1/PRODUCTION_PLAN.md` — последовательность производства, контрольные точки, оценка Kling.
* `stage1/RISKS.md` — риски.
* `stage1/KLING_PROMPT_DRAFTS.md` — черновики промптов (не отправлялись).
* `stage1/evidence/` — контактные листы старых материалов №5.
* `stage1/tools/` — скрипты эскизов.
* `sources/` — исходники Kling от пользователя (IDLE, SELECTED, RUN v1 / vs2), не меняются.
* `stage2/` — этап 2: FRONT_STAND, IDLE (варианты A / B), SELECTED alpha, проверка RETURN_TO_IDLE, проверка RUN; отчёт `stage2/REPORT.md`.
* `stage3_run/` — выбор RUN-петли: 5 вариантов из исходника в одном ролике рядом с Фрэнком, Зефиром и Пупсом; отчёт `stage3_run/REPORT.md`.
* `stage4_race_stand/` — RACE_STAND G1 (1 генерация), сравнение с соседями, заготовка RUN; `KLING_LOG.md` — журнал генераций.
* `stage5_run/` — RUN G1 (1 генерация): исходник, alpha, циклы, сравнение с соседями, старт из стойки; отчёт `stage5_run/REPORT.md`.
