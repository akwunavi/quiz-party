# Луна (№5) — решения пользователя
1. (02.11.2026) Пятая собака — **Луна**, самостоятельный персонаж №5 (`dog5`), не путать с Пупсом №4. Цель — полная библиотека, совместимая с Race V3. Сначала утверждается внешность, затем анимации. Платные генерации — только по отдельному согласованию.
2. (08.11.2026) **Внешность Луны остаётся как у существующего №5**: белая с чёрно-серыми пятнами, тёмное пятно вокруг глаза, тёмная маска (вариант A). Эскизы B–D не используются. Пользователь передал исходники IDLE и SELECTED и повторно — RUN v1 / vs2; все сохранены в `sources/` как исходники Луны.
3. (08.11.2026) Максимально использовать четыре существующих исходника, без новых платных генераций на этом этапе: FRONT_STAND из f0, IDLE и SELECTED из исходников, RETURN_TO_IDLE — сначала проверить монтаж, RUN — проверить vs2 + alpha v2.
4. (08.11.2026) Предварительно: FRONT_STAND f0 — рабочая стойка (окончательно — в общей сцене выбора); IDLE — основной кандидат A (4 с), B сохраняется как альтернатива; SELECTED с подскоком — основной кандидат, уши — компоновкой карточки Пупса; RETURN_TO_IDLE монтажом не собирается, ТЗ сохранить, Kling не запускать; вытянутый галоп допустим, метод 10→12 повтором кадров не утверждён — нужен выбор качественной петли.
5. (08.11.2026) Принят вывод: RUN vs2 (цикл 10 кадров) не подходит к 12-кадровому контракту без дефектов; интерполяция и повтор кадров прекращены. Разрешено: одна генерация картинки RACE_STAND; RUN — только после приёмки стойки, с проверкой периода и без автоматических повторов. IDLE A, SELECTED, FRONT_STAND — рабочие; RETURN_TO_IDLE, START, STOP, SNIFF_PEE, ROLL, BUTTERFLY пока не генерировать.
