## Маршрут (координаты слоя, parallax 0.92; объекты не наезжают, между крупными ≥ 300 px гор)
трибуна A (250) → ель (1465) → **деревня 1** (1880) → ель (2950) → трибуна B (зеркальная, меньше; 3162) → ель (4400) → **деревня 2** (4950) → ель (6070) → трибуна C (6650) → ель (7800) → трибуна D (8450, зеркальная). Окно 22 с видит только первые ≈4 000 px; остальное — для других окон/длинной гонки.

## Что нужно нарисовать (две картинки, одна платная генерация каждая, ≈2 кредита по опыту трибуны)
1. **village_2.webp** — RGBA ≈1920×800, тот же свет (закат слева-сзади, тёплые окна), боковой ракурс, ДРУГОЙ силуэт: длинная низкая линия домов/павильонов с рынком и катком-павильоном, плоские и двускатные крыши разной высоты, **без часовой башни**, гирлянды, вымпелы. Собственный забор внизу — желательно без (иначе гасим маской `fadeBottom`).
2. **spruce_set.webp** — лист из 4 модулей по горизонтали, в каждом 2–3 крупные заснеженные ели разной высоты, тёплые лампочки на нижних ветвях, прозрачный фон, низ на одной линии.
Промпты — по образцу `KLING_CROWD_PLAN.md` (кадр 21:9, `kling-image-v3_0_omni`, 2K), вырезание фона — `scripts/arena/key_sky.py` + `check_layer.py village_2 / spruce_set`.
