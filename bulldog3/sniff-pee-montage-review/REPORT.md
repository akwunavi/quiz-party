# Рокки №3 — SNIFF_PEE, монтаж из Kling clip 1

**Статус:** один кандидат для пользовательской визуальной приёмки. Без Kling, alpha, атласа и игровой лаборатории. Утверждённые RUN, STOP, RACE_STAND, RACE_START, другие собаки и модель Race V3 не менялись.

Отчёт Claude `RESULT_REVIEW.md` в той же ветке: стойка #0–9, нюх #21–45, подъём головы #45–51, стойка #54–78, подъём задней лапы #78–96, удержание #96–120.

- Конечная [`RACE_STAND 1276×720`](assets/DOG3_CLIP1_FIRST_RACE_STAND_1276.png) взята без изменений из той же ветки; это подготовленная копия утверждённой стойки Рокки, SHA-256 `93aa00b522605170a9268079dd7fd8f35bcd757f2d2c730b8ba1540e24c7014f`.

## Монтаж: 240 кадров / 10,000 с, 24 FPS

| Кадры итогового MP4, 0-based | Материал | Длительность |
| --- | --- | ---: |
| 0–120 | Оригинал #0–120 без изменений и ускорения | 121/24 = 5,0417 с |
| 121–168 | Оригинал #119→#72 в обратном порядке | 48/24 = 2,0000 с |
| 169–176 | Оригинал #7→#0 в обратном порядке; прямой стык **#72→#7** | 8/24 = 0,3333 с |
| 177–239 | Утверждённая RACE_STAND, без движения | 63/24 = 2,6250 с |

Оригинальный подъём и движения головы сохранены целиком. Опускание использует существующие кадры того же движения в обратном порядке, без интерполяции; скорость 1×. Поза с поднятой лапой читается около 2 секунд с учётом конца прямого клипа и начала реверса; дополнительная неподвижная задержка в позе не вставлялась. Финальное удержание стойки заполняет остаток времени. Мировая позиция собаки здесь не меняется.

Для закрытия реверса выбрана пара #72→#7: #72 уже имеет четыре опоры, #7 близок к нему по корпусу, ногам, ракурсу и линии пола. Это **прямой cut**. На крупном плане есть короткий сдвиг головы/корпуса, который нельзя объявить бесшовным: средняя разница декодированного кадра (уменьшение до 320×180) на этой паре около **3,4/255**, тогда как переход в утверждённую стойку #0→PNG около **0,8/255**. Число — вспомогательный индикатор, не доказательство художественной плавности. Проверочные кадры: [лист монтажа](DOG3_SNIFF_MONTAGE_CONTACT.png), [сравнение выхода](DOG3_SNIFF_END_STAND_COMPARISON.png), [черновик и новый выход рядом, MP4](DOG3_SNIFF_END_JOIN_COMPARISON.mp4). В сравнении слева черновик, справа новый монтаж; последние 1,5 с начинаются с 6,5 с каждого ролика.

## Известные дефекты

1. **Исходные #45–48:** при подъёме головы виден смаз морды и «призрак» уха. Эти четыре кадра сохранены без замены.
2. **Исходные #81–84:** задняя лапа кратко проходит под корпусом. Обратный монтаж повторяет эти кадры в итоговых **#156–159**, поэтому недостаток виден дважды; их исключение дало бы скачок в суставе. Исходный #87 также содержит тонкую голень.
3. **Конец реверса #168→169:** после исходного #72 следует #7. Хотя все четыре лапы стоят и масштаб постоянен, голова и линия плеч немного меняются за один кадр. Никакой crossfade, morph, оптический поток или изменение внешности для сокрытия этого не применялись. Не считать этот стык визуально утверждённым до просмотра MP4.
4. **Игровой MP4:** source ещё без alpha, поэтому виден прямоугольник студийного фона. Видео показывает **масштаб ячейки 207×116 px** на неизменённой арене Visual Pass 3, а не готовую интеграцию. Прямоугольник нельзя оценивать как дефект будущего alpha; сам alpha в этой задаче не создавался.

## Race V3 и материалы для просмотра

Модель `dog4-v3-lab/model.mjs` задаёт SNIFF_PEE **7,2604167 с** + RETURN **2,7208333 с** = **9,98125 с**. Диагностический MP4 округлён до 240 кадров / 10,000 с при 24 FPS, разница **0,01875 с**. При будущем подключении нужно разложить визуальные кадры по этим двум уже существующим окнам и решить долю последней статичной стойки без изменения `stateAt`, положения, финиша и победителя. В этой задаче такая интеграция **не выполнялась**.
