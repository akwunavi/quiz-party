# Рокки — лаборатория выхода IDLE B → SELECTED

Для просмотра начните с [выбора сразу на #1](DOG3_IDLE_EXIT_TRIGGER_001_GAME.mp4), [входа из спокойной позы #36](DOG3_IDLE_EXIT_TRIGGER_036_GAME.mp4), [возврата после активного жеста #80](DOG3_IDLE_EXIT_TRIGGER_080_GAME.mp4) и [худшего случая #77](DOG3_IDLE_EXIT_TRIGGER_077_GAME.mp4). Все это обычные MP4 полной цепочки, без запуска сервера.

[Карта совместимых точек](COMPATIBLE_ENTRIES.md), [полная карта задержек CSV](DELAY_MAP.csv) и [отчёт со всеми 14 MP4](REPORT.md).

Интерактивный выбор готовых сценариев: в этой папке запустить `python -m http.server 8000` и открыть `http://localhost:8000/`. [index.html](index.html) требует локальный HTTP-сервер только для лабораторного переключателя; MP4 открываются отдельно.

Алгоритм и предпросмотры ожидают визуальной приёмки. Утверждённые анимации Рокки не изменены.
