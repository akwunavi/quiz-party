# Bulldog №3 — проверка существующего STOP Kling 3.0

Исходник прочитан **без merge** из `claude/nifty-johnson-assbj5` (`a437332`): `bulldog3/stop-generation-v1/DOG3_STOP_KLING_V3_ORIGINAL.mp4`. Его SHA-256: `29ff6aefcbb2dacdf402121c51316790df641e183ff9e07058f31e39b2d73d9f`. Исходник не изменён. Параметры: H.264 MP4, 1276×720, 24 FPS, 73 кадра / 3,041667 с, без alpha.

## Выбор шва

Просмотрены все 73 кадра STOP, рабочий RUN source #61–72 и прилегающие кадры. STOP #0–16 повторяет бег; #17–20 переводит передние лапы к земле; #21–39 показывает перенос веса и постановку задних лап; #40–48 — выпрямление; после #48 собака уже почти стоит, но голова/глаза и корпус ещё немного стабилизируются. #68–72 ближе всего к утверждённой RACE_STAND.

Проверены три осмысленные ближайшие стыковки ([контактный лист](ENTRY_END_COMPARISON.png)):

| Переход | Наблюдение |
| --- | --- |
| RUN #67 → STOP #17 | Продолжение прыжка, но ступни и корпус заметно меняют высоту; торможение начинается позднее. |
| **RUN #68 → STOP #18** | **Выбран.** Обе позы показывают передние лапы, идущие к опоре, при поднятых задних; следующее движение STOP #19–21 поглощает скорость. |
| RUN #69 → STOP #20 | Передняя опора уже поздняя; в первом кадре STOP голова заметно ниже и дальше вправо. |

Для выбранного шва диагностические рамки силуэта: RUN #68 ≈ `x139–957, y111–704`; STOP #18 ≈ `x159–1013, y117–687` в кадре 1276×720. STOP шире примерно на 4%, морда смещается вправо до ~56 px исходного кадра (около 9 px при V3 масштабе 207×116), низ опоры выше на ~17 px (около 3 px в V3). Это приблизительные измерения по существующему RUN alpha-v2 и порогу тёмного силуэта на исходном STOP, не точные опорные точки лап. Момент движения в целом читается, но небольшой сдвиг корпуса/головы на шве остаётся; совпадение формы само по себе не доказывает полной плавности.

Итого **111 кадров / 4,625 с**, H.264, `yuv420p`, 1276×720, 24 FPS, `faststart`, без аудио. Активное торможение примерно STOP #18–47 (1,25 с); #48–72 сохранены для естественной стабилизации головы и совпадения с конечной стойкой. Обрезка у #48 дала бы более ранний, но видимый скачок к статичному референсу. Последние #68–72 почти совпадают со стойкой; #72 выбран для выхода без дополнительной интерполяции. Если игровое окно STOP длиннее, удерживать RACE_STAND после завершения клипа — **не замедлять** активное торможение. Окна и физика Race V3 здесь не менялись.

Браузерная страница использует копию **существующей** арены V3 без изменения её пикселей и геометрию спрайта V3: поле 1920×1080, персонаж 207×116 на третьей дорожке. Положение в мире закреплено для проверки шва; движение по трассе и игровая логика не имитируются. Рядом показан синхронизированный крупный план. Для запуска из корня репозитория:

```bash
python -m http.server 8765 --bind 127.0.0.1 --directory bulldog3/stop-review-v1
```

Открыть `http://127.0.0.1:8765/index.html`. Страница загружает MP4 как Blob, поэтому перемотка работает и на простом локальном HTTP-сервере без поддержки byte-range. В `DOG3_STOP_REVIEW_STANDALONE.html` те же MP4, арена и контактный лист встроены внутрь одного файла; внешние запросы ему не нужны. Встроенное содержимое воспроизведено в Chromium. Прямое открытие через `file://` **в этой облачной среде** проверить не удалось: политика её браузера возвращает `ERR_BLOCKED_BY_ADMINISTRATOR` для локальных файлов. Поэтому доказанной остаётся работа через HTTP и работа автономного содержимого в Chromium, а не сценарий двойного клика на этой машине.

## Оставшиеся дефекты и статус

- **Непрозрачные разные исходные фоны** RUN и STOP создают явный прямоугольник при склейке на арене. Это намеренно оставлено видимым: alpha по заданию не создавалась. По этому предпросмотру можно судить о движении и масштабе, но нельзя принимать итоговый внешний вид игрового спрайта.
- RUN #68 → STOP #18 имеет небольшой горизонтальный сдвиг морды и различие линии опоры; в игровом масштабе он умеренный, однако пользовательская оценка движения обязательна. Геометрическое выравнивание, crossfade, morphing и синтетические промежуточные кадры не применялись.
- Внутренний шов рабочего RUN loop #72 → #61 существовал до этой проверки и этим монтажом не исправлялся.
- Цвет/освещение между RUN и STOP различаются; отдельная коррекция отложена до проверки будущего прозрачного STOP. Нет оснований менять утверждённую RACE_STAND.

Локальная проверка: `ffprobe` подтвердил параметры и 111 кадров. В headless Chromium через локальный HTTP-сервер MP4 загрузился и воспроизвёлся (`currentTime` продвинулся), кнопки перехода к входу и стойке переместили воспроизведение на 1,133 и 3,425 с; ошибок страницы не было. Это техническая проверка браузера, **не** художественное утверждение пользователем. Новые Kling-генерации, alpha, merge, deploy и изменения production не выполнялись.
