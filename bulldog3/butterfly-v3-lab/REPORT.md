# Рокки — BUTTERFLY alpha и игровая лаборатория Race V3

**Статус:** утверждённый пользователем художественный исходник обработан и включён в изолированную игровую лабораторию. Технические проверки пройдены; итоговая визуальная приёмка игрового MP4 остаётся за пользователем. Production, общая физика V3, результаты и анимации других собак не изменялись.

## Исходник и alpha

- Утверждённый оригинал из ветки `claude/nifty-johnson-assbj5`: [`assets/DOG3_BUTTERFLY_KLING_V3_ORIGINAL.mp4`](assets/DOG3_BUTTERFLY_KLING_V3_ORIGINAL.mp4). Это побайтовая копия watermark-free MP4, SHA-256 `ff3976679bdbda495bfaa9401d9a0c20ef142d5552c35eff66de250148457171`. 1276×720, H.264, 24 FPS, 121 кадр / 5,0417 с. Исходник не перезаписывался.
- Для всех source #0–120 применён существующий `bulldog1-frenk/alpha_pipeline/dog_alpha.py`: BiRefNet-general-lite, временная стабилизация Farneback, closed-form alpha matting с 2× supersampling, `strength=1`, `tau=12`, `r-in=5`, `r-out=9`, `margin=24`, `min-area=1500`, `exclude-rect=none`. Изображение и движение собаки не перерисовывались. Маски, стабилизированные маски и RGBA-кадры остались в кэше `/workspace/artifacts/bulldog-racing/dog3-rocky-butterfly/work/` для последующих технических исправлений.
- [Полный alpha WebM](assets/rocky-butterfly-alpha-full.webm): VP9, 1276×720, 24 FPS, 121 кадр, `ALPHA_MODE=1`. [Отчёт проверки](alpha_verify_report.json): декодировано 121/121, максимальная alpha четырёх углов 0, лишних островков маски >20 px **нет**, соседний IoU масок min/mean **0,966 / 0,993**. Chromium показал пурпурный фон во всех углах без прямоугольника.
- [Четыре фона](ALPHA_QA_WHITE_BLACK_GREEN_BEIGE.png) и [увеличенная проверка лапы #68/#76/#82/#94](ALPHA_PAW_DETAIL_FOUR_BACKGROUNDS.png): контуры головы, морды, обоих ушей, опорных и поднятой лап сохранены. Пространство под поднятой лапой прозрачно, исходный пол и тень не просматриваются. Сторонних объектов на листах и движущихся объектов вне области собаки при сканировании всех 121 исходных кадров не обнаружено. Очень тёмная поверхность поднятой лапы уже есть в утверждённом Kling-исходнике, цвет не менялся.

| Игровые кадры, 0-based | Изображение | Длительность |
| --- | --- | ---: |
| 0–3 | Утверждённая RACE_STAND | 4/24 = 0,167 с |
| 4–96 | Исходный BUTTERFLY **#12–104 непрерывно**, 24 FPS | 93/24 = 3,875 с |
| 97–120 | Та же RACE_STAND | 24/24 = 1,000 с |
| **Всего** | **121 кадр Race V3** | **5,0417 с** |

В начале исходника #0–14 почти неподвижны; действие начинается около #15. Лапа работает на #68–94, к #96–104 собака стоит устойчиво. Сохранили исходный порядок, темп головы и лапы. Никаких промежуточных кадров, retiming, локального сдвига, изменения масштаба или пропорций. Точная карта игровая ячейка → исходный кадр находится в [`retiming.json`](retiming.json). [Alpha-атлас](assets/rocky-butterfly.png) содержит 121 прозрачную ячейку; [игровой WebM](assets/rocky-butterfly-alpha-121.webm) повторяет ту же последовательность в полном разрешении. Его [проверка](alpha_game_verify_report.json) подтвердила 121 кадр, alpha и Chromium.

Сравнение полноразмерного alpha с утверждённой RACE_STAND: вход source #12 — IoU **0,9950**, средняя RGB-разница в общей непрозрачной зоне **3,14/255**; выход source #104 — IoU **0,9946**, RGB-разница **3,30/255**. Контурная рамка обоих `(261,15)–(958,676)`; подстройка положения не нужна.

## Игровая цепочка и проверки стыков

В лаборатории используются неизменённый `stateAt` из `../race-start-v3-lab/model.mjs`, утверждённые STOP/RACE_START/RACE_STAND/RUN и визуальная фазировка RUN из коммита `3a0acf6`. Физический пример — пресет A, собака 2: STOP **11,458–13,000 с**, BUTTERFLY **13,000–18,042 с**, повторный START **18,042–19,042 с**, затем RUN. Мировая координата во всём BUTTERFLY постоянна. В [`verification.json`](verification.json) проверены также пять категорий скорости `0,75 / 0,90 / 1,00 / 1,10 / 1,25×`: на всех сохраняются окна **37 / 121 / 24 кадра**, предшествующий RUN #68 и нулевой разрыв мировой координаты на границах. `crossing`, `complete`, scoring и победители не пересчитывались.

| Стык игровых alpha-ячеек 178×100 | IoU силуэтов | Наблюдение |
| --- | ---: | --- |
| RUN source #68 → утверждённый STOP #18 | 0,8450 | Ранее согласованная фаза сохранена. |
| STOP последняя → RACE_STAND, первое удержание | 0,9981 | Положение корпуса и линия лап не скачут. |
| RACE_STAND → BUTTERFLY source #12 | 0,9986 | Движение начинается из стойки. |
| BUTTERFLY source #104 → RACE_STAND | 0,9983 | Лапа уже опущена, поза совпадает. |
| RACE_STAND → утверждённый RACE_START | 0,9634 | Принятый стык не изменён. |
| RACE_START → RUN source #52 | 0,7756 | Принятый стык и визуальное вступление RUN не изменены. |

MP4 полной цепочки просмотрен на ключевых кадрах всех границ в реальном игровом размере: телепортации, смены масштаба и съезда с линии трассы не обнаружено. Одно действие состоит из реакции головы и более позднего жеста лапы — таков утверждённый Kling-исходник. В конце окна остаётся **1 секунда стойки**; это не дополнительная физическая пауза, а часть существующих 121 кадров BUTTERFLY.
