## Историческая запись: RACE_START и блокер фазировки, до новой лаборатории

- Художественный результат первой генерации `race-start-v3-lab/assets/DOG3_RACE_START_KLING_V3_ORIGINAL.mp4` **визуально принят пользователем**. Динамика толчка, включая прыжок, не переделывалась.
- Из принятого видео подготовлен игровой участок #18–41, 24 кадра за 1,00 с, alpha VP9 и изолированная [лаборатория RACE_STAND → RACE_START → RUN](race-start-v3-lab/README.md). **Игровая версия RACE_START визуально принята пользователем.** Стык — Kling #41 → исходный RUN #52.
- RUN loop #61–72 и RACE_STAND остаются утверждёнными рабочими материалами. STOP с раздельным таймингом, 37 кадров, alpha и изолированной лабораторией также закрыт и принят пользователем.
- [Проверка полного возврата в RUN](return-run-review/REPORT.md) тогда обнаружила конфликт фаз: Race V3 завершала RUN перед STOP/FINISH на исходном #62, а утверждённый STOP согласован с #68. Этот исторический блокер стал причиной отдельной визуальной лаборатории фазировки; физика не менялась.
- На тот момент выход из STOP обратно в RUN, FINISH, BUTTERFLY, SNIFF_PEE и ROLL для Рокки ещё не были разработаны. Текущий статус см. выше.
