# Рокки — RACE_START: задание для одной генерации Kling

Задача генерации: **только** боковой переход `RACE_STAND → первый толчок лапами → начало бега`. Не генерировать продолжение забега, новый облик или смену ракурса. Kling здесь не запускался.

## Входные изображения

1. [FIRST — утверждённая RACE_STAND](DOG3_RACE_START_FIRST_STAND.png), 1276×720 RGB. Это точное изображение `../race-stand-generation-v1/DOG3_RACE_STAND_GENERATED_01.png`, уменьшенное целиком с 1670×942 до размера RUN без обрезки и изменения позы. Утверждённый оригинал остаётся неизменённым.
2. [LAST — исходный RUN #39](DOG3_RACE_START_LAST_RUN039.png), 1276×720 RGB. Собака взята из уже существующего alpha-v2 кадра, соответствующего исходному RUN #39; скомпонована на ровном нейтральном фоне. Локальное положение внутри кадра: **x −22, y +27 пикселей**, без изменения размера, пропорций, окраса или движения. Исходный RUN не изменён.

[Сравнение двух референсов и альтернативного #40](DOG3_RACE_START_REFERENCE_COMPARISON.jpg). Красная линия на диагностическом листе показывает y=675; она **не входит** в изображения для Kling.

## Почему #39

Сравнивались #36–41, включая оригинальные кадры и существующие alpha-v2. #36 ещё заметно развёрнут к камере; у #37–38 верх ушей упирается в границу кадра. На #39 оба уха, голова и морда целы, ракурс близок к RACE_STAND, задняя лапа ещё даёт опорную фазу, а передние уже начинают выноситься вперёд. #40 имеет чистую голову, но корпус и передние лапы уже сильно вытянуты: ширина alpha-силуэта около 803 пикселей против 696 у стойки. У #39 ширина около 706 пикселей, то есть разница со стойкой ≈1,4%. Это облегчает контроль масштаба, хотя сам по себе близкий силуэт плавности не гарантирует.

После локального выравнивания #39 непрозрачный контур лежит примерно в x=252–957, y=44–675; у RACE_STAND — x=262–957, y=16–675. Правая граница и нижняя линия опоры совпадают; голова и уши в беговой фазе ниже примерно на 28 пикселей. Это ожидаемое снижение корпуса при первом толчке, но его естественность надо проверить в полученном движении. Ракурс в обоих кадрах правый боковой с небольшой видимой передней частью морды. Фоновый RGB у конечного референса нейтральный серый; небольшое отличие света/тона шерсти между утверждённой стойкой и исходным RUN **не корректировалось**.

## Короткий prompt для Kling

Передать `FIRST` как start frame, `LAST` как end frame. Если интерфейс Kling не поддерживает два изображения как граничные кадры в выбранном режиме, не подменять эту схему текстовым описанием и не запускать генерацию без пересогласования.

```text
The same dark charcoal French bulldog, locked right-facing side view and fixed camera. Starting exactly from the first image, he shifts his weight forward, pushes off naturally with his paws, takes his first running stride, and begins accelerating into the exact pose of the last image. Keep his identity, ears, muzzle, coat, anatomy, size, framing and ground line consistent. Continuous believable paw contacts and body motion. No turn toward camera, sitting, pause, jump in place, extra limbs, props or scene change.
```

Целевой полезный участок — около **1 секунды** при 24 FPS, с движением сразу после стойки; фактическую длительность и точки обрезки определить только по результату. Не обещать, что 1-секундное движение получится из выбранной длины генерации без retiming. Не переносить студийный фон из исходного RUN.

## Предварительный монтаж после визуальной приёмки

- Окно `START` Race V3 остаётся **1,0 с**. В него планируется поместить полезный отрезок нового клипа: стойка → первый толчок → поза #39. При необходимости возможен лишь индивидуальный retiming после просмотра работы лап. Физическое перемещение собаки берётся из существующего Race V3; движение рисунка внутри спрайта не должно имитировать дополнительное мировое перемещение.
- На границе START/RUN следующий настоящий кадр — исходный #40. Затем использовать #40–62 как 23-кадровое вступление RUN, после чего повторять утверждённый 12-кадровый цикл #61–72, начиная с фазы #63: `#63…72 → #61…62 → #63…`. Так сохраняются длительность существующего RUN_JOIN (23/24 с), исходные кадры и физика. Фазу и стык #39→#40, а также #62→#63 и #72→#61 проверить в движении; решение пока не утверждено.
- Если генерация достигает #39 раньше или позже конца 1-секундного окна, проверить умеренный локальный retiming либо другую точку входа в RUN на естественной фазе. Не вставлять произвольную статичную паузу и не вырезать активный шаг ради формального тайминга.

## Приёмочные риски

- Первый кадр видео может отличаться от утверждённой стойки по голове, цвету или масштабу; последний — от RUN #39, несмотря на заданные изображения.
- Возможны скольжение опорной лапы, скачок корпуса, лишняя конечность, поворот морды, прыжок на месте и потеря тёмного окраса.
- Разница высоты головы/ушей между референсами должна быть пройдена реальным движением корпуса. Её нельзя скрывать статическим сдвигом.
- У RUN #39–40 различается позиция тела и фаза лап; стык нужно проверять покадрово и в нормальной скорости, в том числе в игровом масштабе. Совпадение граничных картинок не доказывает качества движения.
- Ранее известные обрезанные уши исходных #37–38 не включать в предлагаемое вступление; исходный #39 выбран после них. Отличие света между сгенерированным клипом и RUN может потребовать отдельной локальной коррекции после визуальной оценки.

Никакие alpha-маски не создавались; существующий alpha-v2 применён только для RGB-референса. Утверждённые RUN, STOP, RACE_STAND, общая физика и другие собаки не изменялись.
