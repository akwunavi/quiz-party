# Игровая лаборатория выбора Рокки — проверка RETURN D

**Исторический статус:** лаборатория полного ожидания цикла отклонена пользователем из-за задержки SELECTED до 9,958 с. RETURN D остаётся рабочим вариантом; актуальный алгоритм выхода проверяется в [новой лаборатории](../idle-exit-lab/REPORT.md). Эта запись сохранена для сравнения и не является текущей рекомендацией.

Фиксированные входы: утверждённый `DOG3_IDLE_B_ALPHA_240.webm`, утверждённый `DOG3_SELECTED_ALPHA_121.webm`, [RETURN D alpha](assets/DOG3_RETURN_D_ALPHA_97.webm). Все видео 1276×720, 24 FPS. В MP4 каждый кадр помещается на одну и ту же площадку без изменения масштаба и мирового якоря; размер полного видеокадра в карточке 207×116 px.

## Шесть моментов подтверждения

Исключение: при подтверждении ровно на фазе #0 SELECTED начинается сразу. [Точная покадровая карта каждого MP4](SELECTION_LAB_MAP.json).

| Граница | Наблюдение |

| IDLE B #239 → SELECTED #0 | Одинаковая линия земли и габариты, IoU alpha силуэта **0,9978**. В игровом размере заметного скачка нет. |
| SELECTED #120 → RETURN D #0 | Тот же исходный кадр #120 удерживается ещё на 1/24 с; геометрического скачка нет. |

MP4 закодированы H.264/yuv420p, 24 FPS, `faststart`.

## Что остаётся оценить визуально

В D нет скачка, который был у отклонённых A/B, но **обратное проигрывание части реакции** меняет порядок выражений морды и возвращает переднюю лапу обратным шагом. Пользователь принял это как рабочую основу; финальное решение следует принимать по полным MP4 в реальном времени, особенно при фазах #0 и #180. Числовое совпадение стыков не доказывает естественность жеста.

Долгое ожидание после подтверждения на ранней фазе IDLE B — отдельное ограничение выбранной лабораторной политики: максимум почти 10 секунд. Лаборатория специально показывает задержку, не сокращая и не меняя утверждённый цикл. Изменение поведения выбора в production этим отчётом не предлагается автоматически.

Сборка воспроизводится через [build_working.py](build_working.py) и [build_selection_lab.py](build_selection_lab.py). HTML-лаборатория работает через локальный HTTP-сервер, но для просмотра перечисленных MP4 сервер не нужен. Никаких изменений Race V3, production, других собак, merge или deploy.
