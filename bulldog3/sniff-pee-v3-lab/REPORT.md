## Alpha и монтаж

Применён тот же проверенный `dog_alpha.py`, что и для BUTTERFLY Рокки: BiRefNet-general-lite, Farneback temporal consistency, closed-form matting, 2× supersampling. Параметры: `strength=1`, `tau=12`, `r-in=5`, `r-out=9`, `margin=24`, `min-area=1500`, `exclude-rect=none`. 121 уникальный исходный кадр обработан один раз. Рабочие исходные маски, стабилизированные маски и RGBA сохранены в `/workspace/artifacts/bulldog-racing/dog3-rocky-sniff/work/`; исходный MP4 не изменён.

На четырёх фонах обнаружено, что BiRefNet ошибочно сделал светлую склеру прозрачной в исходных #20, #21, #24, #47–49, #54, #81, #82 и #86. [Локальная коррекция](restore_eye_alpha.py) восстановила alpha только внутри глаза из исходных пикселей Kling; остальные 111 кадров RGBA использованы без коррекции. Параметры и площади коррекции записаны в [JSON](eye_alpha_correction.json). Окрас, глаза, движения и принятый монтаж не перерисованы.

Итоговый atlas повторяет точную карту `f28ecee`: #0–120 = source #0–120; #121–168 = source #119→72; #169–176 = source #7→0; #177–239 = утверждённая RACE_STAND. Ни ускорения, ни интерполяции, ни изменения масштаба или локального положения спрайта нет.

Декодировано 240 alpha-кадров. Четыре угла каждого кадра полностью прозрачны, изолированных островков фона больше 20 px нет, alpha диапазон 0–255. Chromium показал фоновый magenta в углах WebM, ошибок видео нет. Уши, задняя лапа, морда и промежутки между ногами просмотрены на белом, чёрном, ярко-зелёном и бежевом фонах; исходный пол и прямоугольный фон не выявлены.

## Race V3 и стыки

Лаборатория импортирует неизменённые `buildDog/stateAt` и фазировку RUN из `3a0acf6`. Визуальное время alpha-атласа начинается с `SNIFF_PEE.t0` и продолжается через `RETURN` без перезапуска; физические окна: STOP 37 кадров, SNIFF_PEE 7,2604167 с, RETURN 2,7208333 с, START 1,000 с. Сумма действия 9,98125 с против 10,000 с визуального монтажа: разница 0,01875 с приходится на последний статичный кадр RACE_STAND. Мировая позиция во время SNIFF_PEE и RETURN фиксирована штатной моделью. Во всех пяти диагностических категориях скорости 0,75× / 0,90× / 1,00× / 1,10× / 1,25× перед STOP показан исходный RUN #68, последовательность и прогресс непрерывны; finish times, scoring и winner logic не менялись.

Проверены RUN→STOP, STOP→SNIFF_PEE, прямой ход→реверс, принятый стык source #72→#7, выход в RACE_STAND, RACE_STAND→START и START→RUN. Для STOP→SNIFF_PEE силуэт IoU 0,997; смещение центра менее 0,1 px в atlas. Для RACE_STAND→START IoU 0,962; смещение центра менее 0,5 px. Цифры дополняют просмотр, не заменяют его. Линия лап и размер спрайта стабильны; заметного телепорта на игровых стыках не обнаружено.

Остаются ранее принятые особенности исходника: смаз головы/ушей #45–48, краткое положение задней лапы под корпусом #81–84 (повтор #156–159) и видимый в крупном плане cut #168→169 (source #72→#7). Они не исправлялись по указанию пользователя. Финальная игровая визуальная приёмка остаётся за пользователем.

Оба MP4 — H.264 `yuv420p`, `faststart`, без аудио. FFmpeg декодировал их полностью; Chromium воспроизвёл оба до `ended`. В HTML-лаборатории проверены Play, полная цепочка, действие и пять скоростей. Для локального запуска HTML см. [README](README.md); MP4 открываются самостоятельно.
