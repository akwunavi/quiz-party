# Рокки: SNIFF_PEE + RETURN в Race V3

Это изолированная игровая лаборатория. Она читает неизменённые `model.mjs`, утверждённые RUN/STOP/START/RACE_STAND и фазировку RUN из соседних лабораторий. Production-компоненты здесь не используются и не изменяются.

Для локального просмотра из корня репозитория:

```bash
python3 -m http.server 8765
```

Открыть `http://127.0.0.1:8765/bulldog3/sniff-pee-v3-lab/`. Есть полная цепочка, отдельное действие и пять скоростных категорий. Обычные MP4 лежат рядом с этой инструкцией; сервер для просмотра MP4 не требуется.

Принятый визуальный монтаж `f28ecee` перенесён в alpha-атлас без изменения порядка кадров. Физические окна `SNIFF_PEE` и `RETURN` по-прежнему рассчитывает `stateAt` Race V3. Соответствие кадров находится в `retiming.json`.
