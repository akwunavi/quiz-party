# Bulldog №3 — визуальная проверка RUN (13.10.2026)

Статус: **основная петля рекомендована для следующего этапа, художественное утверждение внешности остаётся за пользователем**. Созданы только диагностические производные из существующих source MP4 и alpha-v2 WebM. Цвет, движение, исходные файлы и игровая арена не менялись.

## Материалы и воспроизведение

- [Контактный лист оригинала](reviews/run-acceptance/DOG3_RUN_SOURCE_APPEARANCE.png): ровно source #0, #12, #23, #36, #48, #61, #72, #90, #110, #120. Нумерация с нуля, 24 FPS; кадры только одинаково уменьшены для листа, без коррекции цвета.
- [Основная петля, 12 повторов](reviews/run-acceptance/DOG3_RUN_LOOP_PRIMARY_12X.mp4): source #61–72 = alpha-v2 #25–36.
- [Альтернативная петля, 12 повторов](reviews/run-acceptance/DOG3_RUN_LOOP_ALTERNATIVE_12X.mp4): source #48–59 = alpha-v2 #12–23.
- [Покадровый лист основной](reviews/run-acceptance/DOG3_PRIMARY_FRAME_SEQUENCE.png) и [альтернативной](reviews/run-acceptance/DOG3_ALTERNATIVE_FRAME_SEQUENCE.png) петли для проверки конечностей.

Каждый MP4 — 1920×1080 H.264/yuv420p, 24 FPS, 144 кадра/6 с, faststart, без аудио. В каждом одновременно показаны крупный план и спрайт **207×116 px**, то есть точный размер из `dog4-v3-lab/layout.json` для сцены 1920×1080. Фон ровный нейтрально-серый; реальная трасса намеренно не используется. Видео составлено прямым повтором 12 исходных alpha-кадров, без crossfade, интерполяции, изменения скорости, стабилизации и перекраски. Проверка MP4 проведена полным декодированием FFmpeg и просмотром отдельных кадров/покадровых последовательностей. Автоматизированный просмотр в Chrome в этой проверке не проводился.

## Внешность оригинального RUN

| Признак | Наблюдение |
| --- | --- |
| Шерсть | #0–23 очень тёмная, почти чёрно-коричневая; #48–72 тёмная с более заметными холодными бликами; #90–120 светлее и серее на спине, боках и голове. Изменение есть **в оригинальном MP4**, до alpha-matting. |
| Морда/глаза | Короткая складчатая морда и тёмная маска сохраняются, но оттенок морды и контраст вокруг глаза меняются; видимый глаз меняется с ракурсом и фазой мигания. |
| Уши | Общая форма стоячих ушей сохраняется, дальнее ухо сильнее меняет видимость при повороте. Блики на ушах усиливаются в конце. |
| Пропорции/ракурс | #0–23 фронтальный/три четверти вправо; с разгона собака разворачивается ближе к боковому ракурсу. В позднем беге могут восприниматься иные пропорции из-за ракурса и фазы шага. |
| Свет | Положение и интенсивность бликов на корпусе меняются вместе с движением и видимым студийным источником. Поздняя часть выглядит заметно ярче. |

**Причина высветления неразделима по этому одному сгенерированному ролику.** Изменение освещения явно участвует, однако стабильность самой текстуры шерсти на больших поверхностях не подтверждена: генеративный дрейф окраса также возможен. Нельзя автоматически считать поздние #90–120 тем же утверждённым окрасом, что #0–23. Цветокоррекция не применялась. Исходный фон содержит студийную стойку/свет у #36–72, поэтому для игровых кадров использована уже подготовленная alpha-v2.

## Сравнение 12-кратных повторов

| Проверка | Основная source #61–72 | Альтернативная source #48–59 |
| --- | --- | --- |
| Шаг и корпус | Полный цикл опоры/полёта; высота корпуса меняется согласованно. В #68–70 передние лапы выносятся вперёд, затем собираются. | Тоже полный цикл, но в начальной фазе лапы сильнее визуально сливаются под корпусом. |
| Голова, уши, хвост | Ракурс и силуэт в #72→#61 близки; голова и передние лапы всё же меняют положение на границе. Нет явного раздвоения в отдельных кадрах. | На #59→#48 заметнее смена положения передних лап и высоты головы. На #48 виден неровный тёмный контур под мордой/шеей, требующий отдельной проверки маски перед производственным использованием. |
| Количественный скрининг | Ранее измеренный фазовый IoU ≈0,942, прямое среднее изменение alpha на шве ≈11,21/255 против ≈15,21/255 между соседними кадрами внутри цикла. | Фазовый IoU ≈0,924. Число не доказывает гладкость движения. |
| Игровой масштаб | На 207×116 px малая смена позы шва заметно менее выражена; сам бег читается. | Бег читается, но шов и тёмный край у нижней морды делают кандидата слабее. |

**Рекомендация: #61–72 / alpha-v2 #25–36 как рабочий RUN loop.** Это не утверждение идеального бесшовного цикла: на прямом стыке #72→#61 остаётся небольшой скачок головы/передних лап и фазы корпуса. В крупном плане он виднее, в масштабе гонки умеренный. Повторение точно той же дюжины кадров не создаёт новых конечностей; видимые наложения лап — часть исходного движения или маски. Не добавлять crossfade/интерполяцию для скрытия шва без отдельного решения. Перед окончательной приёмкой RUN стоит посмотреть оба MP4 целиком на целевом дисплее.

## Архитектура стоек

| | A: одна стойка из раннего RUN | B: FRONT_STAND + RACE_STAND |
| --- | --- | --- |
| Опорные кадры | Есть ранний source #0/#12/#23, но с фоном и фронтальным/трёхчетвертным ракурсом. | FRONT_STAND может опираться на ранний RUN; бокового RACE_STAND в доступных файлах нет. |
| Переходы | Номинально одна базовая поза, но каждый STOP и каждый повторный START должен разворачивать собаку из бокового RUN и обратно. Возрастает сложность каждого действия/финиша. | Появляется отдельный переход выбора/первого старта из FRONT_STAND в боковой бег и отдельный RACE_START после событий; события и финиш возвращаются в общий боковой RACE_STAND. |
| Kling-объём | Может быть на один референс и один тип START меньше, если повороты действительно удадутся внутри STOP/START. Повторные неудачные повороты могут потребовать дополнительных клипов. | Минимум один дополнительный утверждённый pose-reference RACE_STAND и вероятно отдельный RACE_START; ориентир полного минимального набора — до 8 новых видео (см. PRODUCTION_PLAN), при отсутствии имеющихся IDLE/SELECTED и удачном повторном использовании STOP для FINISH. |
| Риск | Высокий: смена ракурса на каждом событии, лицо и окрас могут дрейфовать. | Ниже для многократных событий, но зависит от качества создания боковой стойки и первого перехода. |

**Выбор: B, условно.** Она добавляет один эталонный ракурс и, возможно, отдельный restart, но сохраняет боковой ракурс RUN через STOP/действия/FINISH. Ранний кадр нельзя просто объявить `RACE_STAND`. До создания Kling-видео нужно сначала согласовать эталонную внешность и обе позы; числа генераций остаются оценкой, а не заданием на платные работы.

## Нужные референсы и следующий минимальный этап

1. Оригинальный MASTER №3, если он есть; уже существующие IDLE/SELECTED и их исходники, если есть. В доступном реестре не обнаружены.
2. Для цвета/формы: source #0, #12, #23 (кандидаты FRONT_STAND), source #48, #61, #72 и alpha-v2 #12, #25, #36 (RUN, маттинг и стык), source #90/#110/#120 (контроль дрейфа, **не автоматический эталон**).
3. Утверждённый FRONT_STAND в исходном разрешении и **отдельный согласованный** боковой RACE_STAND на четырёх лапах, с тем же корпусом, мордой, ушами, окрасом, масштабом и линией земли. В доступных материалах второго нет; не получать его растягиванием бегового кадра.
4. Только после утверждения внешности и петли: технически спроектировать первый FRONT_STAND→RUN и RUN→STOP→RACE_STAND по настоящим конечным позам. Новые Kling-клипы, alpha и интеграция в этом этапе не создавались.
