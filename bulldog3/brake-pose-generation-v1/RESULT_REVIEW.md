# Bulldog №3 — статичный ориентир для RUN → STOP → RACE_STAND

Дата: 14.10.2026. Один image-to-image вызов; видео, alpha, RUN и утверждённый RACE_STAND не менялись. Цена инструмента заранее не указана; пользователь разрешил один запуск в текущем задании.

## Выбор точки и позы

Рабочий цикл: source RUN #61–72 (24 FPS). В #62–63 задняя лапа находится у земли, но передние ещё подняты. #64–67 — полёт/растяжение. #68–70 — передние лапы выходят вперёд и принимают нагрузку, задние ещё находятся в воздухе. Для входа в торможение полезнее #69: плечи и голова уже опущены, передние лапы ближе к опоре. #71–72 снова уводят собаку в следующий шаг.

Прямой переход из любого бегового кадра к RACE_STAND пропускает постановку задних лап и перенос веса. Дополнительный `STOP_STAND` не нужен: утверждённая RACE_STAND уже является устойчивой конечной позой. Нужен динамический ориентир `BRAKE_POSE` между бегом и стойкой. Это **референс для будущей анимации, не готовый кадр для монтажа**.

Кандидат сохраняет тёмный окрас, форму ушей и морды, направление вправо; видны четыре лапы с опорой. Он выглядит как торможение за счёт низкого корпуса, согнутых передних лап и отставленных задних. Передняя половина тела кажется несколько массивнее, чем в RUN. Силуэт также примерно на **20% шире**, чем у утверждённой RACE_STAND в исходных кадрах одинакового размера (оценка по видимым границам, не замер сегментационной маски). Для настоящего клипа понадобится контролировать масштаб и положение; этот кадр нельзя вставлять напрямую. Положение головы относительно RUN #69 и RACE_STAND различается, поэтому непрерывность движения пока не доказана.

## Цвет

У RACE_STAND относительно RUN местами теплее/светлее круп и морда, но освещение по телу неоднородно: на спине и плече отдельные участки, наоборот, выглядят темнее. Разные позы мешают точному попиксельному сравнению. Локальная коррекция отдельных областей в принципе возможна без повторной генерации, но простая общая коррекция ухудшит другие области. **Сейчас цвет не меняем**; проверять её следует только на кадрах реального STOP в одном масштабе и освещении.

Создать один настоящий STOP-клип: начать с фазы фронтальной нагрузки, близкой к RUN #69, показать постановку задних лап и поглощение скорости в направлении `BRAKE_POSE`, закончить точно в утверждённой RACE_STAND. Движение лап, корпуса и головы должно быть непрерывным; использовать статичный кандидат как позный ориентир, а не монтажный кадр. Затем отдельно проверить переход RUN → STOP → RACE_STAND в движении, масштаб, землю, окраску и отсутствие изменения личности. Генерация видео в этом этапе не выполнялась.
