# Рокки — техническая проверка RACE_START

**Статус:** художественный результат первого Kling RACE_START принят пользователем. Alpha и изолированная игровая интеграция подготовлены как технический кандидат; окончательная визуальная приёмка игрового перехода остаётся за пользователем.

## Диапазоны и скорость

| Участок | Источник / выход | Длительность |
| --- | --- | --- |
| Избыточное ожидание | Kling #0–17, исключено только из игровой версии | 18/24 = 0,75 с |
| RACE_START | Kling #18–41 включительно, 24 последовательных кадра | 1,00 с при исходных 24 FPS; ускорения нет |
| Первое вступление RUN | исходный RUN #52–62 | 11/24 с |
| Повторяемый RUN | утверждённый #61–72, начальная фаза #63–72 → #61–62 | 12/24 с за цикл |

Окно START Race V3 остаётся 1,00 с. Его `frameFor` читает первые 24 ячейки листа с частотой 72 FPS и следующие 16 с частотой 24 FPS. Поэтому в первых 24 ячейках каждый исходный кадр #18–25 повторён трижды, а #26–41 стоят по одному разу. **Фактическое движение во времени остаётся исходными 24 FPS**, без выбрасывания активных кадров, интерполяции и изменения принятого прыжка. После Kling #41 следует существующий RUN #52. Сдвиг рисунка внутри спрайта не применялся; расчётная мировая позиция идёт по неизменённому `stateAt` Race V3.

## Alpha

Источник: `assets/DOG3_RACE_START_KLING_V3_ORIGINAL.mp4` из ветки `claude/nifty-johnson-assbj5`, 1276×720, 24 FPS, 73 кадра. Использован проверенный конвейер BiRefNet-general-lite + временная стабилизация Farneback + closed-form matting с настройками по умолчанию (`strength=1`, `tau=12`, `r-in=5`, `r-out=9`, `margin=24`, `supersample=2`, CRF 14). Источник без watermark; `exclude-rect=none`. Кэш исходных кадров, масок и RGBA сохранён во внешнем рабочем архиве `/workspace/artifacts/bulldog-racing/dog3-race-start/`.

На контрастном зелёном фоне обнаружились прозрачные отверстия в светлой части глаза. Скрипт `repair_eye_alpha.py` восстановил RGB из исходного MP4 только внутри малых замкнутых участков глаза и однопиксельного ободка на кадрах #28, #30–36, #38–40 игрового диапазона. Окрас, форма морды, лапы, уши и движение не редактировались. После коррекции [листы на белом, чёрном, зелёном и бежевом](ALPHA_QA_WHITE_BLACK_GREEN_BEIGE.jpg) показывают целый глаз, уши и лапы, без отделённого пола или исходной контактной тени в проверенных фазах. На быстрых лапах сохраняется мягкий контур исходного motion blur; заметных прямоугольников и оторванных островков маски нет.

Выходной [WebM](assets/rocky-race-start-alpha-24.webm): VP9, 1276×720, 24 FPS, 24 кадра, `alpha_mode=1`; угловая alpha равна 0, диапазон alpha 0–255, дополнительных островков маски >20 px нет. Chromium воспроизвёл WebM поверх пурпурного фона: все четыре угла остались пурпурными, ошибки декодирования не было. Проверка независимым `verify_alpha.py` сохранена во внешнем рабочем архиве.

## Стыки и масштаб

| Стык | Техническая проверка |
| --- | --- |
| RACE_STAND → Kling #18 | IoU alpha-контуров 0,964; стойка `(262,16)–(957,675)`, первый кадр `(262,9)–(948,675)` в исходном размере. Низ лап совпадает. Изменение высоты уха ≈7 px и света небольшое. |
| Kling #41 → RUN #52 | IoU 0,775 — соответствует величине некоторых настоящих последовательных шагов во время ускорения. Bbox `(246,15)–(962,656)` → `(193,40)–(971,645)` отражает вытяжение корпуса и снижение головы в следующей фазе. Совпадающая непрозрачная область отличается по RGB в среднем на 20,4/255. Это **не доказательство бесшовности**; [крупный план](DOG3_ROCKY_START_RUN_SEAM_CLOSE.mp4) дан для визуальной оценки. |
| RUN вступление → петля | #52–62 затем #63–72 → #61–62; это исходное последовательное движение, после которого используется утверждённый шов #72→#61. RUN loop не изменён. |

Пять категорий мирового темпа `.75×`, `.90×`, `1.00×`, `1.10×`, `1.25×` проверены в Chromium. Для всех START ровно 1,00 с, численный разрыв прогресса на BASE→START и START→RUN равен нулю. Анимация остаётся 24 FPS независимо от мирового темпа, как в V3. В игровом масштабе явного скачка мировой позиции или линии опоры не обнаружено. Оба игровых MP4 (1920×1080, 24 FPS, 84 кадра, 3,5 с) воспроизводятся в Chromium и полностью декодируются FFmpeg; H.264, `yuv420p`, `faststart`.

Для контроля масштаба Bulldog №4 показан рядом **только как read-only референс**, без изменения его ассетов. При одинаковом размере спрайтовой ячейки стойки имеют близкую высоту (Рокки 92 px, №4 92 px), но Рокки заметно шире (97 против 69 px); RUN-фаза также шире (109 против 66 px) и чуть выше (84 против 76 px). Менять утверждённые изображения или масштаб Рокки для выравнивания не стали. Это вопрос визуальной приёмки общего состава собак, а не физики.

## Оставшееся

Крупным планом заметна небольшая разница формы головы и света на границе Kling #41 → RUN #52. В игровом масштабе она значительно слабее; пользователь должен оценить обычные MP4. Alpha-контур быстрых лап слегка мягкий из-за исходного motion blur. Лаборатория не доказывает готовность остальных действий Рокки или production-интеграции. STOP, RUN loop, RACE_STAND, другие собаки, Race V3 physics, winner/scoring и production не менялись. Kling, merge и deploy не выполнялись.
