# Проверка существующего RUN №3

## Источник и разметка

`assets/bulldog_03_run.mp4` из commit `1c652ce822455469101f5f4740653db3f12e8868`: H.264/yuv420p, 1276×720, 24 FPS, 121 кадр, 5,041667 с. Исторический отчёт использует номера исходных кадров 37–121 **с единицы** для полезной части; далее здесь нумерация **с нуля**: alpha output #0 = source #36, output #84 = source #120.

По исходному contact sheet: #0–23 — относительно устойчивая стойка в ракурсе лицом/три четверти вправо; #24–35 — перенос веса, поворот и разгон; примерно #36–120 — непрерывный бег вправо. Alpha-v2 сохраняет только бег, 85 кадров/3,542 с при исходных размере и FPS. Исходный бег хорошо передаёт уши, короткую морду, тяжёлый корпус и чередование опоры/полёта лап. Контуры лап и межлапные просветы требуют внимания при повторе. У конца исходника шерсть и освещение существенно светлее, чем в начале; это видно и в **оригинальном MP4**, а значит не устраняется маской alpha.

## Проверка alpha-v2

WebM: VP9, 1276×720, 24 FPS, 85 кадров, `alpha_mode=1`. Декодирование `libvpx-vp9` всех кадров прошло без ошибок. На уменьшенном 160×90 декодировании alpha имеет значения 0…255, все четыре угла прозрачны на всех 85 кадрах, у порога 128 видна одна связная область без отдельных островков. Chromium через локальный HTTP воспроизвёл видео до 1,76 с; Canvas показал alpha=0 в углу и alpha=255 на корпусе. Это техническая проверка, не полная художественная приёмка каждого края.

Исторический `report.md` для alpha-v2 документирует локальное исправление старого штатива у морды, восстановления глаза и остатков пола/тени на отдельных кадрах. Сравнение на белом, чёрном, зелёном и фоне трассы хранится в исторических `dog3-review.jpg` и `dog3-before-after.jpg`. При нашем просмотре опубликованного review грубого прямоугольника не видно; тёмный контур, мелкие просветы ног и перемена цвета остаются зонами внимательной проверки в игровом масштабе.

## Кандидат RUN loop

В 85-кадровой alpha-последовательности виден период около **12 кадров = 0,5 с**. Предварительно предлагается **output #25–36** (source #61–72, оба диапазона 0-based; source 2,542–3,000 с). Альтернатива **output #12–23** (source #48–59, 2,000–2,458 с) темнее, но включает область исторической коррекции штатива на output #12–15.

Метод скрининга: декодирование 160×90 RGBA, силуэт при alpha>128; для сравнения фазы сдвиг центра ограничен 3 пикселями. Для #25–36 силуэт следующего исходного #37 против начала #25 имеет IoU≈0,942; средняя разница цвета ≈3/255. Прямое среднее |Δalpha| на стыке #36→#25 составляет ≈11,21/255 против ≈15,21/255 между соседними кадрами внутри участка. Для #12–23 аналогичный фазовый IoU≈0,924. **Эти показатели только отбирают кандидатов**: они не проверяют непрерывную работу лап, ушей и головы и не доказывают бесшовность.

Из просмотренных сохранённых кадров #25 и #36 имеют близкий масштаб и ракурс, но различаются положением передней лапы и морды. Внутри #25–36 есть output #32/#33, перечисленные в историческом отчёте как локально исправленные. **Обновление 13.10.2026:** пользователь разрешил диагностические производные, и два MP4 по 12 повторов созданы. Результат, наблюдаемые дефекты и выбор основной петли описаны в [VISUAL_ACCEPTANCE.md](VISUAL_ACCEPTANCE.md). Вход в будущий STOP ещё не проверялся, поскольку клипа STOP №3 нет.

## Ограничения RUN как референса

- Устойчивой боковой стойки внутри сохранённой alpha-части нет: почти все кадры беговые. Начальная стойка существует только в исходном MP4 с фоном и более фронтальным ракурсом.
- В оригинале собака заметно высветляется в поздней части. Нельзя считать длинный alpha-v2 единым неизменным референсом окраса для Kling.
- Сравнение одного silhouette IoU не заменяет проверку ног и центра тяжести. Не применять морфинг или crossfade для скрытия несовместимой позы.
