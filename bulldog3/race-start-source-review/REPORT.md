# Рокки: проверка исходного RUN для RACE_START

Статус: **блокер для естественного RACE_STAND → RACE_START → RUN**. Монтажная версия и игровая лаборатория не выпускались. Утверждённые RACE_STAND, RUN loop и STOP не изменены.

## Материалы и проверка

- Исходник: `../assets/incoming/bulldog_3_run.mp4`, 1276×720, 24 FPS, 121 кадр (#0–120). Просмотрен весь ролик; все фазы представлены на [полном контактном листе](FULL_RUN_CONTACT.jpg).
- Утверждённая стойка: `../race-stand-generation-v1/DOG3_RACE_STAND_GENERATED_01.png`.
- Сравнение стойки с покадровым первым движением: [#24–44](STAND_TO_RUN_24-44.jpg); сравнение alpha-силуэтов с боковыми фазами: [#36, #37, #39, #50, #63, #68](STAND_SIDE_CANDIDATES.png).
- Существующий alpha RUN v2 соответствует исходным #36–120; утверждённая петля — исходные #61–72.

## Что есть в исходнике

| Кадры | Наблюдение | Пригодность |
| --- | --- | --- |
| #0–23 | Стойка почти анфас, без первого бокового толчка. | Не стыкуется с утверждённой боковой RACE_STAND. |
| #24–34 | Шаги и поворот от фронтального к боковому ракурсу; положение лап и головы меняется вместе с разворотом. | Использование даёт скачок ракурса на входе. |
| #35–36 | Собака уже отрывается от земли; #36 — первый кадр в существующем alpha RUN. | Нет опорной фазы толчка из RACE_STAND. |
| #37–38 | Продолжение прыжка; верх головы/ушей достигает границы исходного кадра. | Дополнительный дефект для полной последовательности #36–60. |
| #39–60 | Активный разбег в боковом ракурсе. | Можно использовать как *хвост* нового START после подходящего входного движения; нельзя начать непосредственно из стойки. |
| #61–72 | Утверждённый повторяемый RUN. | Оставить без изменений. |
| #73–120 | Дальнейший бег и изменение освещения/тона. | Нет возврата к боковой стойке или первого толчка. |

Совпадение силуэта не доказывает непрерывности: например, #50 близок к стойке по общему контуру, но передние лапы уже подняты и корпус движется в галопе. На #36 лапы выше линии опоры стойки примерно на 36 исходных пикселей, а туловище и морда смещены вправо. Локальный сдвиг спрайта исправит лишь положение картинки, не создаст отсутствующий перенос веса и контакт лап. Удержание стойки или retiming также не решают этот разрыв. В #37–38 информация у верхнего края отсутствует в самом MP4.

## Окно Race V3

START длится 1 секунду. Исходные #36–60 занимают 25 кадров (примерно 1,04 секунды при 24 FPS), затем #61 входит в рабочий RUN. Этот отрезок мог бы дать хвост ускорения, но отсутствует вход из боковой RACE_STAND и есть обрезание ушей в #37–38. Подгонка его до окна START без настоящих первых шагов только маскирует проблему; физика Race V3 не менялась.

## Следующее решение

1. **Рекомендуется:** получить отдельный короткий боковой клип первого толчка из точной утверждённой RACE_STAND, с четырьмя опорными лапами в начальном кадре, переносом веса и переходом к согласованной фазе существующего RUN (ориентир — область #39–40, точную границу определить по полученному клипу). После визуальной приёмки обработать alpha и проверить укладку в 1-секундное START без изменения физики. Это потребует отдельного разрешения на генерацию/производство нового движения.
2. Альтернатива без генерации — явно согласовать видимый монтажный скачок RACE_STAND → #36/39. Он не удовлетворяет нынешнему критерию естественного старта, поэтому не выдавался за готовый asset.

Вариант с фронтальной стойкой для #24–34 потребовал бы отказаться от утверждённой боковой RACE_STAND и сломал бы совместимость со STOP; в рамках задачи не рассматривается. RUN №4, все пять категорий скорости, положение относительно физического перемещения и игровой MP4 не проверялись, потому что входной переход блокирует сборку честной игровой демонстрации. Новая alpha-обработка не запускалась: нужного входного движения в исходнике нет.
