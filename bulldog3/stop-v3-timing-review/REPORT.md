# Bulldog №3 — проверка STOP в окне Race V3

Исходная точка: принятый монтаж коммита `9aaf30f`. Это проверка тайминга; игровой STOP, alpha и интеграция пока не выполнялись.

## Фактические границы

| Участок принятого монтажа | Исходные кадры | Длина |
| --- | --- | ---: |
| RUN перед торможением | #61–72 × 2, затем #61–68 | 32 кадра / 1,333 с |
| Активное торможение | STOP #18–47 | около 30 кадров / 1,250 с |
| Окончание движения к стойке | STOP #48–72 | 25 кадров / 1,042 с |
| Принятый STOP целиком | STOP #18–72 | **55 кадров / 2,292 с** |
| Окно STOP в изолированной Race V3 | `STOP=37/24`, кадры #0–36 | **37 кадров / 1,542 с** |

В игровом окне при обычной скорости 24 FPS помещаются только исходные STOP **#18–54**. На #54 лапы уже стоят, но голова, уши, взгляд и морда ещё меняются. Прямой переход #54 → утверждённый `RACE_STAND` даёт заметный скачок позы. Кадры #55–68 содержат движение головы и глаз; #68 уже близок к стойке, но #69–72 лучше согласуются с утверждённым конечным изображением. Ускорение этой фазы или пропуск кадров не проверены пользователем и меняют принятый монтаж. Активные движения лап #18–47 оставлены нетронутыми.

Для сравнения: [контактный лист](STOP_WINDOW_COMPARISON.png) показывает #54, #68, #72 и RACE_STAND крупно и с размером спрайта V3 207×116. [Диагностический MP4](DOG3_STOP_FORCED_37F_DIAGNOSTIC.mp4) показывает вынужденную обрезку после #54. Это **не игровой результат**: видео сохраняет исходные непрозрачные фоны, показывает неподвижную относительно экрана собаку и служит только для проверки скачка позы. Итоговый принятый монтаж остаётся в [предыдущем отчёте](../stop-review-v1/REPORT.md).

## Минимальное изменение для сохранения принятого движения

Согласовать для Bulldog №3 STOP **55 кадров вместо 37**: добавить **18 кадров / 0,750 с**. Тогда исходные #18–72 проигрываются при 24 FPS без обрезки и ускорения, затем показывается утверждённый RACE_STAND. Это минимальный вариант, сохраняющий *весь уже принятый монтаж* без нового движения и без нового стыка. Изменение длительности STOP в Race V3 может затронуть траекторию, финишное время и порядок мест, поэтому его нельзя вносить без отдельного согласования. Если единое окно 37 кадров обязательно для всех собак, потребуется отдельно согласовать локальный тайминг или новый монтаж, который не гарантирует прежнее качество.

## Стык RUN → STOP

Принятый вход остаётся RUN #68 → STOP #18. Оценка по силуэту исходных кадров: морда в STOP смещена вправо примерно на 56 px изображения 1276×720 (около 9 px спрайта V3), центр силуэта — примерно на 38 px (около 6 px спрайта), низ лап — вверх примерно на 17 px (около 3 px спрайта). Мировую координату менять не нужно. После создания alpha можно проверить **только локальное положение рисунка внутри спрайта**: начальное смещение STOP примерно −38 px по X и +17 px по Y относительно исходного изображения с плавным сведением к нулю к стойке. Это предварительная оценка, не утверждённая коррекция. Одной трансляцией нельзя одновременно точно совместить морду и все лапы; проверка по реальному alpha и в движении обязательна.

## Статус

Выявлена блокирующая проблема тайминга. В соответствии с заданием alpha, изолированная лаборатория и итоговый игровой MP4 **не создавались** до решения по окну STOP. Исходники, принятый монтаж, Race V3, production и другие собаки не изменены. Kling, merge и deploy не запускались.

Диагностический MP4 проверен через `ffprobe`: H.264, `yuv420p`, 1276×720, 24 FPS, 93 кадра, 3,875 с, `faststart`. Браузерная проверка новой alpha пока неприменима: alpha не создана.
