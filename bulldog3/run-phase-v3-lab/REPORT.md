# Рокки — визуальная фазировка RUN перед STOP и FINISH

**Статус:** изолированный технический кандидат для визуальной приёмки. Принятые RUN, STOP, RACE_STAND и RACE_START не изменены. Production и физика Race V3 не менялись.

## Решение

Простой постоянный сдвиг цикла на 6 кадров ставит перед STOP исходный RUN #68, но ломает уже принятый стык RACE_START → RUN: после утверждённого START пришлось бы сразу показывать #58 вместо #52 либо перескакивать с #62 на #69 на границе вступления и петли. Поэтому такой вариант не использован.

В этой лаборатории первые 23 игровые ячейки RUN остаются прежними: `#52–62`, затем `#63–72, #61–62`. В дальнейшем на каждом длинном RUN-отрезке выполняются ровно **шесть** пропусков одного кадра в пределах утверждённой 12-кадровой петли. Каждый пропуск приходится на переход **source #64 → #66** вместо #64 → #65 → #66. Между ними остаётся обычный порядок кадров при 24 FPS. Последний пропуск происходит минимум за **39 кадров (1,625 с)** до торможения; прямо перед STOP/FINISH петля снова идёт равномерно. Последняя игровая ячейка RUN №22 визуально показывает исходный **#68**, затем идёт неизменённый STOP #18.

| RUN-отрезок | Длина | Ячейки, после которых пропущен #65 | Последний кадр до STOP |
| --- | ---: | --- | --- |
| Самый короткий V3 | 155 | 36, 59, 70, 81, 104, 115 | #68 |
| Показанный в полной цепочке, пресет A / собака 2 | 239 | 48, 83, 106, 129, 164, 187 | #68 |
| Длинный чистый забег, пресет A / собака 1 | 1007 | 156, 299, 430, 573, 704, 847 | #68 |

Полное отображение для всех отрезков есть в [`verification.json`](verification.json). Алгоритм находится в [`phase.mjs`](phase.mjs). Он меняет только индекс отображаемого RUN-спрайта, получая мировую позицию и состояние из неизменённого `stateAt` модели V3. `alignedStopTime` и `nextStopTime` проверены на фактически построенных гонках пресетов A/B/C: **38 RUN-отрезков** заканчиваются старым исходным #62 и новым #68, непосредственно перед STOP или FINISH_DECELERATE. Время событий, `crossing`, `complete` и порядок мест не меняются.

## Стыки и измерения

Измерения сделаны по alpha-силуэтам уже утверждённых спрайт-листов, в одинаковых ячейках 178×100. IoU — вспомогательная оценка; игровые MP4 нужны для оценки движения лап.

| Стык | IoU | Вывод |
| --- | ---: | --- |
| RACE_START последняя ячейка → RUN #52 | 0,776 | Ранее принятый стык сохранён. |
| RUN #62 → #63, граница петли | 0,793 | Ранее принятый порядок сохранён. |
| Коррекция фазы RUN #64 → #66 | 0,756 | Одна пропущенная фаза; возможен небольшой импульс шага. |
| Прежний RUN #62 → STOP #18 | 0,583 | Заметный конфликт позы и контакта лап. |
| Новый RUN #68 → STOP #18 | **0,845** | Опора лап и линия земли совпадают; предыдущая STOP-лаборатория использовала именно эту фазу. |
| STOP последняя ячейка → RACE_STAND | 0,998 | Принятый стык не менялся. |
| RACE_STAND → RACE_START первая ячейка | 0,963 | Принятый стык не менялся. |
| Повторный RACE_START → RUN | 0,776 | То же самое вступление RUN, фазовые коррекции начинаются позже. |

В [полной цепочке](DOG3_ROCKY_RUN_STOP_STAND_START_RUN.mp4) использован настоящий сценарий пресета A, собака 2: RUN до **11,458 с**, STOP **11,458–13,000 с** (37 кадров), стойка вместо будущего действия BUTTERFLY **13,000–18,042 с** (121 кадр), повторный START **18,042–19,042 с** (24 кадра), затем RUN. Стойка в окне BUTTERFLY — только диагностический способ проверить повторный старт Рокки, не реализация этого действия.

В [финишном сценарии](DOG3_ROCKY_RUN_FINISH_STAND.mp4) использован пресет A, собака 1: RUN до **43,458 с**, утверждённый STOP как FINISH_DECELERATE **43,458–45,000 с**, затем неподвижная RACE_STAND 2 секунды. `crossing` остаётся **43,008 с**, как в неизменённой модели. Это проверка визуального переиспользования STOP, без отдельной FINISH-анимации.

Пять диагностических профилей скорости `0,75× / 0,90× / 1,00× / 1,10× / 1,25×` проверены в режиме **«Пять категорий скорости»** локальной лаборатории через тот же `stateAt`; для каждого проверены непрерывность мировой координаты, окна START 24 кадра и STOP/FINISH 37 кадров, исходный #68 на входе в торможение. Дополнительно проверены все реальные V3-пресеты A/B/C. Профили служат только изолированному визуальному тесту и не добавлены в production.

## Ограничение кандидата

Фазовый сдвиг достигается шестью однокадровыми пропусками RUN за каждый длинный RUN-отрезок. На игровом размере это значительно мягче прежнего скачка RUN #62 → STOP, но в момент #64 → #66 остаётся потенциально заметный однокадровый импульс лапы. Изображения не интерполировались, фазы не переставлялись, скорость прямо перед торможением не ускорялась. Кандидат требует визуальной оценки пользователя; его нельзя считать автоматически принятым для production.
