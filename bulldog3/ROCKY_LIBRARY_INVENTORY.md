# Рокки (Bulldog №3) — инвентаризация анимаций

Обновлено после подготовки изолированной лаборатории STOP. Это статусы **только Рокки**; наличие исходника или технического кандидата не означает приёмку полной игровой цепочки.

| Анимация / опора | Что есть | Статус для игры |
| --- | --- | --- |
| RUN | Исходный `assets/incoming/bulldog_3_run.mp4`, прозрачный alpha-v2 в архиве обработки, рабочий цикл source #61–72 | Материал и цикл доступны; отдельная художественная приёмка RUN loop и всех его применений ещё не зафиксирована |
| STOP | Kling-исходник из ветки `claude/nifty-johnson-assbj5`, утверждённые source #18–72; пользователь принял раздельный тайминг до 37 кадров | Alpha и изолированная лаборатория подготовлены; итоговый игровой вид ожидает визуальной приёмки |
| RACE_STAND | `race-stand-generation-v1/DOG3_RACE_STAND_GENERATED_01.png` принят как рабочий референс; прозрачная производная для лаборатории | Поза утверждена как референс; её отдельное использование в production ещё не согласовано |
| IDLE | `assets/incoming/bulldog_3_idle.mp4`; внутренний loop #34–58 предложен | Исходник есть; петля требует приёмки, alpha нет |
| SELECTED | `assets/incoming/bulldog_3_selected.mp4` | Исходник есть; alpha и выход из реакции не подготовлены |
| FRONT_STAND | IDLE source #0 в `reviews/asset-intake/` | Статичный референс с фоном, не игровой alpha asset |
| BRAKE_POSE | `brake-pose-generation-v1/DOG3_BRAKE_POSE_GENERATED_01.png` | Только ориентир позы; около 20% шире RACE_STAND, не кадр STOP |
| Первый START | Нет подтверждённого клипа | Требуется отдельная будущая работа; переход с выбора на гонку в этой задаче не разрабатывался |
| RACE_START после событий | Нет подтверждённого клипа | Требуется до полной цепочки STOP → RUN |
| BUTTERFLY, SNIFF_PEE, ROLL | Нет подтверждённых клипов для Рокки | Не готовы |
| RETURN | Нет | Нужен только если фактический конец будущего действия не совпадёт с RACE_STAND |
| FINISH | Переиспользование STOP ещё не проверено для Рокки | Отдельный FINISH потребуется только при неудачной проверке STOP на финише |

Изолированная лаборатория проверяет **RUN → STOP → RACE_STAND** в пяти темпах. Она не свидетельствует о готовности SELECTED → первый START, действии после STOP или финише. Чужие библиотеки и production не изменялись.
