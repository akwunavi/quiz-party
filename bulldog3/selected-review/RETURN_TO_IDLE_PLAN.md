# Предварительное ТЗ: SELECTED → RETURN_TO_IDLE → FRONT_STAND

Исторический черновик до утверждения SELECTED. Актуальные референсы, параметры и условие проверки цены перед генерацией через Claude — в [RETURN_TO_IDLE_FINAL_PLAN.md](RETURN_TO_IDLE_FINAL_PLAN.md).

**Только план после визуальной приёмки SELECTED. Kling не запускался.**

## Почему нельзя надёжно собрать из имеющихся кадров

Конец SELECTED #120 — устойчивый, но это улыбка и более широкая передняя стойка; FRONT_STAND #0 — серьёзное выражение, голова и корпус расположены иначе. Прямой стык заметен по лицу и лапам. В исходном SELECTED нет самостоятельного участка #120→FRONT_STAND. [Диагностический полный реверс](DOG3_RETURN_REVERSE_DIAGNOSTIC_NOT_FOR_USE.mp4) достигает #0, но проходит всю реакцию назад: после удержания улыбки Рокки в обратном порядке убирает шаг лапы, возвращает улыбку через удивление и повторяет раннее моргание. Это выглядит как перемотка, а не спокойное возвращение в стойку. Реверс **не рекомендуется как asset**. Пропуск середины создал бы крупный скачок позы.

## Один будущий запрос Kling

| Поле | Предложение |
| --- | --- |
| Режим / модель | `image_to_video`, `kling-video-v3_0` |
| FIRST | [SELECTED source #120](DOG3_RETURN_FIRST_SELECTED_120.png), последний устойчивый кадр улыбки |
| LAST | [утверждённый FRONT_STAND #0 на том же студийном фоне](DOG3_RETURN_LAST_FRONT_STAND_000.png); собака взята из неизменённого [alpha PNG](../idle-alpha-lab/assets/DOG3_FRONT_STAND_ALPHA.png) |
| Длительность | 3 с на естественную мимику и небольшой возврат лап; реальный полезный диапазон определить по результату |
| Разрешение | 720p, стандартный исходный формат около 1276×720 / 24 FPS подтвердить после генерации |
| Прочее | одна сцена, без звука, multi-shot off; FIRST и LAST как фиксированные крайние референсы |
| Цена | ориентир **18 кредитов**: столько стоила подтверждённая 3-секундная генерация Kling v3.0/720p в [логе Фрэнка](../../bulldog1-frenk/KLING_LOG.md). Текущая цена не проверена и может измениться; перед запуском её нужно уточнить. |

[Английский промпт](RETURN_TO_IDLE_PROMPT.txt) описывает только спокойное расслабление после выбора и возврат в точную FRONT_STAND, без новой хореографии.

После будущей генерации потребуется визуально проверить начало от SELECTED #120, окончание в FRONT_STAND #0, четыре опоры, непрерывность перемещения передних лап, лицо/окрас и отсутствие изменения масштаба. Затем отдельно решить alpha, монтаж и цикл IDLE. Текущая работа их не начинает.
