# STOP Френка на трассе: варианты A / B / C (визуальная проверка)

Что это: локальный воспроизводимый тест. **Не** страница игры: офлайн-пересборка `draw()` из `dog4-v3-lab/app.mjs` для одной дорожки (настоящая арена V3, геометрия `layout.json`, тень, размер и якорь спрайта) с **настоящими кадрами Френка** (alpha) и, для сравнения, **настоящими спрайтами Bulldog №4**. Физика — настоящий V3 (копия модели с переопределением длительностей STOP и BUTTERFLY только для полосы 0, оригиналы не тронуты). Визуальный слой — P3-прототип `race-v3-p3-lab` без изменений.

Условия одинаковые у всех вариантов: seed 1069078 (полоса 1: NORMAL, одно событие BUTTERFLY на 51 % трассы), та же скорость и план, одна арена. Различие только в физическом окне STOP: **A** 37/24 с (остаток клипа 38–73 — неподвижный хвост), **B** 63/24 с (хвост 64–73), **C** 73/24 с (весь клип внутри STOP). Окно BUTTERFLY — «по размеру» (хвост + 93 кадра + `lead` 3), поэтому усечений нет; START канонический 1 с, `lead` 3.

Файлы (`out/`): `FRENK_STOP_A_B_C_vs_DOG4_annot_x1.mp4` (2×2: Bulldog 4, A, B, C; красная линия — физический якорь, синяя — остановка двигателя, чёрные риски каждые 10 px — измерительные, **их нет в игре**), `..._clean_x1.mp4` (то же без наложений), `..._annot_STOP_PHASE_x0.5.mp4` (фаза торможения вдвое медленнее), `STOP_A_B_C_CONTACT_SHEET.png`. Рядом: `STOP_VARIANTS_CHART.png`, `stop_visual_measurements.json`, `timelines.json`, `REPORT.md`.

Воспроизведение: `prepare.sh T && cd T && REPO=<корень репозитория> node export_timelines.mjs` → `timelines.json`; `render_stop_demo.py` (кадры); `measure_stop_demo.py` (измерения); `make_contact_sheet.py`. Входы вне репозитория: арена и спрайты Bulldog 4 (читаются из git, `dog4-v3-lab/assets/`, не меняются) и кадры RUN Френка #87–98 (рабочая распаковка `dog1-run-alpha.webm`, в этой ветке файла нет).
