## Задачи по приоритету

### 1. Выбор в любой момент IDLE → SELECTED (ближайшая задача, без Kling)
* **Зачем:** решение пользователя от 22.10 для всех пяти собак — после выбора доиграть движение IDLE до совместимой стойки, без мгновенного переключения и кроссфейда. У Фрэнка проверен только выбор на границе цикла (`selection_alpha_v1/player/`).
* **Входы:**
  * утверждённые `selection_alpha_v1/DOG1_IDLE_v1_alpha_f8-f118.webm`, `DOG1_IDLE_v1_alpha_loop220.webm`, `DOG1_SELECTED_v1_alpha_f20-f121.webm`;
  * исходники `assets/sources/bulldog_01_{idle,selected}.mp4`.
  * Образец механики (не копировать один в один) — `bulldog2/lab_select_v1/selection.mjs`.
* **Уже измерено в аудите** (средняя разница кадров 319×180):
  * с началом SELECTED (f1–f20) совпадают только IDLE **f8–f13** (0,72–0,92, лучший вход — SELECTED f4–f9) и f14–f15 (1,1–1,3). Медиана шага IDLE — 0,81.
  * IDLE f12 ↔ SELECTED f20 — 1,17 (`return_to_idle_prep/PLAN.md`).
  * Совместимая стойка в цикле одна — его начало f8–f13.
* **Действия:**
  1. Описать путь выхода. Цикл IDLE и так ходит туда-обратно, поэтому после клика IDLE идёт к f8–f13 по ближайшему направлению своими кадрами, затем вход в SELECTED.
  2. Измерить ожидание. По предварительной оценке, худший случай — клик у разворота f118: около 105 кадров ≈ **4,4 с**. Это дольше утверждённых у Зефира 2,42 с, поэтому длительность ждёт решения пользователя.
  3. Выбрать точку входа в SELECTED:
     * (a) вход в утверждённый f20 из IDLE f12 (1,17) — без новой alpha;
     * (b) вход в SELECTED f4–f9 (0,72–0,92) — нужна alpha кадров SELECTED f1–f19 тем же конвейером. Сам SELECTED не меняется, добавляется только стоячий вход, как у Зефира.
  4. Собрать лабораторию по образцу Зефира: выбор в 4–6 фазах IDLE, полная цепочка IDLE → выбор → стойка → SELECTED → RETURN → IDLE с f9. Замеры стыков (центр, линия лап, высота).
* **Результат:** `selection.mjs` для Фрэнка, лаборатория, MP4 выбора в разных фазах, отчёт с картой ожидания.
* **Kling:** не нужен. **Стоимость:** 0 кредитов (CPU: вариант (b) ≈ 20 мин alpha).
* **Приёмка:**
  * без кроссфейда;
  * стык IDLE → SELECTED не больше обычного шага IDLE;
  * центр и линия лап ≤ 1 px;
  * IDLE, SELECTED и RETURN не меняются;
  * пользователь принимает максимальное ожидание.
* **Зависимости:** нет. Вопрос пользователю: допустимое ожидание (до 4,4 с) или искать другую стратегию без генерации.
