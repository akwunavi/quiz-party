## 3. Проверенные методы (кроме смены точек входа/выхода)
- **Выравнивание положения.** Горизонтальный сдвиг RUN-кадров с плавным затуханием (кубический Hermite, 12–24 кадра, нулевая начальная скорость): для исходного стыка убирает шаг −15,5 → −1,5 (IoU 0,867, цвет 37,7), но излом вертикальной скорости остаётся (вертикальная коррекция потребовала бы 43 px исх. = 7 px холста, IoU падает до 0,795, корпус «всплывает»): отвергнуто. Для f35→#88 сдвиг не нужен (шаг cx −9,4 — обычный шаг цикла 8,7), а сдвиг на 8,5 px увеличил разрыв потока 18,3 → 19,9: не применён.
- **Короткий мостик (оптический поток, 2 промежуточных кадра).** Доля полупрозрачных пикселей 0,13–0,16 против 0,04–0,07 у обычных кадров, двойные уши и лапы (`analysis/morph_f35_88.png`, `morph_f37_90.png`): отвергнуто. Растворения не использовались.
- **Согласование фаз.** Вход n перебран по всему циклу #87–#98 (выше); фаза лап в выбранном стыке совпадает (сбор → вынос).
- **Локальное изменение скорости.** Отдельно не применялось: смена точки входа уже даёт сдвиг фазы, а ускорение/замедление первых кадров RUN меняло бы темп цикла (12 кадров) относительно игровой скорости без явной пользы. Не тестировалось.

## 5. Вывод и ограничения
**Рекомендую улучшенный стык f35→#88 как кандидат на приёмку**, исходный f37→#90 остаётся резервом. Основания: лучшая кинематика (подъём не «обрывается»), поток в 1,7 раза ровнее, нет сдвигов, мостиков и растворений. Цена: силуэт на кадре стыка похож чуть хуже (0,816 против 0,858, но выше нормы внутри клипов) и **разгон короче на 2 кадра (31→29 кадров между толчком и RUN, 1,29 → 1,21 с)**: это метаданные длительности разгона, физику гонки и результаты не менял и не проверял; перед включением в игру нужна отдельная проверка (в preview компенсация положения пересчитана на 29 кадров по той же формуле N1). Если менять длительность разгона нельзя, оставить исходный (его горизонтальный шаг можно сгладить сдвигом, вертикальный излом не исправляется).
Не исправляется без генерации: разница в размахе прыжка и в тёмпе (gen3 прыгает выше, период 13 кадров против 12), разница резкости (gen3 чёткий, RUN с motion blur), разная ширина пасти.
Дополнительных версий SNIFF_PEE не создавалось.
