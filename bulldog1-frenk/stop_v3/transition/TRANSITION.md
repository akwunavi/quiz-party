## Ответ

## Что происходит на стыке (лист `bridge_phases_sheet.png`)

* RUN #94–96: корпус почти горизонтален, передние лапы вытянуты вперёд, задние отброшены назад, голова вперёд. #96 — касание земли (низ силуэта ≈ y 688).
* RUN #97–98: «сбор» — корпус сжимается, задние лапы подтягиваются под таз, ось корпуса уходит с −14,6° до −24°.
* STOP V3 f1: уже **готовая тормозная стойка** — корпус приподнят, передние лапы далеко впереди и упёрты, одна задняя поднята, резкая детальная шерсть.

Между #96 и f1 не хватает фаз:
1. перенос веса на передние лапы после касания (плечи чуть опускаются);
2. задние лапы выносятся вперёд под таз и ставятся;
3. смена наклона корпуса с горизонтального на приподнятый;
4. передние лапы переходят из «вытянуты в полёте» в «упёрты»;
5. стиль: RUN-кадры размыты (движение), V3 резкие — отдельный разрыв по текстуре.

## Проверка имеющихся кадров

* IoU силуэтов (с подбором сдвига): f1 ↔ RUN #96 = 0,62; ↔ RUN #97 = 0,645; ↔ старый STOP v1 f1 = 0,645.
* Поиск среди 339 кадров (RUN #40–120, STOP v1, RACE_START gen3/v1, FIRST_START): максимум 0,67–0,68, и это приседания RACE_START, а не приземления.
* Норма: соседние кадры RUN 0,79–0,88, через кадр 0,73–0,79. Стык #96→f1 хуже нормального шага через кадр.
* Вставка RUN #97/#98 перед f1 даёт ≈ +0,02 IoU и не убирает разрыв стиля и позы.

Вывод: подходящих кадров ни в цикле RUN, ни в STOP v1, ни в стартовых материалах нет.
