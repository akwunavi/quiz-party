# Решения по Френку (13.10.2026) и почему

Это решения пользователя и мои технические выводы к ним. Менять их можно только по явной причине и с новым измерением.

1. **Френк = Bulldog №1; его внешний вид утверждён.** Идентичность берётся из master, а не из Bulldog №4. У пяти собак допустимы разные ракурсы, их заставлять повторять геометрию №4 не нужно.
2. **Архитектура B (две стойки) выбрана вместо A (одна передняя).** В оригинале Френк стоит анфас и бежит вправо. В варианте A каждое событие начиналось и кончалось бы в передней стойке, значит после каждого STOP нужен почти полный 3D-разворот из бега в анфас и обратно; это самая дорогая и рискованная генерация, и повторялась бы на каждом событии. В B один раз нужен RACE_STAND (боком вправо), которой не существует в исходниках: все кадры после разворота — фазы галопа (проверено по контактам и резкости).
3. **RACE_STAND v3 утверждена** (v1 запасная, v2 отвергнута): ракурс ближе к ¾, внешность держится. Размеры и координаты — ориентиры для позднего выравнивания, а не повод деформировать собаку.
4. **Первый START берётся из оригинального RUN**: стойка анфас #0–24, разворот #28–36, разгон #38–63, затем стык в цикл #87–98 (кадр #64 ≈ #87, IoU 0,956). Начало с #25: движение стартует примерно на #25–26. Кадры #28–36 не вырезаются (это разворот корпуса вправо).
5. **RUN цикл #87–98** (период галопа 12 кадров = 0,5 с). Стык последнего кадра с первым не хуже обычного шага цикла; #95–106 хуже (низ лап перескакивает на 22 px при допуске 21).
6. **STOP: START = кадр #97** (передние лапы вынесены к земле, зад собран низко); следующие кадры цикла — постановка задних лап под корпус, то есть реальная физика торможения. #88 хуже (задние лапы «двоятся»), #98 — запасной.
7. **Коррекцию масштаба/цвета/резкости START и END не делали.** Голова одного размера (ухо→зрачок 201 против 199 px, ухо→низ морды −4%); разница высоты 18% — поза (приседание ↔ стойка). Цвет: END (R−B≈38) ближе к master (≈40), чем START (≈51); подгонять END под START значит уходить от master, а START менять нельзя (стык с RUN). Резкость (24 против 570 по лапласиану) — физика остановки, размытие уходит само. Меняли только положение END (+сдвиг вправо для продвижения вперёд, −6 px вверх).
8. **Хореография STOP:** продвижение вперёд внутри кадра допустимо, камера неподвижна, два-три сокращающихся шага «как получится естественно», короткая финальная стойка. Параметры Kling: `kling-video-v3_0`, 3 с, 720p, звук и multi-shot выключены, одна генерация.
9. **STOP v1: вариант A (полный), а не сокращённый B.** Входная точка B (f11 после #96) не хуже обычного шага цикла (IoU 0,717 против 0,683 в среднем), но экономит только 0,42 с из 3,04 с; всё глубже (f20+) даёт стык заметно хуже обычного шага (IoU 0,58–0,60). Решение пользователя: A.
10. **Alpha:** восстановленный конвейер принят. Super-sampling 2× в matting включён по умолчанию (приблизил результат к утверждённому alpha RUN: ошибка кромки 28,2 → 22,3, при 3× выигрыша нет, а время ×4).
