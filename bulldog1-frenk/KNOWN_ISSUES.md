# Известные дефекты и открытые риски (Френк)

## Источники (не ошибки вырезания)
- **STOP v1.** Первые ~48 кадров (около двух секунд) продолжается галоп почти в полную силу: разница между соседними кадрами держится 10–14 до кадра ~45 и падает только в конце. Остановка «втиснута» в кадры ~50–60; задняя лапа в 50–53 истончается и подменяется нормальной парой лап (морфинг). Пользователь принял как естественное торможение на глаз; в игре после цикла RUN может читаться как «бежал и вдруг встал». Не исправлять дорисовкой.
- **STOP v1, лицо.** В кадрах ~25–41 морда темнеет и выглядит «злее», рот открыт; в 49–55 морда опущена. Внешность держится, но с дрейфом.
- **Размытие и «двойные» контуры лап** в быстрых фазах (особенно RUN #87–89, STOP 1–13): сохранены как в источнике.
- **Оригинальный RUN.** Камера не зафиксирована: с #42 уезжает фон (студийная стойка), собака плавает в кадре по фазе шага (ширина ~280–400 px). В игре ставить по опоре лап, а не по рамке.
- **IDLE** не бесшовный цикл (первый/последний кадры 4,3/255, 45 из 120 переходов почти неподвижны). **SELECTED** заканчивается позой с открытым ртом (11/255 от стойки), возврата в стойку нет: для гонки не годится.
- **RACE_STAND v3.** Задние лапы чуть подогнуты, спина слегка наклонена вперёд, ракурс ближе к профилю (около 10–15° от чистого профиля), в оригинале кадра справа была стойка света (убрана заливкой в END, исходник v3 не менялся).

## Интеграция
- **В STOP есть продвижение вперёд внутри кадра +92 px** (правый край 929 → 1021). Контракт V3 говорит, что в действии собака не перемещается, а START/STOP двигают якорь по физической кривой. Перед интеграцией решить, как якорь STOP привязывается к мировой позиции.
- **Масштаб разный у поз:** высота RACE_STAND ≈ 631 px, в беге ≈ 534 px на холсте 1276×720 (поза, не деформация). Калибровка масштаба клипов в игре отдельная.
- **Оригинал `bulldog_01_master.png` не получен как файл.** Есть копия 2000×1129 из чата (исходно WebP ~70 КБ, детали шерсти потеряны). Все генерации шли от неё.
- **Ссылки Kling живут ~24 ч.** Всё, что нужно, сохранено в `assets/`.

## Alpha-конвейер
- Только CPU: ≈ 11–15 с/кадр нейросеть + 4–7 с matting; 5-секундное видео ≈ 28 минут.
- Floor-тень вырезается вместе с фоном. В START #34 тень-лента между лапами убрана опцией `--floor-shadow`; в **#36** остаётся бледное смазанное пятно между лапами и тёмная полоса вдоль нижнего края (не отделимы без цветового фильтра, см. `plans/FIRST_START_REPORT.md`). В #34 после среза видны прямые края и тонкая светлая линия.
- Размытие, морфинг и «двойные» лапы источника конвейер не чинит.
- Chroma 4:2:0 в VP9 слегка смягчает цвет на кромке (неизбежно для `yuva420p`).

## Интеграция в V3 (проверка 13.10.2026)
- Нет смещения на клип → RACE_START (START-кадр −125) телепортирует собаку на 20,3 экранных px; нужен `shiftFrom/shiftTo` или запекание в видео. Подробно `plans/RACE_START_COORDINATES_REPORT.md`.
- В V3 глобальные `spriteAnchorX=148` (задний контур стойки Dog4), длительности START 1 с / STOP 37 кадров и фазы входа/выхода RUN (прелюдия 11 + цикл 12): для Френка нужны метаданные клипа (якорь ≈155 px холста, START 3 с, STOP 73 кадра, вход в RUN #91, выход перед #97).
- STOP несёт +111 px (по центру масс) собственного перемещения (+18 экранных px).

## RACE_START V1 (13.10.2026)
- Последний кадр не равен RUN #90 (IoU 0,564, цвет 30,7); прямого стыка с циклом в пределах обычного шага нет (лучший f49→#90: 0,573/30,1).
- В начале ≈1,2 с подкрадывания (дрейф назад ≈59 px), потом рывок f29–34 с тёмным прищуренным лицом; ритм 9 кадров вместо 12.
- Нет компенсации координат, которая убрала бы весь обратный дрейф (лучший расчёт −52 px/с); нужен профиль под принятый клип.

## RACE_START V1 salvage (13.10.2026)
- В клипе V1 вырезать нельзя: присед f12–27 (≈0,7 с) и рывок f28–36 с тёмным лицом — из приседа нет прохода к реальным кадрам RUN. Прямой разрез стойка→#90 даёт видимый скачок позы, несмотря на приемлемые числа.
- Короткие гибриды (V4/V5) непригодны при нынешнем движке: чистое продвижение за START отрицательное или скачок профиля.

## RACE_START V2 (13.10.2026)
- V2: присед и прищур f13–f21 повторяются несмотря на промпт «без приседания», толчок только с f20–21 (≈0,85 с ожидания); лапы скользят назад на 23–44 px до толчка; ритм 9 кадров; цвет клипа темнее RUN на ≈9 %.
- Шов с RUN только поздний (f64→#91); из присеста/толчка в RUN нет перехода.
