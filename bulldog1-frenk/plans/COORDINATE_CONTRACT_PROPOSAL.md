# Предложение: универсальный контракт координат для пяти собак (13.10.2026)

**Только предложение, ничего не внедрено. V3 и механика гонки не менялись; решение за пользователем и Codex.** Основание — `RACE_START_COORDINATES_REPORT.md`, `TRACK_DIAGNOSTIC_REPORT.md` (диагностика Френка с адаптером на физике V3).

## Принципы
1. **Мировая позиция собаки — только `progress`.** Видео не задаёт положения на трассе. Это уже так в V3; не меняется.
2. **Положение спрайта = физический якорь + смещение клипа.** Смещение — данные клипа, а не поведение движка. Один постоянный smoothstep на все случаи не вводится: у Френка профиль зависит от лап и от дрейфа клипа (N2 показал, что «выведенный» профиль не лучше пропорционального, когда дрейф лежит до толчка).
3. **Смещение клипа проверяется офлайн, до игры.** Правило приёмки: после первого отрыва лапы экранная скорость спрайта (сглаженная на один шаг) не отрицательна; до отрыва `shift` постоянен (лапы стоят — спрайт едет вместе с лапами). Остаточное скольжение лап, которое дало сам клип, не гасится кривой, а записывается в известные дефекты.
4. **Длительности и фазы — метаданные клипа, не глобальные константы.** У Френка START 1,79 с (43 кадра), STOP 3,04 с (73 кадра), у №4 START 1 с, STOP 37/24 с.

## Поля (на собаку и на клип)
```
dog: { id, anchorSrcX, srcFrame:{w,h}, scaleCanvasPerSrc, groundLineSrc, standCenterSrcX }
clip: {
  id, file, frames, fps | variableFps[], durationSec, loop?,
  enterPhase, exitPhase,                     // например runEntryFrame #90, stopEntryFrame (кадр цикла, с которого входим в STOP)
  contactRelease: frameIndex,               // первый отрыв опорной лапы (для START) — момент старта скорости
  velocityRamp: { startFrame, endFrame },   // где скорость движка меняется (START/STOP), вместо константы 1 с
  bakedTravelSrc: number,                   // перемещение внутри кадра (у STOP Френка +111 исходных px)
  shift: { perFrameSrcPx: number[] }        // смещение спрайта на каждый кадр (0 везде для большинства клипов)
}
```
Для клипов без смещения `shift` пропускается (0). `bakedTravelSrc` нужен модели для сравнения мест (событие происходит на `bakedTravel·scale` впереди физической точки: у Френка +18 px холста).

## Правила проверки (скрипт офлайн, по клипу)
- шов на входе/выходе: |скачок центра| ≤ шаг цикла RUN, на переходе событие↔START `shift(0)` совпадает с положением стойки;
- условие выполнимости START: `ΔEngine ≥ shift(release) + cx(release) − cx(join)` (исходные px; `ΔEngine` — путь движка за весь интервал от отрыва до стыка с RUN). У Френка gen3: 125 + 543 − 609 = 59 px; при разгоне за 1,29 с (N1) ΔEngine = 111 px, при разгоне до f20 и дальше крейсерской скоростью (N3) = 175 px, то есть условие выполнено в обоих вариантах (у V2 нужное было 1,22 с). Условие необходимое, но не достаточное: скольжение лап клипа до отрыва условие не лечит;
- метрика отката: максимум «положение сглаж. − его бегущий максимум» после `contactRelease` ≤ 1 px;
- отдельно фиксируются: скольжение опорной лапы до отрыва, дельта цвета ΔE к циклу RUN и к стойке.

## Что меняется в V3 (если примут)
- `sprite()` рисует с `x − spriteAnchorX + shift(frame)·scale` (одна строка, `shift` по умолчанию 0);
- START/STOP берут длительность и `velocityRamp` из метаданных клипа; формулы `2·(u³−u⁴/2)` и `2·(u−u³+u⁴/2)` остаются, меняется только базовый интервал;
- `spriteAnchorX` становится полем собаки (у Френка ≈ 155 px холста вместо 148).
Для Dog4 все `shift = 0`, длительности = нынешние константы: поведение №4 не меняется (можно проверить самотестом `adapter.mjs::selfTest`).

## Пример: Френк RACE_START (рабочий)
`velocityRamp: {startFrame: 12 (gen3 f7), endFrame: 42 (join) | 24 (вариант N3)}`, `contactRelease: 12`, `shift.perFrameSrcPx` — массив `race_start_working/RACE_START_WORKING.json → compensation.per_frame_C_START_window_N1/N3`; STOP `bakedTravelSrc: 111`, `velocityRamp: {0, 72}`.

## Риски
- массив `shift` у клипа без разрешения скользить назад: скольжение клипа остаётся (Френк: до 22 px холста за 0,5 с);
- если разгон по клипу короче константы (N3), физическая START у разных собак различается — это нужно согласовать с моделью мест;
- одинаковый контракт не гарантирует одинаковый вид: для каждой собаки собственный диагностический проход.
