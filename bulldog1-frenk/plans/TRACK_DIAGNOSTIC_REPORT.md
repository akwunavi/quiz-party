# Проверка Френка на игровой дорожке (13.10.2026)

Цепочка `RUN → STOP → RACE_STAND → вход V1 f1–f16 → gen3 f2–f37 → RUN #90–98 → цикл`, физика V3, масштаб V3 (спрайт 207 px на холсте 1920 — «игровой пиксель» ниже = пиксель этого холста). Инструмент и варианты: `track_diag/README.md`. V3, production, №3/№4 не менялись; Kling не запускался.

## 1. Скачки корпуса на переходах (канвас-px, шаг между соседними кадрами; нормальный шаг рядом ≈ 0,3–2)
| переход | N0 без компенсации | N1 / N2 / N3 |
|---|---|---|
| RUN → STOP | −0,6 | −0,6 |
| STOP → удержание | 0,0 | 0,0 |
| **удержание → вход f1** | **−20,3 (телепорт)** | 0,0 |
| вход → gen3 f2 | −0,6 | −0,7 |
| gen3 f37 → RUN #90 | −1,4 | −2,7 |
Вывод: единственный скачок — −20 px при отсутствии смещения на клип (подтверждено ещё раз); с профилем остаётся шаг 2,7 px на шве gen3→RUN (центр 609 против 594 в кадре: тот же порядок, что обычный шаг цикла).

## 2. Скольжение лап (отслеживается опорная передняя лапа по кадрам; `paw_tracking.json`)
Опорная лапа смещается назад **−3,7 px к f5 (0,17 с), −14 px к толчку f7 (0,29 с), до −22 px к f12 (0,5 с)**, пока не оторвётся (f13). Во всех вариантах одинаково: до толчка движок стоит, `C` постоянна, значит скольжение полностью собственное в клипе; после толчка убывание `C` гасит прибавку движка. На экране 22 px = около 11 % длины собаки за 0,5 с. Входной отрезок f1–f16 лапы не двигает (0,2 px). В STOP последние 15 кадров скольжение 0,5 px. **Остаточное скольжение не скрыто и не компенсировано.**

## 3. Цвет в реальном масштабе
ΔE (CIE76, среднее по alpha): gen3 f30–f37 против среднего цикла RUN **2,1** (против #90 — 3,3); соседние кадры самого RUN до 2,4; шов RUN #96 → STOP 3,9; **стойка против цикла 6,8**; V1 f16 против стойки 6,6. Самый заметный цветовой скачок цепочки — уже утверждённая стойка → вход (6,6), а не gen3 → RUN (2–3). На стилле `track_colour_stills.png` разницу gen3/RUN в масштабе игры не вижу. **Цветокоррекция не нужна.** Если захочется кандидат: усиление RGB ×(0,987, 0,964, 0,959) к gen3 f30–37; не применялось, оригиналы не тронуты.

## 4. Обратное движение
Максимальный откат положения (сглаживание 9 кадров): N0 **17,2 px**, N1/N2/N3 **9,3 / 9,25 / 9,1 px**; минимальная скорость −71,6 px/с у N0 и −24,5 px/с у N1–N3 (отрицательных кадров: 12 / 24 / 21 / 17). N2 не лучше N1: откат создаёт скольжение лап до толчка (−14 px), а огибающая работает только после толчка. Вывод: **обратное движение ≈ 9 px (4 % длины собаки) — это собственное скольжение клипа, а не кривая компенсации.** Предыдущее диагностическое превью считало с момента толчка и давало −12,8 px/с (−79 исходных px/с); теперь окно включает вход, поэтому −24,5 px/с.

## 5. Визуальное ускорение против физической скорости
Разгон по V3-кривой от толчка (N1) идёт 1,29 с; в момент, когда у gen3 уже полный галоп (f20, +0,54 с), движок на 38 % крейсерской скорости: ноги бегут вдвое быстрее, чем собака едет, ≈ 0,75 с. N3 (разгон до f20, 0,54 с) выравнивает, но тогда START физически короче константы V3 в 1 с; цена: чистое смещение собаки +5,7 px при движке +28,4 px (спрайт держится позади физической точки), откатных кадров 17 вместо 24. Решение по длительности разгона — в контракт (`rampStartFrame/rampEndFrame` у клипа), не константа.

## 6. Дополнительное смещение STOP
STOP двигает собаку на **59,4 px** при движке **42,4 px**: +17 px (запечённые +111 исходных px). Затем START возвращает −22,7 px (N1: собака −4,7 px при движке +18). В итоге положение спрайта относительно физической точки: стойка и событие **−29 px**, бег **−47…−52 px** (разница 18–23 px, 1,5–2 % трассы). Скачка нет, но событие происходит на 18 px впереди физической точки: для сравнения мест/вертикальных разделений V3 это ±18 px на трассе 1170 px.

## 7. Плавность перехода к циклу RUN
Шов gen3 f37 → RUN #90 по метрике на alpha IoU 0,859, цвет 39,1 (граница нормы), шаг положения 2,7 px; фазы лап независимых клипов не совпадают идеально (учтено в `KNOWN_ISSUES.md`). Дальше цикл #87–98 стандартный.

## Сравнение с прежним диагностическим превью
Прежний `DOG1_RS_GEN3_FULL_*` считал только от толчка и без шкалы трассы: откат 6–11 px, скорость −79 px/с исходных. Дорожка подтверждает величины и добавляет то, чего там не было: скачок 20 px без компенсации (N0), весь откат лежит до толчка, ускорение отстаёт от физической скорости на 0,75 с, STOP даёт +17 px. Профили компенсации остаются диагностикой, не окончательным решением.
