# План RACE_START (RACE_STAND → RUN) для Френка

Статус: **план, ничего не запущено, Kling не использовался.** Запуск только по прямому слову пользователя.
Цель по контракту: `RACE_STAND → совместимая фаза RUN` (`../../docs/bulldog-race/ANIMATION_CONTRACT.md`), без телепортации, скачка масштаба и лишней паузы.

## 1. Можно ли обойтись существующими кадрами? Нет, полностью нельзя
| Источник | Почему не подходит |
|---|---|
| Оригинальный START #25–63 | начинается из стойки **анфас** (FRONT_STAND), потом разворот вправо. RACE_STAND уже повёрнута вправо: пришлось бы повторять разворот, которого у неё нет. Годится только для самого первого старта из FRONT_STAND. |
| STOP v1, проигранный назад | при обращении времени ноги бегут назад, торможение превращается в «разгон с лунной походкой»; лапы скользят в обратную сторону. Нефизично, отвергается. |
| Сшивка кадров бега | в готовых кадрах нет ни одной статичной стойки боком (проверено: все кадры после разворота — фазы галопа). |

Можно переиспользовать **хвост**: настоящие кадры разгона #38–63 и цикл #87–98 (оба с готовым alpha). Новое нужно только между стойкой и первой фазой бега.

## 2. Конец клипа: кадр, ближе всех похожий на стойку
Пересечение силуэтов RACE_STAND (выравнивание по центру масс и линии земли) и кадров RUN: лучшие #90 (0,611), #114 (0,612), #55 (0,610), #79 (0,610), #45 (0,607), #91 (0,603). Для цикла #87–98: #87 0,503; #88 0,544; #89 0,579; **#90 0,611**; #91 0,603; #92 0,571; #93–95 ниже 0,47 (фазы полёта); #96–98 0,50–0,54.
Вывод: стойка ни на один кадр бега не похожа по силуэту (макс. 0,61); ближайшая фаза цикла — **#90/#91** (задние лапы упёрты в землю, корпус собран). Это же логичный конец START: фаза толчка.

Цепочка: `RACE_STAND → [Kling: разгон] → кадр #90 (последний кадр клипа) → цикл с #91: #91…#98, #87…#98…`.
Альтернативный конец #89 (0,579; следующий кадр #90 — тот же толчок).

## 3. Подготовка кадров (бесплатно, делается сразу после согласования плана)
- **START-кадр** = RACE_STAND v3 (из `DOG1_STOP_END.png`) на той же плите фона, что и START/END клипа STOP, **сдвинутая влево примерно на 120–150 px** от положения собаки в цикле (центр цикла x≈615), чтобы оставить место для продвижения вперёд при разгоне. Только перенос, без деформации; линия земли ≈ 682.
- **END-кадр** = RUN #90 (из `dog1-run-alpha.webm`, исходный номер #90) на той же плите + мягкая тень (как у START кадра STOP).
- Проверить по плейбуку: размер головы (ухо→зрачок), линия земли, фактура/цвет; коррекций не делать (см. DECISIONS п.7).

## 6. Приёмка и обработка после генерации
1. Первый кадр = RACE_STAND (разница < 2/255), последний = #90 (проверить наложением).
2. Разгон узнаваем как разгон, а не морфинг; лапы не пропадают и не удваиваются; камера и размер без дрейфа; Френк узнаваем.
3. Если стойка удерживается в начале дольше ~0,5 с, обрезать только ведущую неподвижную часть (не менять скорость).
4. Alpha: `dog_alpha.py` (`--exclude-rect none`, без водяного знака) → `verify_alpha.py`; особое внимание на кадрах перехода лап.
5. Предпросмотр цепочки в игровом масштабе 0.235: `RACE_STAND (0,5 с) → RACE_START → RUN loop ×4 → STOP → RACE_STAND`. Скачок на стыке RACE_START → цикл измерять так же, как делали для STOP (IoU и цвет на стыке не хуже обычного шага цикла: IoU ≈ 0,68 и цвет ≤ 26).
6. Стоимость и итог — в `KLING_LOG.md`.
