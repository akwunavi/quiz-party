# RACE_START, третья генерация: разбор и план (13.10.2026)

**Kling не запускался. Жду твоего «да» на одну генерацию (18 кредитов, баланс 369 → 351).** Файлы: `race_start_gen3_prep/`. Консультация архитектора (субагент `architect`, Opus) — ниже; его выводы я проверил и один совет отверг.

## Диагноз по двум провалам
V1 и V2 с разными START и разными промптами дали одну картину: оседание, удержание, прищур, рывок. Постоянный фактор один: **tail_image (END)**. Переход «присед → галоп» занимает ≈0,4 с, клип по правилам 3 с, END фиксирует последний кадр, и модель раскладывает лишние ~2 с по клипу, а «подготовку» кладёт в начало. Подтверждение с моей стороны: у V1 и V2 хороший галоп только в конце, где он нужен для попадания в #89/#90; в V2 с f22 Kling сам идёт в точный тайминг, а до f20 он «ждёт». Вторичные причины: (а) негации в промпте («не приседай ниже», «не щурься») праймят то, что запрещают; (б) поза f16 с вынесенными вперёд лапами читается как подкрадывание; (в) кадр END #90 темнее и смазан, отсюда потемнение лица и клипа на 9 %.

## Решение
1. **Не подавать tail_image.** Остальное без изменений: `image_to_video`, `kling-video-v3_0`, 720p, 3 с, звук выкл., multi-shot выкл., 1 шт.
2. **START тот же, `DOG1_RACE_START_V2_START_f16.png`** (вход стойка → f1–f16 уже согласован; менять START вместе с tail нельзя, иначе не поймём, что сработало).
3. **Промпт только позитивный** (`prompt_GEN3_not_sent.txt`): взлёт с первого кадра, лапы и фазы по секундам, глаза открытые, яркий свет на морде, без слов squint / crouch / wait. Сторону лапы не называю по «правой/левой» (при взгляде вправо ближняя к камере лапа левая), пишу «near front paw».
4. **Шов с RUN искать после генерации в первых ≈1,5 с** по фазе лап (как f64→#91), а не по тексту про ритм.

**Что отверг у архитектора:** «боковая съёмка с камерой, едущей за собакой». Движущаяся камера меняет фон и перспективу, ломает допущения конвейера (фиксированная камера, собака «на месте», движок задаёт ход по трассе). Вместо этого в промпте «фиксированная камера, собака скачет на месте, как на беговой дорожке». Это сохраняет контракт, риск: собака уедет вправо (проверим по кадрам, при провале — запасной план).

## Три итерации промпта (кратко)
1. Мой исходник: «из присеста сразу вперёд, без паузы, глаза открыты, не щуриться» → отвергнут: негации, слово «присед».
2. Версия архитектора: взлёт на первом кадре, 0–0,5 с два шага, дальше галоп, яркая морда, едущая камера → принято всё, кроме камеры.
3. Итог: версия 2 + фиксированная камера «на месте» + «ближняя передняя лапа» + «четыре ноги».

## Критерии приёмки (смотрю каждый кадр f1–f24, а не через 3)
К f6 хотя бы одна передняя лапа оторвана; корпус в f1–f8 не опускается больше чем на 5 px от f1; нет серии > 3 кадров с IoU соседних ≥ 0,97; глаза открыты на каждом кадре до шва; нет потемнения лица и уха; опорные лапы скользят не больше 8 px до отрыва; габарит не выходит за край, масштаб ±8 %; есть шов k ≤ 36 к RUN #87–98 (IoU ≥ 0,85, цвет ≤ 33, фаза ≥ 0,85), проверенный глазами.

## План трат
- Потолок: две генерации (36 кредитов). Если провал только по оседанию в начале, вторая попытка: без tail, START = V2 f22 (фаза толчка). Если провал по лицу или уходу из кадра, промпт не крутим: запасной вариант — гибрид V3 из V1 (f1–49 → #90) или реальный первый START. Две одинаковые неудачи — систематика, а не случайность.
