# Диагностический проигрыватель Френка на дорожке

Изолированный адаптер в папке Френка. **V3 (`../../dog4-v3-lab/`) не менялась и не копировалась**: адаптер читает её `layout.json` (холст 1920×1080, `startX 406`, `finishX 1484`, `finishControlOffset 92`, спрайт 207×116, якорь 148) и импортирует `model.mjs` только для самопроверки.
- `adapter.mjs` — строит таймлайн Френка (24 кадра/с) по физике V3 (скорость `1/42` в секунду, кривые разгона `2·(u³−u⁴/2)` и торможения `2·(u−u³+u⁴/2)`), считает прогресс `p`, экранный якорь `406+1170·p`, положение спрайта с компенсацией. **Самопроверка `selfTest()`**: те же формулы совпадают с `stateAt()` самой V3 на её START/STOP с ошибкой 5·10⁻¹⁷ (63 точки).
- `frames_meta.json` (центр, линия земли, лапа по кадрам, `td_meta.py`), `timeline.json` (результат адаптера по четырём вариантам), `metrics.json`, `paw_tracking.json`, `colour_metrics.json`.
- `td_render.py` — отрисовка (спрайт 207×116, якорь 148, тики прогресса каждые 0,01); `td_metrics.py`; `hy_load.py` — загрузка alpha (пути вшиты под рабочую среду, как в `analysis/`).
Запуск: `node adapter.mjs` (нужен `frames_meta.json`).

## Варианты
| | скорость разгона | компенсация C |
|---|---|---|
| **N0 V3-как-есть** | кривая START от начала клипа входа, по длительности клипа | нет (глобальный якорь, `C=0`) |
| **N1 пропорциональная** | кривая от кадра толчка (gen3 f7) за 1,29 с до стыка | `C=125` до толчка, затем `125·(1−(2u³−u⁴))` |
| **N2 выведенная** | как N1 | N1 + нижняя монотонная огибающая сглаженного положения |
| **N3 разгон по галопу** | кривая от толчка до кадра f20 (0,54 с) | как N1 |
Единицы C — пиксели исходного кадра 1276×720 (×0,1622 = пиксели холста 1920). Исходные значения N0 сохранены рядом.
Цепочка: `RUN (петля до #96) → STOP f1–73 → RACE_STAND 1,0 с (слот события) → вход V1 f1,f7–f11,f16 → gen3 f2–f37 → RUN #90–98 → петля #87–98 ×6`, 255 кадров. Скорость собаки базовая (variations = 1).
Видео: `DOG1_TRACK_compare_N0_N1_N2_N3_x2.mp4` (четыре дорожки друг под другом, ×2), `DOG1_TRACK_N2_follow_x4.mp4` (камера за физической точкой, ×4, красная линия = физический якорь). Листы: `track_cmp_sheet.png`, `track_colour_stills.png`.
