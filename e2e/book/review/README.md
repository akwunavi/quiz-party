# Book Design Review — как смотреть прототипы «Книги»

Это страница для просмотра нового оформления темы «Книга»: слева список экранов, сверху кнопки. Внутри — **настоящий проектор**
(тот же код, что в игре) с демо-данными. Играть и управлять игрой с пульта здесь не нужно: кнопки «Шаги» делают то, что сделал бы ведущий.
В боевую сборку сайта эта страница **не входит** и на `docs/` не влияет.

## Запуск (живой вариант, с анимациями)

Нужны Node.js и один раз `npm install` в папке проекта. Затем в терминале, в папке проекта:

```
npm run book:review
```

Что произойдёт: проект соберётся во временную папку (1–2 минуты), поднимется маленький сервер на вашем компьютере и напечатает адрес.
Откройте его в браузере: **http://127.0.0.1:7399/review/**. Остановить — `Ctrl+C` в том же окне терминала.
Если сборка уже была и вы ничего не меняли в коде — быстрее так: `npm run book:review -- --no-build`.
Если пишет «стенд уже запущен» — закройте предыдущее окно терминала (порт 7399 занят прошлым запуском).

## Что умеет страница

- **Слева** — все экраны по группам: лобби, правила, вопросы, ожидание, раскрытие, мелодия, финал, плитки команд, лист шрифтов.
- **Экран** — размер проектора: 1920×1080, 1899×905 (ваш реальный), 1366×768. Картинка сама вписывается в окно.
- **Команд** — 0 / 4 / 8 / 10 / 16 / 24 (работает там, где команды видны: лобби, ожидание, раскрытие, финал).
- **V1/V2/V3** (финал) и **T1/T2/T3** (плитки команд в лобби) — варианты оформления; **«Рядом ×3»** показывает все три сразу.
- **Шаги** — «Следующий вопрос» (листание страницы), «Повторить раскрытие ответа» (разворот карточки), «Играть отрывок» (пластинка крутится,
  пока играет музыка — один раз кликните по экрану проектора, иначе браузер не даст включить звук), «Запустить рулетку», «+ Добавить команду».
- **↻** — начать сцену заново; **⛶ / клавиша F** — во весь экран; **🔗** — скопировать ссылку на текущий вид
  (`?scene=…&res=…&teams=…&fin=…&team=…&split=1`); **← / →** — предыдущая/следующая сцена; **1 / 2 / 3** — вариант; **S** — «рядом».

## Статическая версия (без сервера)

Один файл `docs-dev/book-redesign/review/book-review.html` собран из готовых кадров `shots/proto`: открывается двойным щелчком, с теми же
навигацией, размерами и вариантами, но **без анимаций** и без переключателя числа команд (только снятые кадры). Пересобрать:

```
python3 -I e2e/book/review/build-static.py
```

## Известные ограничения

Анимации и звук проверены только в автоматическом браузере (Chromium без экрана) и по замерам, не на реальном ТВ. Проектор в просмотре
открыт без PIN ведущего — он только показывает; автопереходы игры (раскрытие через 3 с, автопроверка) здесь намеренно не срабатывают.
