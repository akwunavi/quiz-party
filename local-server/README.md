# Quiz Party — локальный сервер бара (Windows)

Это запасной вариант на случай, если в баре нет нормального интернета.
Вместо того чтобы играть через облако, ноутбук, к которому подключён
проектор, сам становится сервером: телефоны команд подключаются к нему
напрямую по локальной сети (вай-фай бара или мобильный хот-спот с
телефона ведущего), без выхода в интернет вообще.

**Важно понимать заранее:** это ДРУГОЙ адрес, не тот, с которого обычно
играете. Проектор и админка тоже должны быть открыты с ЭТОГО адреса —
если проектор открыт на обычном сайте, а команды подключились сюда, они
будут играть в разных играх, которые друг друга не видят.

---

## Один раз перед первой игрой (дома, заранее)

1. Скачай портативную версию Node.js (не для установки, а «переносимую»,
   `.zip`, Windows, 64-бит) с официального сайта: https://nodejs.org/en/download
   — там выбери "Windows Binary (.zip)".
2. Распакуй архив. Внутри будет папка с файлом `node.exe` и другими файлами.
3. Возьми файл `node.exe` (и папку `node_modules` рядом с ним, если она
   есть — обычно не нужна для нашего сервера) и положи в папку
   `local-server/node/` рядом с этим README — то есть должен получиться
   путь `local-server/node/node.exe`.
4. Собери приложение и положи в папку `local-server/app/` (для ведущего,
   который не программист: этот шаг обычно делает тот, кто заводил проект
   — попроси собрать `dist/` и переименовать/скопировать в `local-server/app/`).
   Проверка: в папке `local-server/app/` должен лежать файл `index.html`.
5. Дважды кликни `start-quiz-local.cmd`. Должно открыться чёрное окно
   консоли с адресами вида `http://192.168.x.x:7331/quiz-party/`.

Если что-то не так — скрипт сам напишет понятную ошибку в этом же окне.

## Брандмауэр Windows

При первом запуске Windows спросит: "Разрешить node.exe работать в сети?"
(может появиться не сразу, а когда первый телефон попробует подключиться).
Нужно поставить галочку **"Частные сети"** (не публичные) и нажать
"Разрешить доступ". Если пропустить это окно или нажать "Отмена" —
телефоны не смогут подключиться, а с самого ноутбука всё будет работать
(поэтому баг иногда незаметен, пока не начнут подключаться гости).

Если окно с вопросом не появилось само — открыть Панель управления →
Брандмауэр Windows Defender → Разрешить приложение через брандмауэр →
найти в списке node.exe → поставить галочку "Частные".

## Мобильный хот-спот (если в баре нет своего вай-фая)

Windows 11: Параметры → Сеть и Интернет → Мобильный хот-спот → включить.
Телефон ведущего (или отдельный роутер/повербанк с сим-картой) раздаёт
вай-фай, к которому подключаются: ноутбук с проектором и все телефоны
команд. Адрес ноутбука в такой сети обычно `192.168.137.1` — но точный
адрес всегда написан в чёрном окне консоли после запуска сервера,
ориентируйся на него, а не на этот пример.

**Все устройства (ноутбук, телефоны команд, телефон ведущего с
админкой) обязаны быть в ОДНОЙ сети** — либо все в вай-фае бара, либо все
на одном хот-споте. Если ноутбук в вай-фае бара, а телефон ведущего — на
мобильном интернете, страница `/local` и админка на нём не откроются.

## Как играть

1. Запустить `start-quiz-local.cmd`, дождаться адресов в консоли.
2. На проекторе открыть браузер по адресу из консоли (`http://<ip>:7331/quiz-party/#/`).
3. С телефона ведущего открыть `http://<ip>:7331/quiz-party/#/local` —
   там кнопка **«ВКЛЮЧИТЬ ЛОКАЛЬНЫЙ РЕЖИМ»**. Без неё сервер не примет ни
   одной записи (это специально — защита от случайного начала записи в
   пустой сервер, пока всё ещё готовится).
4. Там же на `/local` — кнопка «залить пакет на сервер»: сервер должен
   заранее получить вопросы пакета. Нужно, чтобы пакет был уже скачан в
   этом же браузере кнопкой «Скачать пакет для офлайна» в админке
   (обычной, облачной — это можно сделать заранее, дома, пока есть
   интернет).
5. Дальше — админка `http://<ip>:7331/quiz-party/#/admin`. Логин/пароль
   здесь НЕ спрашивает (это другой адрес — облачный вход туда всё равно
   не достучится без интернета): доступ к серверу в локальной сети сам
   по себе и есть допуск, как с самим этим README.
6. QR для команд — на странице `/local` или прямо на проекторе в лобби,
   как обычно.

## Если порт занят

Сообщение в консоли: "Порт 7331 уже занят". Значит, уже где-то запущена
вторая копия сервера (например, забыли закрыть предыдущее окно). Найди
старое окно консоли и закрой его, потом запусти снова. Если не находится
— можно перезагрузить ноутбук.

## Закрытие окна = конец игры

Пока чёрное окно консоли открыто — сервер работает. Свернуть его можно,
закрывать нельзя: закрытие мгновенно обрывает связь со всеми телефонами
и проектором. Данные при этом не теряются (лежат в файле на диске), можно
снова запустить `start-quiz-local.cmd` и продолжить — но во время самого
закрытия команды на секунду увидят, что связь пропала.

## Что делать после игры (вернуться в облако)

На странице `/local` — кнопка «выгрузить игру в файл»: скачивает один
JSON-файл со всеми командами, ответами и баллами игры. Сохрани его — из
него позже (отдельная задача, ещё не сделана) можно будет перенести игру
обратно в облако для истории/статистики.
