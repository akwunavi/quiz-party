# Оглавление памяти knowledge-keeper

Эта память — не дубликат `CLAUDE.md`/`HANDOFF.md` (те канонические и
обновляются в каждом коммите). Здесь — то, чего в них нет: развёрнутые
объяснения архитектуры и связей между модулями, которые стоило время
на то, чтобы в них разобраться.

Файлов пока нет — заведи первый, когда впервые накопаешь что-то стоящее
запоминания, и впиши его сюда одной строкой.

Формат строки: `- \`имя-файла.md\` — о чём коротко`.
