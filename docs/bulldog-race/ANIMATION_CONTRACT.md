# Контракт анимаций для пяти собак

Это контракт проверки ассетов, не требование сделать всех собак в ракурсе №4. Для каждой собаки её собственные базовые позы, масштаб, линия земли и якорь корпуса фиксируются отдельно. Для Френка №1 Claude Code рассматривает FRONT_STAND + RACE_STAND; его активные материалы не менялись и не копировались из рабочей директории.

| Состояние | Роль и вход → выход | Тип ассета/длительность | Якорь и проверка | Основной риск |
|---|---|---|---|---|
| FRONT_STAND | Фронтальная презентация → переход в RACE_STAND, если нужна | Статичный PNG или прозрачный клип; длина по UX | Центр корпуса и опорные лапы; совпадение окраса при повороте | Нельзя напрямую резать на боковой RUN без движения поворота. |
| RACE_STAND / BASE_STAND | Собственная устойчивая стойка собаки → START или ACTION | PNG/alpha клип; удержание по сценарию | Четыре опоры, линия земли, видимый ракурс | Один красивый кадр не доказывает устойчивость скрытой лапы. |
| IDLE | Ожидание выбора → SELECTED/переход к старту | Прозрачный цикл; длина произвольна | Не смещать мировой якорь на кадрах цикла | Дрожание контура и изменение размера. |
| SELECTED | Реакция на выбор → стойка/переход на старт | Прозрачный клип; длительность по роли выбора | Выход должен соответствовать следующему клипу | Нельзя прерывать незавершённую реакцию без стыка. |
| START | RACE_STAND → совместимая фаза RUN | Прозрачный клип; фактическое время клипа, в V3 №4 1 с | Якорь корпуса движется по физической START кривой; контроль первого и последнего кадров | Телепортация, скачок масштаба, старт не в согласованной фазе RUN. |
| RUN | После START → заранее выбранная фаза STOP/FINISH | Прозрачный цикл, длительность произвольна; №4 #11–22/0,5 с | Мировая позиция модели, ноги не должны заметно скользить | Разрыв шва и неверная фаза перед STOP. |
| STOP | RUN → стойка для действия | Прозрачный клип; полная фактическая длительность, №4 37/24 с | Торможение начинается заранее; финальная опора на земле | Смена фазы лап/головы на входе, остатки пола. |
| BUTTERFLY | Стойка → стойка для START | Только собака в alpha-клипе; объект бабочки рендерится отдельно в мире | Не менять мировую координату при реакции | Встроенная бабочка из генерации, контакт уха с маской, смена ракурса. |
| SNIFF_PEE | Стойка → стойка либо RETURN | Только собака в alpha-клипе; длительность по реальному движению | Лапы/язык/морда сохраняются, позиция постоянна | Конец может быть в другом ракурсе; не обрезать утверждённые жесты. |
| RETURN | Конец SNIFF_PEE → RACE_STAND | Прозрачный клип, если действие само не завершает возврат | Проверить перенос веса и все промежуточные шаги | Удаление середины шага даёт скачок; retime требует проверки. |
| ROLL | Стойка → валяние → физически понятное вставание → стойка | Прозрачный клип, на №4 ~6 с | Линия земли и корпус не вращаются как на платформе | Лишние/пропавшие лапы, дрейф окраса, несоответствие финальной стойки. |
| FINISH | RUN→FINISH_DECELERATE→BASE_STAND | Можно проверить переиспользование STOP; отдельный клип при дефекте | Пересечение линии происходит до остановки; затем 2 с стабильной стойки в тесте | Нельзя подменять отсутствие торможения crossfade/морфингом. |

Общие требования к alpha: прозрачный фон без старого пола, тени, прямоугольника и цветного ореола; сохранение ушей, лап, морды, окраса и межлапных просветов; проверка на белом, чёрном, зелёном и цвете арены, а также при непрерывном воспроизведении. WebM VP9 с реальной alpha предпочтителен для Chromium; `alpha_mode=1` проверять декодированием. Оригиналы MP4 и промежуточные маски оставлять неизменными.

Длительность действия не выводится из имени и не назначается заранее ради баланса. Она измеряется у конкретного клипа, затем явно согласуется со сценарием. Физическая модель гонки отвечает за мировую позицию, видео — за локальную позу. Butterfly/BONE игровые объекты должны привязываться к позиции собаки или координатам мира; BONE сейчас исключена из V3.
