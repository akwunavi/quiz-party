# Сохранившиеся знания об удалении фона

Код и параметры разрозненно сохранены в `dog4-alpha`, `four-alpha`, `v2-dog3-dog5`, `sniff-pee-lab`, `dog4-stop-asset`, `dog4-return-asset`, `dog4-butterfly`, `dog4-roll-asset`, `dog4-tech-audit`. Все доступные скрипты и JSON статистики входят в реестр; единый универсальный исполняемый pipeline **не заявляется**. Claude Code параллельно восстанавливает общую обработку, не создавайте независимую вторую версию здесь.

Подтверждённый метод из отчётов: BiRefNet-general-lite через локальный ONNX/rembg, модельный вход 1024×1024; опорные маски в исходном размере; перенос между кадрами оптическим потоком с проверкой окклюзий/согласованности; temporal consistency; closed-form alpha matting PyMatting; очистка цвета только в полупрозрачной кромке. Непрозрачные RGB пиксели собаки сохранялись из исходника. Исходный пол и тень удалялись, игровая тень рисуется отдельно. Исходные MP4 и кадры масок сохранены там, где доступны.

Вывод: VP9 WebM с `alpha_mode=1` и отдельные RGBA/alpha16 промежуточные кадры. Техническую прозрачность проверяли декодированием `libvpx-vp9`, выборкой alpha 0…255 и Chromium Canvas на белом/чёрном/зелёном/бежевом фоне. Наличие одного тега `alpha_mode` не является художественной проверкой кромки. Быстрые лапы, уши, морда, межлапные просветы и мерцание требуют выборки нескольких кадров и непрерывного воспроизведения.

Для Dog №3 v2 локальная коррекция убрала остатки студийного фона у морды/лап и восстанавливала глаз; для Dog №5 новый Kling source заменил старый RUN, старый результат сохранён. Для BUTTERFLY локальная коррекция около кадра #61 убрала пиксели встроенной бабочки рядом с ухом. Для ROLL исходный чёрный фон отделён без изменения 145 кадров движения.

Архив не доказывает, что каждая mask последовательность покрывает весь исходник, и не делает новые alpha assets. Если новый агент пересобирает WebM, сначала сверяет SHA-256 исходника, диапазон кадров, FPS и визуальный QA из соответствующего отчёта; старый утверждённый RUN не перезаписывать.
