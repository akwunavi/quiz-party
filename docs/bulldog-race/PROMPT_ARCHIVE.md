# Промпты и параметры генераций

Архив различает **точный оригинальный текст запроса в Kling**, предложения промпта для будущей генерации и инструкции пользователю/агенту. Это не взаимозаменяемые категории.

В доступных текстовых файлах найден **один явно оформленный предложенный Kling prompt** для ROLL: `artifacts/dog4-roll-prep/REPORT.md`, раздел после строки «Предлагаемый prompt». Сохранённый отчёт имеет неизменённые байты в реестре; текст не переписывается здесь. Это предложение для генерации, а не доказательство того, что именно такой запрос был отправлен в Kling.

Файлы `kling_20261008_*`, `kling_20261009_*`, `kling_20261012_*`, `kling_20261013_*` и соответствующие источники MP4 сохранены. Их имена, длительности, разрешения, FPS и SHA-256 перечислены в `ASSET_MANIFEST.json`. **Точные отправленные в Kling тексты, negative prompts, параметры модели/seed, число оплаченных попыток и стоимость в кредитах не обнаружены.** Нельзя приписывать генерации промпт из отчёта или восстановленное по виду видео описание. Для этих полей в архиве стоят MISSING-записи.

Пользовательские задания Codex из доступных вложенных текстовых файлов сохранены побайтово в tar-архиве с типом `user-upload`. Это технические инструкции, а не оригинальные Kling prompts. Часть прошлой переписки недоступна; архив не заявляет её восстановление.

Технические параметры, подтверждённые локальными исходниками/отчётами: типичный Kling MP4 1276×720, H.264/yuv420p, 24 FPS; проверяйте индивидуальную длительность и число кадров по каждой записи. Для ROLL source известны 145 кадров/6,041667 с; BUTTERFLY — 121 кадр/5,041667 с; новый SNIFF v2 — 241 кадр/10,041667 с. Значения не следует механически переносить на другие клипы.
