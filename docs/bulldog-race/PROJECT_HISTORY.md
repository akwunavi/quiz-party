# Проверяемая история разработки

Это восстановление по доступным файлам, сообщениям текущей сессии и Git refs. Вся прежняя переписка недоступна; где оригинальный источник не найден, это отмечено.

1. Visual Pass 2/3 создали отдельный автономный макет гонки. Visual Pass 3 пользователь утвердил как направление, но прототип и production — разные вещи. Ранние HTML, снимки и ZIP сохранены в реестре.
2. Исходные Kling RUN для пяти бульдогов имели непрозрачный фон. Локальный BiRefNet-general-lite/ONNX + временные маски + matting дали прозрачные VP9 WebM. №3 и №5 позднее были повторно обработаны; старые версии оставлены. Отчёты `dog4-alpha`, `four-alpha`, `v2-dog3-dog5` дают проверенные диапазоны кадров.
3. Прямая склейка RUN→SNIFF_PEE→RUN не прошла визуальный критерий. Геометрическое выравнивание, speed ramp и crossfade не решили смену ракурса и позы. Исследование STAND показало, что начало SNIFF совместимо со стойкой, а конец — нет. Потребовался настоящий RETURN.
4. Для №4 появились кадры STOP/RETURN/ROLL для Kling, новые MP4, прозрачные производные и монтажные тесты. Отклонённые или условные версии сохраняются: ранний SNIFF v1, reverse STOP, сокращённый RETURN B, seam-кандидаты RUN, прямые crossfade-сборки. Точные решения находятся в отчётах каждого этапа.
5. Рабочая игровая цепочка №4 стала `RUN → STOP → SNIFF_PEE → RETURN → START → RUN`; позднее BUTTERFLY и ROLL получили отдельные прозрачные действия. BUTTERFLY была нарисована внутри Kling MP4 и удалена маской: игровая бабочка должна быть отдельным мировым объектом. Косточка BONE не включена в текущую V3; найденные идеи сохранены, подтверждённых файлов BONE-анимации не найдено.
6. FINISH проверялся без новой генерации: STOP можно переиспользовать как торможение в игровом масштабе, затем точная BASE_STAND. На крупном плане остаются небольшие скачки фазы лап/освещения.
7. Диагностика 10 клонов перешла к пятидорожечной V3, затем к трём событиям и случайной seeded-механике. Исходный V3 balance audit и фиксированные A/B/C сохранены, как и поздняя регрессия финиша внутри START.
8. Seed fallback добавил последовательный выбор первого допустимого seed. RUN cadence A/B сравнивались на трёх скоростях: адаптивный ритм нарушил фазу входа в STOP, поэтому текущая V3 оставила фиксированный RUN.

Точные commit SHA, имена и хеши доступны в `ASSET_MANIFEST.json` и `ARCHIVE_SHARDS.json`. Хронология внутри каталога должна читаться вместе с `DECISIONS.md`: ранняя рекомендация не всегда является текущим решением.
