# Неудачные и условные эксперименты — не удалять

| Эксперимент | Итог и причина | Где искать |
|---|---|---|
| Прямой RUN→SNIFF_PEE→RUN, геометрическое выравнивание и crossfade | Отклонено пользователем: скачки позы/ракурса, двойные конечности при смешивании. Оптимизация выравнивания не решала исходную несовместимость. | `sniff-pee-lab/REPORT.md`, `transition-rework/REPORT.md`, `transition_v1_alignment.mp4`, `transition_v2_speed_ramp.mp4` и старые ZIP. |
| Один STAND как единственный мост без RETURN | Невозможно для текущего SNIFF: вход похож на RUN #0, конец SNIFF остаётся в другом ракурсе (лучший IoU среди #208–240 около 0,583). Скачок лишь переносится на SNIFF→STAND. | `stand-study/REPORT.md`, контактные листы и референсные PNG. |
| SNIFF_PEE v1 | Пользователь передал новый утверждённый v2, старый вариант оставлен для отката. Не подменять им v2. | `sniff-pee-lab/bulldog_04_sniff_pee_alpha_v1.webm`, старый Kling MP4 и отчёты. |
| Reverse STOP из исходного RUN | Только диагностический кандидат, естественное торможение не подтверждено. Позже создан отдельный STOP Kling. | `dog4-tech-audit/03b_reverse_stop_diagnostic.mp4`, отчёт. |
| RETURN B с удалением середины | Пропуск исходных #61–70 создаёт скачок лап и корпуса; не опубликован как улучшение. | `dog4-return-asset/REPORT.md`, исходный RETURN MP4 и кадры. |
| Слишком длинный RETURN | Пользователь отметил топтание/приседание. Умеренный retime ускорил все исходные кадры без удаления шагов; более динамичный вариант оставлен для сравнения. | `dog4-return-retime/REPORT.md`, оба MP4. |
| RUN loop #3–25, #34–58 и другие seam-кандидаты | Не утверждены: смена горизонта, формы или ритма на шве. #11–22 стал рабочим V3. Не выдавать старый количественный аудит за пользовательский просмотр. | `dog4-loop-audit/REPORT.md`, все clean/seams MP4. |
| STOP-короткий кандидат | Сокращение могло нарушить работу лап и стык; полный STOP 37 кадров сохранён для V3. | `dog4-stop-asset/candidate_short_*`, отчёт. |
| Прямая адаптация RUN до 0.90/1.10× | Слабое уменьшение возможного скольжения, но перед STOP у медленной/быстрой собаки кадры #14/#17 вместо согласованного #22. На 24 FPS возникают повторы/пропуски кадров. | `DOG4_V3_RUN_SPEED_COMPARISON.mp4`, `DOG4_V3_SEED_AND_RUN_REPORT.md`. |
| BONE | Исключена из текущей механики. Подтверждённых файлов генераций BONE в доступном архиве нет; найдено только описание идеи. | `dog4-run-reference/REPORT.md`; MISSING-запись в реестре. |

При просмотре старых превью всегда сверяйте годный игровой масштаб и крупный план: высокий IoU силуэта не доказывает плавного движения лап, освещения и ракурса. Нельзя объявлять стык исправленным по одной статичной картинке или скрывать дефект морфингом.
