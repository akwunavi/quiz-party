# Реестр решений и уровень подтверждения

| Решение | Статус | Основание |
|---|---|---|
| Visual Pass 3 — визуальное направление арены | Принято пользователем | Сообщение пользователя об утверждении; материалы `pass-3/`. Не означает разрешения менять production. |
| Dog №4 RUN alpha — эталон для последующих тестов | Принято пользователем | Пользователь назвал WebM утверждённым RUN; SHA-256 `1a26ccd66ed780b75564a9fdb2fab5fc5cd0cd0b8b4d0e24e7d169d84fec045f`. |
| Поведение нового SNIFF_PEE v2, включая язык и повтор лапы | Принято пользователем | Прямое сообщение об утверждённом визуальном поведении Kling `...144_0.mp4`. Это не утверждение старой прямой склейки. |
| RUN loop #11–22 | Рабочий вариант V3 | Использован в дальнейших проверках и V3. Ранний аудит помечал как условный; не объявлять сам аудит финальной приёмкой. |
| STOP→SNIFF_PEE→RETURN→START | Рабочая цепочка №4 | Поздние монтажные отчёты и пользовательское согласование динамики в игровом масштабе; в крупном плане есть небольшие дефекты. |
| Переиспользовать STOP как FINISH_DECELERATE | Техническая рекомендация, V3 применяет | `dog4-finish-test/REPORT.md`: приемлемо в игровом масштабе, не безупречно крупно. |
| Бабочка — отдельный программный объект | Требование пользователя | Исходный BUTTERFLY Kling имел бабочку внутри видео; она удалена. В лаборатории отдельная игровая бабочка пока не реализована. |
| BONE не включать в текущую игру | Требование пользователя для архива | Наличие ранних идей в `dog4-run-reference/REPORT.md` не делает BONE частью V3. Оригинальные BONE-генерации в доступных источниках не обнаружены. |
| Пять собак могут иметь разные базовые ракурсы/стойки | Требование архитектуры | `stand-study/REPORT.md` показывает несоответствие ракурса даже у одной собаки; для Френка №1 Claude ведёт FRONT_STAND+RACE_STAND. Не переносить геометрию №4 автоматически. |
| Seeded V3: 1/2/3 события, категории скорости, реальные финиши | Принято пользователем для изолированной V3 | Задание на реализацию и последующее предварительное согласование контрольного заезда. Production не изменён. |
| Первый допустимый seed, лимит 64 | Принято пользователем для V3 лаборатории | Задание на надёжный запуск; тест `20261423→20261424`. |
| Фиксированный RUN 1.00× | Текущий выбор V3 | Сравнение `DOG4_V3_RUN_SPEED_COMPARISON.mp4`: адаптивный ритм даёт RUN #14/#17 перед STOP вместо #22. Не переносить эксперимент B в модель. |
| Единый 3D-скелет | Исследовательская гипотеза, не принято | Ранний `stand-study/REPORT.md` предложил короткую проверку, но дальнейшее производство осталось видео-путём. Не утверждать выбор 3D задним числом. |

При противоречии старого отчёта и поздней прямой инструкции пользователя приоритет у поздней инструкции. Статус отдельного файла указывается в реестре только если есть соответствующее доказательство; название `final`/`v2` само по себе ничего не утверждает.
