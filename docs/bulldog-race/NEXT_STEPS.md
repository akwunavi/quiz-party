# Следующие шаги

## Codex

1. Держать V3 изолированной. Проверить пользовательское решение по визуальному сравнению RUN; текущий выбор — фиксированный 1×.
2. Не менять event weights, winner logic и scoring без нового задания. При будущей интеграции сначала согласовать, как production обрабатывает `RaceScheduleError`, а затем отдельно планировать перенос V3 в RaceBoard.
3. По мере появления новых файлов дополнять `ASSET_MANIFEST.json`, связанный SHA-256, статус и доказательство приёмки. Не удалять отвергнутые версии. Проверять архив из чистого клона после каждого существенного расширения.
4. Когда появятся утверждённые ассеты других собак, проверять их собственные START/RUN/STOP/action стыки и контакт лап в игровом масштабе; не копировать координаты №4 без проверки.
