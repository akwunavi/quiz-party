# Если ты новый агент и не имеешь доступа к прошлой переписке, начни здесь

1. Работай с веткой `codex/dog4-race-v3-5lane-20261012`. Не изменяй production, не делай merge или deploy без разрешения пользователя.
2. Прочитай [APPROVED_RULES.md](APPROVED_RULES.md), [PROJECT_HISTORY.md](PROJECT_HISTORY.md), [DECISIONS.md](DECISIONS.md), [FAILED_EXPERIMENTS.md](FAILED_EXPERIMENTS.md), [ANIMATION_CONTRACT.md](ANIMATION_CONTRACT.md), [ASSET_MANIFEST.json](ASSET_MANIFEST.json).
3. Убедись, что текущий статус другой работы не изменился. Claude Code параллельно занимается Френком №1 и восстановлением alpha-конвейера. Не меняй его активные материалы; описанное здесь состояние — снимок времени архивации.
4. Сверь контрольные суммы через `python docs/bulldog-race/tools/verify_archive.py`. Для Git-объекта используй указанный в реестре commit/path; для tar — `path` и `member`. Не заменяй отсутствующий файл похожим по имени.
   Чтобы извлечь один файл под исходным именем, используй, например, `python docs/bulldog-race/tools/restore_asset.py asset-005608 /tmp/bulldog_04_sniff_pee_alpha_v2.webm`. Скрипт сверит SHA-256 и не перезапишет существующий файл.
5. Лаборатория: `cd dog4-v3-lab && python -m http.server 8765`; в Chrome открыть `http://127.0.0.1:8765/`. На странице выбрать seed `20261013`; он должен остаться эффективным `20261013`. Seed `20261423` должен детерминированно перейти в `20261424`.
6. Проверить `node fallback_validate.mjs 10000` (если установлен Node), `node validate.mjs`; результат и прежние выборки есть в JSON и отчётах. Дополнительная браузерная проверка требует Playwright Core и Chromium. Видео `DOG4_V3_RANDOM_SEED_20261013.mp4` и `DOG4_V3_RUN_SPEED_COMPARISON.mp4` открываются обычным видеоплеером.
7. Не менять утверждённые видео. Не повторять отклонённые crossfade, ROLL/RETURN монтажи или адаптивный RUN без новой проверяемой причины. Отсутствующие оригинальные Kling prompts не восстанавливать по догадке.
8. При добавлении другой собаки сначала зафиксируй её собственные базовые позы и стыки. Не копируй автоматически геометрию Bulldog №4 на Френка.

Критически важные пробелы перечислены в [KNOWN_ISSUES.md](KNOWN_ISSUES.md) и в записях `MISSING` реестра. Архив не утверждает, что вся история переписки доступна. Параллельная активная работа Claude не включалась из его рабочей директории, чтобы не создавать конфликт.
