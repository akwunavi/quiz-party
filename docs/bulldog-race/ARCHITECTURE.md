# Фактическая архитектура изолированной V3

`scenario.mjs` планирует пять собак из seeded RNG до начала гонки: число и типы событий, начальные/последующие скорости, вариации и координаты. `generateRace(seed)` перебирает до 4096 полных наборов координат при фиксированных для этого seed остальных выборах; неподходящие наборы отбрасываются. `resolveRace(requestedSeed)` ищет первый подходящий целый seed с лимитом 64 и возвращает диагностику. Все выборы до старта, никаких `Math.random()` в проигрывании.

`model.mjs` превращает каждый план в непрерывную цепочку временных сегментов. Позиция — нормированная мировая координата. Базовый темп NORMAL — 1/42 трассы в секунду. Изменение по четвертям умножается на 0.98–1.02. START/STOP используют интеграл плавной скорости; в BUTTERFLY, ROLL, SNIFF_PEE, RETURN и BASE координата постоянна. STOP стартует в согласованной фазе RUN; после действия новая скорость начинает действовать только через START.

Состояния: `BASE → START → RUN`; события `RUN → STOP → BUTTERFLY/ROLL → START → RUN` или `RUN → STOP → SNIFF_PEE → RETURN → START → RUN`. Раннее событие может пройти `BASE → ACTION → START → RUN`. Финиш: `RUN/START → [пересечение] → FINISH_DECELERATE → BASE`. Для финиша используется существующий STOP-клип, а не новая генерация.

Победитель и порядок основаны на аналитическом `crossing`, а не на первом отрисованном кадре. Регрессия события на 99% пересекает финиш внутри START при 41.910386 с, раньше окончания START. `stateAt(dog,t)` вычисляет кадр и позицию для произвольного времени, поэтому результат независим от браузерного FPS и seek/reset. `app.mjs` рисует пять дорожек на исходной арене; `record.mjs` снимает тот же Canvas в 24 FPS. Только диагностический `run_compare.mjs` содержит гипотезу адаптивного RUN; `model.mjs` её не импортирует.

RUN loop использует alpha-кадры #11–22 после пролога #0–10, 12 кадров/0,5 с. STOP — 37/24 с; BUTTERFLY — 121/24 с; ROLL — 145/24 с; SNIFF_PEE — оптимизированные 7,26 с плюс RETURN 2,721 с; START — 1,0 с. Физика V3 не импортирует `buildRace` или production RaceBoard. Visual Pass 3 сохранён как ресурс арены.

Точки проверки: `validate.mjs`, `random_validate.mjs`, `fallback_validate.mjs`, `browser_check.mjs`. Браузерная автоматизация проверяла A/B/C, seeded 20261013, fallback 20261423→20261424 и эксперимент RUN. Она требует локального Chromium/Playwright только для проверки, не для обычного просмотра HTML по HTTP.
