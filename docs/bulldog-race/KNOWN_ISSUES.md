# Известные ограничения и пробелы

1. **Недоступная история:** точные Kling prompts, model version/seed, negative prompts и кредиты для известных MP4 не найдены. Доступны только один предложенный ROLL prompt и технические задания Codex. MISSING-записи в реестре дают конкретные ссылки на источники упоминаний.
2. **Активный Claude Code:** его рабочая директория и свежие материалы Френка №1 не копировались. Ветка архива содержит только ранее доступные исторические материалы и одобренные границы ответственности. Перед продолжением узнай актуальный статус Claude.
3. **Промежуточные статусы:** тысячи диагностических кадров не имели индивидуального пользовательского решения. `EXPERIMENTAL`/`UNKNOWN` нельзя трактовать как `APPROVED`. Имена `v2`/`final` не являются доказательством.
4. **№4 крупный план:** RUN→STOP иногда меняет фазу лап/головы; STOP→BASE может слегка менять свет. Игровой масштаб признан пригодным для проверки, но точность каждого перехода для production отдельно не утверждена.
5. **RUN cadence:** фиксированный 24 FPS даёт небольшую теоретическую разницу контакта лап при 0.75–1.25×; простая адаптация 0.90–1.10× нарушает фазу перед STOP и оставлена только в эксперименте.
6. **Seed fallback:** при 64 последовательных непригодных seed или конце uint32 приходит структурированная ошибка. Production не подключён и не содержит обработчик этой ошибки.
7. **Отсутствующий единый alpha pipeline:** разрозненные скрипты и описания есть; Claude восстанавливает общий конвейер. Не обещать полную пересборку всех WebM одной командой.
8. **BONE:** идея в старом отчёте, но нет подтверждённой BONE-анимации/промпта в найденных источниках. Событие исключено из текущего V3.
9. **Долговременное хранение:** tar части хранятся в отдельной Codex ветке, без LFS и внешнего сервиса. Их целостность проверяется SHA-256; при удалении ветки понадобится резервная копия. GitHub Release/LFS не создавались без разрешения пользователя.
10. **Полнота относительно отсутствующих сессий:** архив охватывает доступную текущую среду и просмотренные исторические refs, но не может доказать отсутствие файлов в старых недоступных средах. Новые найденные материалы добавлять в манифест, не заменять прежние записи.
