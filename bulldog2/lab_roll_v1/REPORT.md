## Лаборатория (`index.html`, `app.mjs`, `dog2roll.mjs`)
Визуальный слой STOP-лаборатории подключён без изменений, добавлено окно ROLL. Каждая дорожка показана от начала своего окна ROLL (τ = 0).
Пресеты:
* `EARLY5` — 5 категорий: RACE_STAND → ROLL → RACE_STAND → RACE_START B → RUN (ROLL до первого старта);
* `MID5` — 5 категорий: RUN → STOP B → ROLL → RACE_STAND → RACE_START B → RUN (ROLL на 35 %);
* `PAIR` — рядом №4 с его ROLL для масштаба.

Проверка: headless Chromium, покадрово 24 к/с, τ −1…+8,6 с (`tools/lab_check.mjs`), анализ `tools/analyse.py` → `results/analysis.json`.
