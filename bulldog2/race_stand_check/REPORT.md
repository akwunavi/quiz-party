## 3. RACE_START из кадров RUN после #30
Окна V3 не меняются: START = 1 с, присоединение к бегу 23/24 с, цикл 0,5 с. У Фрэнка визуальный клип START был длиннее окна (41 кадр) и продолжался в RUN (`spillFromStart`). Тот же механизм подходит и здесь.

Факты из исходника:
* толчок начинается сразу после #30: центр тела идёт вперёд 609 → 670 к #36 (≈ +10 px в игре за 0,25 с);
* галоп становится периодичным к #36–#40 (повтор через 12 кадров: 13 → 6–8);
* внутри кадра собака дальше почти не смещается: средний центр разгона 650 против 660 у цикла;
* стыки разгона с циклом #88–#99 в той же фазе: до ~#60 они заметны (разница 7–15 при шаге галопа ~8), с ~#69 — чистые (#70 → #95: 4,3; #71 → #96: 3,8).

| Вариант | Кадры | Длина | Стык с циклом | Замечание |
|---|---|---|---|---|
| **A (рекомендую)** | #30 → … → #87, дальше цикл с #88 | 58 кадров = 2,42 с | **нет стыка** (#87 → #88 — продолжение исходника) | толчок #30–#36, дальше обычный галоп того же стиля |
| B | #30 → … → #71, дальше цикл с #96 | 42 кадра = 1,75 с (как START Фрэнка, 41) | 3,8 при шаге 8 — незаметно | короче, один стык |

**Вывод:** RACE_START собирается из существующих кадров **без генерации** (экономия 18 кредитов).
* **Ноги быстрее земли.** Ноги выходят на полный галоп за ≈ 0,25 с, а физика V3 разгоняет собаку линейно за 1 с. Первые ≈ 0,7 с ноги бегут быстрее, чем собака едет. У Фрэнка было то же («разгон отстаёт от ног») и это приняли.
* **Фаза входа в STOP.** Какой кадр RUN будет перед первым STOP, определит будущий STOP №2 (lead, как у Фрэнка). Это решается при подготовке STOP, вариант A этому не мешает.
* Проверка в браузерной лаборатории рядом с №4 — после alpha.
