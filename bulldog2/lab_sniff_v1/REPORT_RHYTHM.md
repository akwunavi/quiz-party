## Корень проблемы
Окно ≈ 10 с, движение в исходнике 7,1 с (s6–s176). Без нового материала примерно 2,9 с неподвижности можно только **переложить**, а не убрать. Вопрос — где неподвижность читается естественнее.

## Что можно продлевать (замеры по кадрам 1276×720, средняя разница соседних кадров /255)
| участок | что движется | шаг | вывод |
|---|---|---|---|
| s74–s113 удержание, 1-я часть | поднятая лапа покачивается вверх-вниз, период ≈ 11–12 кадров (0,5 с) | 0,5–2,3 | **не продлевать**: повтор цикла = повторяющееся движение лапы (запрещено требованиями к метке, риск «почёсывания»). Петля нашлась бы бесшовно (s110 ≈ s99, 0,75), но её не используем |
| s114–s122 | лапа успокаивается | 0,3–0,7 | — |
| **s123–s142** удержание, 2-я часть | практически ничего | **0,12–0,19** | можно играть туда-обратно: разворот невидим (шаг на развороте тот же 0,14). Это и есть «естественное» удержание исходника |
| s143–s152 | опускание лапы | до 5 | не трогаем (как просили) |

Отвергнуто: стоп-кадр (повтор одного кадра) — мёртвая картинка; повтор цикла покачивания — см. выше; вся неподвижность в начало (2,9 с стоит после STOP, потом нюхает) — то же ожидание, только раньше.

## Лаборатория (MID5 и EARLY5, все 5 категорий; `results/rhythm/analysis_*.txt`)
Все стыки 0,00 px (STOP B → стойка/клип, клип → стойка, SNIFF_PEE → RETURN, RETURN → START B); RUN → STOP B и START B → RUN как в утверждённых лабораториях; якорь Δx = 0; лапы −26…−19 px; самый большой шаг тела в клипе 1,04 px.

## Честная оценка
* Ощущение «ждёт перед стартом» в обоих вариантах уходит: после возврата в стойку 0,7 с, и старт.
* Цена: в V1 Зефир 3 с стоит в позе метки почти неподвижно. По смыслу это «делает своё дело», но на крупном плане может читаться как застывшая поза (в исходнике там нет даже дыхания). В игровом масштабе заметно меньше. V2 делит неподвижность: 1 с паузы после торможения («заметил запах») и 2 с в позе.
* Полностью убрать неподвижность без нового движения нельзя — только перераспределить.
