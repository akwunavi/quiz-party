# ВРЕМЕННЫЕ ассеты прототипа темы «Книга» — НЕ ФИНАЛЬНЫЕ

Только для прототипов этапа 2 редизайна `ny_book` (`docs-dev/book-redesign/PROTOTYPES.md`). Перед боевой реализацией
(этап 4, Б7) содержимое заменяется финальными ассетами в `public/ny-book/` (проверка альфы, контрольный лист, свой
кеш Service Worker), папка `_tmp` удаляется.

- Источник: листы с настоящей альфой `docs-dev/book-redesign/assets-src/sheet-trees.png`, `sheet-wreaths-garlands.png`.
  Новых генераций не делалось.
- Нарезано `scripts/ny-book/cut-sheet.py` (связные компоненты по альфе, поле 16 px, WebP q88 с альфой без потерь).
- `MANIFEST.json`: `id`, `w`, `h`, `lamps` (центры лампочек в долях ширины/высоты — для мерцания DOM/CSS), `sha`, `src`.
- Огрехи: ели `tree-2` и `tree-4` на листе заходят друг на друга — область перекрытия поделена по близости, у `tree-4`
  слева срезан кусок лапы; лампочки найдены автоматически, часть — блики на шишках.
