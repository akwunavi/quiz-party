# Пупс — экран выбора: цикл IDLE и выход к стойке (23.10.2026)
Статус: **технически готово, ждёт просмотра**. G2 SELECTED и G3 RETURN_TO_IDLE не генерировались. G0, гоночные анимации Пупса, Race V3 и production не менялись. Merge и deploy не было.

## Что сделано
* Утверждённый исходник G1 сохранён без изменений (`../idle_g1/`, `APPROVED.md`).
* Игровой цикл f0–f239, тон выровнен к G0, alpha — `../idle_loop_v1/README.md`.
* Лаборатория `index.html` + `lab.mjs` + `selection.mjs`:
  * IDLE играет непрерывно;
  * «Выбрать Пупса» можно нажать в любой момент → IDLE **доигрывает вперёд** своими кадрами до ближайшего кадра стойки → на месте будущего SELECTED на 1 с показывается утверждённая G0 → IDLE снова с f1 (так будет после RETURN, который закончится на G0);
  * масштаб 638×360, 4 фона, точная покадровая перемотка, без кроссфейда.
* Инструменты: `tools/lab_check.mjs` (рендер сценариев в headless Chromium), `tools/metrics.py` (геометрия alpha на стыках).

## Стыки
**Геометрия alpha** (`results/seams_alpha_geometry.json`, пиксели кадра 1276×720):

| Стык | Центр Δx / Δy | Линия лап | Высота |
|---|---|---|---|
| шов цикла f239 → f0 | 0,05 / 0,11 | 0 | 0 |
| любые ворота → G0 (вход в будущий SELECTED), максимум по 104 кадрам | 0,12 / 0,30 | 1 | 1 |
| G0 → f1 (конец будущего RETURN → IDLE) | 0,02 / 0,18 | 0 | 1 |
| обычный шаг IDLE, медиана / 90-й процентиль | 0,02 / 0,03 и 0,75 / 1,44 | 0 и 0 | 0 и 2 |

Линия лап цикла — 684 px. На f138–f176 нижняя точка 675: это поднятая ближняя лапа, остальные три стоят.

**Пиксели в масштабе лаборатории 638×360** (`results/seams_lab_pixels.json`, средняя разница, белый / чёрный фон):
* шов цикла f239 → f0: 0,34 / 0,31;
* ворота → G0: 0,53–0,89 (хуже всего на краях ворот f74 и f181, где собака только встала);
* G0 → f1: 0,52 / 0,49;
* для сравнения шаг IDLE: медиана 0,10, 75-й процентиль 0,72, 90-й 1,60; неподвижная стойка — 0,03.

Худший стык (0,89) — на уровне утверждённого входа A Фрэнка (0,91) и ниже 90-го процентиля обычного шага. G0 чуть резче кадров Kling, поэтому даже на «идеальных» воротах разница ≈ 0,5. Когда появится SELECTED, его первый кадр будет Kling-рендером той же G0, и стык, скорее всего, станет мягче — проверим отдельно.
