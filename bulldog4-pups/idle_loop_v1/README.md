# Пупс — игровой цикл IDLE v1 (из утверждённого G1)
* **Источник:** `../idle_g1/DOG4_IDLE_G1_kling_original.mp4` — не меняется.
* **Цикл:** кадры **f0–f239** (240 = 10,0 с, 24 к/с). Все движения на месте: ухо и взгляд, наклон и облизывание, «топ» лапой. Спокойные участки не сокращались.
* **Тон:** `make_graded_loop.py`. Для каждого кадра — поканальный сдвиг, чтобы неподвижный студийный фон (x 30–300 и 1000–1246, y 30–690; собака туда не заходит) совпал с утверждённым G0. Сдвиг добавляется ко всему кадру, движение не меняется.
  * Сдвиг: в среднем +2,8 / +3,1 / +2,5 (RGB), от +1,8 до +3,2; на f0 меньше всего — Kling почти повторил входную картинку.
  * Собака против G0 до коррекции: 2,0–3,5 уровня; после: ≤ 0,6 (f0: 0,01 / 0,43 / −0,01; f239: −0,16 / 0,53 / −0,56).
* **Превью с фоном:** `DOG4_IDLE_v1_graded_studio_1cycle.mp4` (1 цикл, H.264).
* **Alpha:** `alpha/DOG4_IDLE_v1_alpha_loop240.webm`.
  * Общий конвейер `bulldog1-frenk/alpha_pipeline`, настройки по умолчанию (`alpha/run_alpha.sh`), вход — выровненный по тону цикл, сжатый без потерь (libx264rgb, crf 0; декодирование побайтно равно PNG).
  * Проверка `verify_alpha.py` (`alpha_check/`): VP9, `alpha_mode=1`, 1276×720, 24 к/с, 240 кадров; углы прозрачны; лишних островков нет; покрытие 17,2–17,8 %; соседние маски IoU min/mean 0,951 / 0,994.
  * Фоны: белый, чёрный, бежевый, тёмно-серый — `alpha_check/ALPHA_sheet_backgrounds.png`; Chromium на мадженте — `alpha_check/ALPHA_chromium_on_magenta.png`. Лаборатория — ещё белый, чёрный, зелёный, бежевый.
* **Кадр f = индекс f** в WebM.
