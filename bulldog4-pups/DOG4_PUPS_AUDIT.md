### 2.3 «Полёт» и скольжение (впервые измерено для №4; `audit_evidence/feet_and_ground_metrics.json`)
Скорость трассы NORMAL — 1,07 px игры за кадр (1078 px / 42 с / 24). Масштаб спрайта — 0,162.

* **RUN — камера в исходнике следует за собакой.**
  * Опорная лапа в кадре уходит назад на ≈ 40 px исходника за кадр (медиана) = **6,4 px игры за кадр**, а трасса двигает спрайт вперёд на 1,07. Лапы в RUN скользят назад относительно дорожки примерно на 5 px за кадр.
  * Нижняя точка силуэта в цикле гуляет на 73 px исходника = **11,8 px игры**: кадры #16–18 — фаза полёта галопа, все лапы в воздухе; тень в лаборатории постоянная.

  Это свойство утверждённого RUN, тот же класс, что у Фрэнка (P3: RUN Фрэнка ≈ 11× скорости трассы). Дефектом Пупса я это не считаю. Насколько «полёт» и скольжение заметны в движении, по кадрам решить нельзя.
* **START.** Кадры #0–23 — стоячие (лапы на месте); трасса за START сдвигает спрайт на ≈ 12,8 px, плавно, большая часть — на #24–39, где собака уже бежит. Видимое скольжение стойки до толчка мало: за первые 0,33 с якорь проходит < 1 px.
* **STOP.** Лапы в кадре почти неподвижны (медиана 0,0 px), а трасса за окно STOP ведёт спрайт вперёд на ≈ 19,8 px с затуханием (≈ 1 px за кадр в начале, 0 в конце). Значит, в игре **опорные лапы STOP проезжают вперёд по дорожке ≈ 20 px** за 1,5 с: «докатывание». Это заложено физикой V3 (торможение во время STOP). Тот же STOP — финиш.
* **BUTTERFLY, ROLL, SNIFF, RETURN** — координата в V3 постоянна. Лапы в кадре стоят (медиана 0). Линия лап меняется на 1,3–4,2 px игры (ROLL — переход в лежание, задокументирован Codex: 3–4 px).

## 5. Выводы

### A. Готов ли Пупс к общей тестовой гонке? — **Да, гоночная часть пригодна**, с двумя оговорками, которые решаются без Kling.
**Основания:**
* все 8 гоночных состояний есть с alpha, атласом и логикой кадров;
* атлас тождествен утверждённым alpha;
* комплект не устарел относительно поздних работ по №4;
* все валидаторы Race V3 зелёные и воспроизводимы;
* №4 — эталон, по которому уже проверены Фрэнк и Зефир: он рядом с ними в `race-v3-frenk-lab/` и `bulldog2/lab_*`;
* пользователь назвал его «утверждённым эталоном гоночной физики и анимационной лаборатории».

**Оговорки перед сборкой общей гонки (не переделки, а подготовка):**
1. **Игровая бабочка.** У Пупса нет ни объекта, ни траектории. У Фрэнка траектория есть (`butterfly_v1/butterfly_trajectory_synced.json`), у Зефира бабочку рисует игра. Нужно решить, какая бабочка летает у Пупса. Без Kling: траекторию можно снять с исходного Kling-видео, где бабочка видна ≈ #29–77.
2. **Масштаб атласа.** Ячейка атласа Пупса — 178×100, а рисуется она в 207×116 (×1,163). Атлас Фрэнка — 207×116. В общей гонке Пупс может выглядеть чуть мягче соседей. Можно пересобрать атлас 207×116 из тех же утверждённых alpha, без изменения движения — **только по отдельному решению**, потому что сейчас атлас — эталон, побайтно проверяемый тестами.

### B. Полностью ли завершена библиотека Пупса? — **Нет.**
Экрана выбора нет целиком: FRONT_STAND (есть только кандидат — кадр RUN #0), IDLE, SELECTED, RETURN_TO_IDLE, переходы и выбор в любой момент. Для этого понадобятся новые генерации, их запуск — только с согласия пользователя. Подробно — `DOG4_PUPS_REMAINING_WORK.md`.
