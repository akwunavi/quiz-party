## Оценка по требованиям пользователя
| Требование | Итог |
|---|---|
| Тот же Пупс | **Да.** Сине-серый окрас и фактура, складки на лбу, янтарные глаза с бликом, форма ушей с розовым, мягкая улыбка с кончиком языка, короткий хвостик |
| Тот же студийный фон и свет | **Да.** Тёмно-серая студия, светлый пол, мягкий свет сверху-справа, контактная тень |
| Корпус фронтально | **Да, почти.** Грудь и обе передние лапы к игроку; корпус слегка развёрнут — зад виден слева, как у Фрэнка и Зефира, только в зеркальную сторону. Ширина силуэта 431 px (у них 422–430) против 496 у RUN #0 |
| Взгляд в камеру | **Да.** Голова прямо, зрачки на игрока, нос по центру между глаз |
| Спокойная дружелюбная поза | **Да.** Стоит спокойно, без напряжения старта |
| 4 лапы на полу | **Да**, все 4 стоят, лап ровно четыре |
| Уши с запасом сверху | **Да**, после нормировки 41 px; у Фрэнка и Зефира 35–36 |
| Без ощущения старта, бега, поворота вправо | **Да.** Корпус не уходит вправо, вес на всех лапах |

## Что отличается от RUN #0 (не скрываю)
1. **Мимика чуть мягче и «просящая».** Складки над глазами приподняты сильнее, чем в RUN #0, где выражение более хитрое. Характер «Пупса» сохраняется, но оттенок немного другой.
2. **Белое пятно на груди больше** — спускается ниже, на живот. В RUN #0 оно уже.
3. **Уши** чуть шире расставлены, розовый внутри насыщеннее.
4. **Язык** виден чуть больше.
5. **В фоне** в правом нижнем углу едва заметный прямоугольник: Kling повторил след залитого мной водяного знака из референса. Собаку это не касается и после alpha исчезает. В студийном кадре для видео виден, только если искать.

Генерации, в которых облик Пупса остался бы совершенно неизменным, по одному кадру не бывает. По-моему, расхождения 1–3 узнаваемость не ломают, но решать вам.
