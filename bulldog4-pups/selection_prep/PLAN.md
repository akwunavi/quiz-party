### Критическая оценка по пунктам
| Вопрос | Оценка |
|---|---|
| **Обращён ли к игроку** | **Частично.** Морда повёрнута к камере, но не прямо: голова примерно на четверть оборота вправо и приподнята, зрачки смотрят чуть вправо-вверх, мимо игрока. | **Виден ли характер** | **Да.** Мягкая улыбка, кончик языка, большие янтарные глаза, задранные уши — «Пупс» читается сразу. Это главное достоинство кадра |
| **Полный силуэт** | **Да**, но с запасом всего 25 px над ушами (у соседей 35). Для SELECTED с подскоком это риск обрезки ушей; у Зефира уши уже обрезались на прыжках |

| **RETURN_TO_IDLE** | Риск выше, чем у соседей. Реакция SELECTED почти наверняка развернёт собаку к игроку, и тогда RETURN должен будет повернуть корпус обратно на 3/4 вправо. Это крупное движение: смена опорных лап, поворот таза, у Kling это частая причина морфинга лап. При фронтальной стойке RETURN — это «успокоиться и встать ровно», как у Фрэнка и Зефира |
| **Совместимость с гонкой** | Совпадение FRONT_STAND с BASE гонки — не аргумент: переход «экран выбора → гонка» не проектируется (решение пользователя для Фрэнка, правило общее) |

## 2. IDLE — сценарий живого ожидания (G1)
**Урок Рокки:** короткий внутренний цикл #34–58 (25 кадров ≈ 1 с) выглядел повторяющимся, почти как картинка. Для Пупса цикл должен быть длинным (6–10 с) и состоять из нескольких разных маленьких действий.

**Генерация:**
* `kling-video-v3_0`, 720p, **10 с**, звук выключен, multi-shot выключен;
* **first = tail = FRONT_STAND** — тогда конец клипа сам возвращается в стойку и цикл замыкается без «туда-обратно», в отличие от IDLE Фрэнка.

**Ход действия** (Kling точные тайминги не соблюдает — у Фрэнка тайминги дали «клевание», — поэтому в промпте только порядок, без секунд):
1. Стоит, спокойно дышит — грудь и живот видимо поднимаются и опускаются **весь клип**; естественное моргание 2–3 раза за клип.
2. Одно ухо поворачивается в сторону, как на звук, и возвращается; взгляд уходит в сторону и возвращается к игроку → **возврат в исходную стойку** (ворота 1).
3. Фирменный щенячий наклон головы набок, пауза, голова выпрямляется, быстрое облизывание носа кончиком языка → **снова исходная стойка** (ворота 2).
4. Мягкий перенос веса: чуть приподнимает одну переднюю лапу и ставит на то же место («топ»), успокаивается.
5. Конец = точно стартовая стойка (tail).

**Почему так:** «возвраты в стартовую стойку» в середине — это **совместимые ворота** для выбора в любой момент. Чем их больше, тем короче ожидание после клика. Цель — не дольше утверждённых 2,42 с у Зефира, допустимый предел — 4,42 с, как у Фрэнка. Если Kling возвраты не сделает, работает запасной путь из лабораторий Фрэнка и Зефира: выход к ближайшему стоячему кадру своими кадрами, туда-обратно, с картой задержки.

**Монтаж цикла:**
* по кадрам найти стоячие моменты (разница с кадром 0 на уровне стоячего шага);
* убрать только затянутую неподвижность, без удаления середины движений;
* проверить шов «конец → начало».

Подъём лапы в п. 4 — часть IDLE: ошибкой не считается (так решили для Зефира).

Промпт — `PROMPT_G1_IDLE_video.txt`.

## 3. SELECTED — реакция на выбор (G2)
**Характер Пупса — милый «обнимашка», а не спортсмен.** Фрэнк и Зефир празднуют прыжками: у Зефира подскок до 96 px, уши обрезались о верх кадра. Пупс празднует **по-щенячьи, не отрываясь от пола**:
1. глаза загораются, уши вперёд, широкая счастливая улыбка с открытой пастью и языком;
2. **игровой поклон** — грудь и передние лапы к полу, локти на полу, зад вверх, коротенький хвост и вся задняя часть радостно виляют;
3. поднимается на 4 лапы, несколько быстрых радостных «тапов» передними лапами на месте, не прыгая;
4. финал: гордо стоит анфас, счастливая улыбка, язык наружу, уши торчком, смотрит на игрока.

**Почему так:**
* отличается от соседей по характеру;
* остаётся в общей эстетике: та же студия, анфас, полный силуэт, 5 с;
* поклон уводит силуэт **вниз**, поэтому риска обрезки ушей нет.

Без вращения: у Kling оно часто ломает лапы.

**Генерация:**
* `kling-video-v3_0`, 720p, **5 с**, звук выключен;
* **first = FRONT_STAND, tail не задаём** — финал свободный, как у Фрэнка и Зефира, чтобы Kling не сжимал реакцию ради возврата в стойку.

Промпт — `PROMPT_G2_SELECTED_video.txt`.

**Вход из IDLE** — как утверждено для всех собак: после клика IDLE доигрывает до ворот (стойка = кадр 0), дальше SELECTED с первого стоячего кадра. Если начало SELECTED окажется стоячим, как у Фрэнка f1–f19, в игре оставляем только то, что нужно для входа без скачка; лишнюю неподвижность режем, как у Фрэнка (вход A, f20).

## 4. RETURN_TO_IDLE (G3)
**Генерация:**
* `kling-video-v3_0`, 720p, **5 с**, звук выключен;
* **first = последний кадр SELECTED** (точный кадр из принятого монтажа), **tail = FRONT_STAND**;
* тот же приём, что для RETURN Фрэнка и Зефира: поза в начале и конце совпала с референсами точно.

**Ход действия:** закрывает пасть до мягкой улыбки с кончиком языка, расслабляет уши, одним небольшим шагом ставит передние лапы под грудь, смотрит на игрока, замирает ровно в FRONT_STAND.

**Связь с выбором в любой момент:**
* RETURN заканчивается **кадром ворот IDLE** (= кадр 0 цикла). После него IDLE продолжается со следующего кадра цикла, без стыка — как у Фрэнка (r121 → IDLE f9) и Зефира;
* во время SELECTED и RETURN выбор не принимается: собака уже выбрана;
* после RETURN цикл и ворота те же, поэтому выбор в любой момент снова работает сразу.

**Известные риски и меры:**
* Kling RETURN Фрэнка был темнее на 2–3 уровня — исправлялось поправкой тона при монтаже;
* затянутые неподвижные части режем аккуратно, как у Зефира (m109), не трогая движения.

Промпт — `PROMPT_G3_RETURN_TO_IDLE_video.txt`.

## 6. План alpha и лабораторной проверки
**Alpha:**
* общий конвейер `bulldog1-frenk/alpha_pipeline` (`dog_alpha.py` + `verify_alpha.py`), настройки по умолчанию, без «чистки пола»: у Фрэнка она резала лапы;
* для каждого клипа — `verify_alpha.py`: углы прозрачны, лишних островков нет, соседние маски, Chromium на мадженте;
* фоны: белый, чёрный, зелёный, бежевый;
* alpha делается только по принятому монтажу — для IDLE, SELECTED, RETURN и FRONT_STAND.

**Лаборатория** `bulldog4-pups/selection_v1/` по образцу утверждённых `bulldog1-frenk/selection_anytime_v1/` и `bulldog2/lab_select_v1/`:
* `selection.mjs`: цикл IDLE, ворота, `exitPath` для каждого кадра цикла, SELECTED, RETURN, повторный вход в цикл, `chain()`;
* лаборатория: IDLE играет непрерывно, «Выбрать» в любой момент, SELECTED один раз, RETURN один раз, затем IDLE бесконечно; без кроссфейда; точная покадровая перемотка; 638×360 на 4 фонах;
* `tools/lab_check.mjs` и `tools/metrics.py` — рендер сценариев и замеры: центр тела, линия лап, высота, площадь на каждом шаге и стыке.

**Проверки:**
* **Карта задержки** выбора по всем кадрам цикла: максимум и среднее. Цель — ≤ 2,42 с, предел — 4,42 с.
* **Не меньше 6 моментов выбора**, включая самое долгое ожидание и самые активные движения: наклон головы, подъём лапы, поворот уха.
* **Стыки:** IDLE → SELECTED, SELECTED → RETURN, RETURN → IDLE, шов цикла. Центр и линия лап ≤ 1 px, разница кадров не больше обычного шага IDLE.
* **IDLE** — 3 цикла подряд, проверка, что не выглядит картинкой: доля неподвижных кадров, разнообразие действий.
* **MP4:** IDLE ×3, полная цепочка для 4–6 моментов выбора, сравнение с Фрэнком и Зефиром в одном ряду.
* **Масштаб:** финальная высота и линия лап совпадают с FRONT_STAND соседей.

**Ограничение, как и раньше:** непрерывное воспроизведение MP4 в реальном времени из этой среды я не вижу. Проверка покадровая и по замерам, итоговое решение — по вашему просмотру.
