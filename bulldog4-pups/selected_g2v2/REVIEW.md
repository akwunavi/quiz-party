## Покадровый разбор
| Кадры | Время | Что происходит |
|---|---|---|
| f0–f12 | 0–0,5 с | стойка G0 |
| f16 | 0,7 с | прищур |
| f20–f28 | 0,8–1,2 с | глаза распахиваются, уши вверх, пасть открывается |
| f28–f72 | 1,2–3,0 с | **радость:** широкая улыбка с открытой пастью и языком, смотрит на игрока; **«топы» передней лапой** — f36, f44–f48, f60, f68: лапа приподнимается и ставится на место; лёгкое покачивание корпусом |
| f76–f92 | 3,2–3,8 с | успокаивается, пасть закрывается до мягкой улыбки с кончиком языка |
| f96–f100 | 4,0–4,2 с | моргание |
| f104–f120 | 4,3–5,0 с | стоит в стойке G0 |

## Требования
| Требование | Итог |
|---|---|
| Похож на француза, внешность Пупса | **Да.** Тот же компактный корпус, большая голова, короткие толстые лапы. Хвостик — короткая серая пупочка, как у G0, весь клип (`CLOSEUP_tail_side.png`) |
| Радостная морда, улыбка, язык | **Да**, 1,2–3,0 с |
| Радостные движения лапами | **Да**, несколько «топов» передней лапой на месте. Лапа поднимается невысоко и ставится обратно, пальцы читаются |
| Без поклона, лёжа, локтей | **Да**, всё время стоит на 4 лапах |
| Без прыжков, разворота, перемещения | **Да.** Корпус анфас, лапы на линии 684 |
| Уши не обрезаются | **Да.** Выше всего — y = 38 (f20); ниже утверждённых 41 px запаса только на 3 px |
| Первый кадр = G0 | **Да.** Поза та же, тон темнее на 2,0–2,4 уровня, как у IDLE |
| Финал | **Совпадает с G0.** Наложение G0 и f120 даёт резкую картинку без двоения; разница 3,06 — почти вся из тона (на 2,7–3,8 уровня темнее, лечится той же поправкой) |

## Что это значит для цепочки
* **RETURN_TO_IDLE отдельной генерацией не нужен.** SELECTED сам заканчивается в стойке G0, после него IDLE может продолжаться с f1, как после RETURN у Фрэнка и Зефира.
* Цепочка: IDLE → выбор → IDLE доигрывает вперёд до стойки → SELECTED f0–f120 (5 с) → IDLE с f1. Экономия — одна генерация (30 кредитов) и один стык.

## Замечания (честно)
1. **Реакция заметно спокойнее, чем у Фрэнка и Зефира.**
   * Радость читается в основном по морде и одной передней лапе.
   * Виляния всем задом почти не видно — корпус лишь слегка покачивается.
   * Для «милого Пупса» это, по-моему, по характеру, но если нужна ярче — это предмет решения, не брак.
2. **Последние ~0,7 с (f104–f120) — почти стоячая стойка.** При сборке цепочки их можно частично отдать IDLE.
3. Самый резкий шаг — f46 (5,6 при медиане 0,85): быстрое движение лапы, без склейки.
