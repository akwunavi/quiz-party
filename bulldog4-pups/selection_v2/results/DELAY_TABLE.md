# Карта задержек выбора Пупса (полная цепочка, v2)

Задержка = время от кадра IDLE, на котором нажали «выбрать», до первого кадра SELECTED. Выход только вперёд по IDLE до ближайших ворот (кадр IDLE, совпадающий с G0), без перемотки назад и без кроссфейда. Ворота те же, что в `selection_v1` (104 кадра); значения пересчитаны по `selection_v2/selection.mjs` и совпали с `selection_v1` для всех 240 кадров (расхождений: 0).

* максимум **3,625 с** (87 кадров) — нажатие на f94, ворота f181;
* среднее 0,79 с; сразу (ворота) — 104 кадра из 240;
* по секундам: < 1 с — 163 кадра, 1–2 с — 37, 2–3 с — 24, 3–3,62 с — 16.

| кадры IDLE | что это | задержка | ворота |
|---|---|---|---|
| f0–f23 | ворота | 0 (SELECTED со следующего кадра) | — |
| f24–f28 | между воротами | 0.21 → 0.04 с | f29 |
| f29–f37 | ворота | 0 (SELECTED со следующего кадра) | — |
| f38–f73 | между воротами | 1.50 → 0.04 с | f74 |
| f74–f93 | ворота | 0 (SELECTED со следующего кадра) | — |
| f94–f180 | между воротами | 3.62 → 0.04 с | f181 |
| f181–f197 | ворота | 0 (SELECTED со следующего кадра) | — |
| f198–f205 | между воротами | 0.33 → 0.04 с | f206 |
| f206–f239 | ворота | 0 (SELECTED со следующего кадра) | — |

Полная таблица по каждому кадру — `delay_map.json`; график — `DELAY_MAP.png` (тот же, что в `selection_v1`, ворота не менялись).
