## ⚠ Уши SELECTED и компоновка карточки
На SELECTED s63–s70 (0,33 с, пик подскока) кончики ушей выходят за верхний край кадра. Кадры оставлены как есть (решение 02.11.2026). **Требование к экрану выбора:** верхний край изображения совпадает с верхним краем области карточки, всё за краем обрезается — тогда уши уходят за границу карточки. Над кадром не должно быть видимого фона. Растушёвку, уменьшение собаки и сдвиг кадров не применять.

2. Ожидание выбора до 3,625 с; спокойные участки IDLE не сокращаются (решение 02.11).
3. Атлас 178×100 растягивается до 207×116 (×1,163). Решение 1.2 открыто, по умолчанию «как есть».
4. Свойства утверждённых гоночных клипов, известные с аудита: «полёт» и скольжение RUN, «докатывание» лап в STOP, смена фазы на стыке RUN → STOP крупно, ускоренный START, ≈ 0,5 с стойки в конце ROLL, ускоренный RETURN.
5. Клипа-моста «экран выбора → гонка» нет — смена экрана.
Полный список — `integration_v1/README.md`, «Известные допустимые ограничения».
