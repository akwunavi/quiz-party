# Новогодняя трасса — концепт для визуальной приёмки

Сначала откройте [единый PDF](WINTER_ARENA_CONCEPTS_A_B_C.pdf): три страницы, по одному направлению и пять ключевых кадров на каждой. Исходные листы доступны отдельно в `art/`, схемы маршрута — в `maps/`. Сравнение художественных решений, логика камеры и риски описаны в [CONCEPT_PACKAGE.md](CONCEPT_PACKAGE.md).

Три направления показывают **один маршрут** и не являются тремя разными игровыми аренами. Кадры — иллюстрации для выбора стиля, а не снимки браузерной гонки или утверждённая геометрия. Работы над Race V3, исходными анимациями и production в этой ветке нет.

Карты можно воспроизвести командой `python3 make_maps.py`, PDF — `python3 make_review_pdf.py` (используются Pillow и ReportLab). Оригинальные концепт-изображения в `art/` сохранены без изменения.
