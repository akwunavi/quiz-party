# Зимняя арена Bulldog Racing — изолированная лаборатория

**Статус:** технический и композиционный прототип для визуальной приёмки. Существующий RaceBoard и Race V3 не изменены; эти MP4 показывают только диагностическое движение.

## Запуск

Из корня репозитория после `npm ci`:

```bash
npx vite prototypes/winter-arena-lab --host 127.0.0.1
```

Открыть `http://127.0.0.1:5173/`. Доступны композиции A/B, допустимый угол камеры, запуск/пауза и сброс. Атласы RUN уже сохранены в `assets/`; Kling и генерация новых движений не нужны.

## Аудит и контракт рендера

- В текущем `src/pages/rounds/RaceRound.tsx` находится production `RaceBoard` с собственным `buildRace` и отображением трассы. Его код не импортирован и не менялся. Отдельные лаборатории Race V3 используют `bulldog3/race-start-v3-lab/model.mjs`, где `stateAt(dog,t)` выдаёт `progress`, `segment`, `clip`, `frame`, а время STOP/FINISH вычисляется моделью. `bulldog3/run-phase-v3-lab/phase.mjs` меняет только отображаемую фазу RUN Рокки. Это готовый принцип подключения нового рендера: адаптер принимает готовое состояние, но не решает результаты гонки.
- В этой лаборатории движение — линейный тест по пяти полосам и 24 FPS, **не Race V3**. Для последующей интеграции вход рендера: `{dogId, lane, progress, clip, frame, eventIndex}`. `progress` переводится в мировую координату X; `lane` — в фиксированную Z; клип и кадр выбирают утверждённый alpha-атлас. Событие BUTTERFLY в будущем даст отдельный объект с координатой от того же мирового якоря собаки. Снег, лёд, ели и камера не должны вызывать обратных вызовов в физику.
- Две будущие арены лучше оформлять как сменяемые наборы окружения `winter` / `stadium` над одним контрактом координат дорожек и одним адаптером Race V3. Выбор арены меняет сцену, свет и декорации, но не прогресс, события или анимации собак. Стадион сейчас не реализован.
- Исходные alpha-файлы различаются прозрачными полями; атласы содержат исходные пиксели, а размер плоскости подогнан по видимой высоте силуэта. Для перспективной камеры применяется только компенсация **размера отображаемой плоскости** по глубине; проекционная высота собаки остаётся приблизительно постоянной между дорожками и при движении по X. Видимый низ лап закреплён у Y≈0.04, рядом с отдельной программной контактной тенью. Камера ограничена небольшим диапазоном высоты, без поворота собак к зрителю. Пять независимых плоскостей движутся по X, каждая на собственной Z. Эта визуальная компенсация не влияет на мировую позицию и физику.
- Источники атласов: Frank #1 и Zephyr #2 — `artifacts/bulldog-racing/four-alpha/published/dog{1,2}-run-alpha.webm`; Rocky #3 и dog #5 — `artifacts/bulldog-racing/v2-dog3-dog5/published/bulldog_{03,05}_run_alpha_v2.webm`; dog #4 — `artifacts/bulldog-racing/dog4-loop-audit/delivery/dog4_run_loop_short_03_13_alpha.webm`. Здесь dog #5 подписан «Пупс» по заданию; связь имени с номером нужно сверить перед общей интеграцией. Атласы — диагностические выдержки по 12 кадров, а не новые утверждённые игровые RUN. Исходные видео не менялись.

## Выбор технологии

| Подход | Плюсы | Ограничения для этой сцены |
| --- | --- | --- |
| Canvas 2D | Простая интеграция alpha и кадров; малый технический риск | Ели, боковые поверхности льда, камера и перекрытия потребуют ручной системы проекции и сортировки. |
| Three.js | Согласованные мировые координаты пяти полос, объёмные ели, свет, камера, проверяемая опора лап | Нужна тщательная работа с прозрачностью и размером спрайтов; WebGL на слабых проекторах надо профилировать. |
| Гибрид: 3D окружение + DOM/Canvas собаки | Сохраняет существующий 2D-плеер собак | Требует синхронизации экранных и мировых координат, z-occlusion и теней на каждом кадре. |

**Рекомендация для прототипа:** Three.js с плоскими alpha-плоскостями собак. Это проверяет самое рискованное место — совместимость принятых 2D-персонажей с 3D трассой — без переписывания Race V3. В production выбор следует подтвердить профилированием проекторного устройства и проверкой реальных событий.

## Открытые вопросы

- Атласные выдержки демонстрируют RUN, но не утверждённые переходы STOP/START/ROLL всех пяти собак. Потребуется реестр клипов и отдельная проверка каждого состояния.
- Прозрачные поля и ракурсы собак отличаются; текущая нормализация по высоте помогает одинаковому игровому размеру, но точные игровые якоря предстоит утвердить на общей гонке.
- Проекторная читаемость проверена в Chromium на кадре 1920×1080; контраст пастельного льда и размер собак нужно оценить на реальном проекторе. Возможная 3D окклюзия от новых декораций должна тестироваться отдельно.
- Тестовая траектория и подпись «Пупс» — демонстрационные. Никаких результатов, очков, победителя или физического влияния льда здесь нет.
