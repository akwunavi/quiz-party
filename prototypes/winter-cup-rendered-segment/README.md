# Снежный кубок — интерактивный участок B × C

Изолированная лаборатория одного зимнего зрительского участка. Построена на выбранной конструкции **B — спортивный кубок** и палитре **C — сказочные сумерки**. Собаки, Race V3 и production не подключены. Пять полупрозрачных габаритных маркеров включаются флажком в интерфейсе.

## Запуск

Из корня репозитория:

```bash
npx vite prototypes/winter-cup-rendered-segment --host 127.0.0.1 --port 5180
```

Открыть `http://127.0.0.1:5180/`, нажать **«Запустить камеру»**. Ползунок перемещает камеру внутри 18-секундного участка. Кнопка **«Габариты участников»** показывает пять тестовых объёмов, не изображения собак.

Собранная версия лежит в `dist/`: её можно открыть через любой статический HTTP-сервер. MP4 в `review/` открывается отдельно, без запуска сервера.

## Технология и границы результата

Трасса, снежные разделители, зрительские трибуны, домики, ели, фонари, зрители и гирлянды — объекты Three.js с мировыми координатами. Камера действительно перемещается вдоль X; сооружения проходят перед ней. Статичные меши объединены по материалам и пространственным блокам. Небо и дальние хребты — процедурная 2.5D текстура, а не прокрутка концепт-изображения. Лёд и доски имеют процедурные текстуры. Дорогих динамических теней нет; внешних ассетов нет.

Это **техническая визуальная итерация**, не художественно принятая сцена. Измеренные FPS, память, точные расхождения с концептом и рекомендуемый следующий шаг — в [REPORT.md](REPORT.md). Снимки и MP4 реального браузерного рендера — в `review/`.
